# Практика. Организуем разделы приложения

## Перед началом

Откройте учебную базу в **Конфигураторе**. В дереве должны быть справочники «Клиенты», «Товары» и «Сотрудники», созданные в день 2. Если их нет, сначала выполните практику дня 2.

## Шаг 1. Создайте подсистему «Продажи»

1. В дереве конфигурации найдите узел **Подсистемы** и щёлкните по нему правой кнопкой мыши.
2. Выберите **Добавить**. Будет создан объект метаданных типа «Подсистема».
3. В окне свойств в поле **Имя** введите `Продажи`, а в поле **Синоним** — «Продажи».
4. Откройте вкладку **Состав**. Это список объектов, команды которых можно показать в разделе.
5. Раскройте группу **Справочники**, установите флажки у «Клиенты» и «Товары».
6. Нажмите `Ctrl+S`.

**Проверка:** в дереве есть подсистема «Продажи»; в её составе отмечены «Клиенты» и «Товары».

## Шаг 2. Создайте подсистему «Компания»

1. У узла **Подсистемы** снова выберите **Добавить**.
2. В полях свойств укажите имя `Компания` и синоним «Компания».
3. На вкладке **Состав** раскройте «Справочники» и отметьте «Сотрудники».
4. Нажмите `Ctrl+S`.

**Проверка:** «Сотрудники» включены в «Компанию», а не в «Продажи».

## Шаг 3. Проверьте интерфейс

1. Нажмите `F7` и подтвердите обновление конфигурации базы данных.
2. Нажмите `F5`, чтобы открыть режим «1С:Предприятие».
3. В панели разделов откройте «Продажи»: там должны быть команды «Клиенты» и «Товары».
4. Откройте «Компания»: там должна быть команда «Сотрудники».

Если раздела нет, вернитесь в Конфигуратор: проверьте состав подсистемы, сохранение и обновление конфигурации базы данных.
