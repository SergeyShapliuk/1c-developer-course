# Занятие 15. Процедуры, функции и параметры

## Цель

Научиться выносить код из обработчика команды в отдельные процедуры и функции, передавать им параметры, задавать значения по умолчанию и понимать, когда присваивание внутри процедуры меняет переменную снаружи.

## Результат занятия

В модуле формы обработки `УчебнаяКонсоль` появились функции `РассчитатьСумму`, `РассчитатьСуммуСНДС`, `СуммаДиапазона` и процедура `ВывестиИтог`. Обработчик `Выполнить` только вызывает их и не содержит ни одной формулы. Вы видели на своём коде разницу между обычным параметром и параметром с `Знач`.

## Маршрут

1. Прочитайте [теорию](theory.md) — около 25 минут.
2. Выполните [практику](practice.md) — около 55 минут.
3. Ответьте на контрольные вопросы в конце практики, не подглядывая в теорию.

## Ключевые термины

Процедура, функция, `Возврат`, вызов, параметр, аргумент, порядок параметров, значение по умолчанию, передача по ссылке, `Знач`, `Экспорт` (упоминание), модуль формы.
