# Практика. Выносим расчёты в процедуры и функции

## Перед началом

Работаем там же, где и на занятиях 11–14. В дереве конфигурации откройте **Обработки → УчебнаяКонсоль**, затем её форму и вкладку **Модуль**. В модуле уже есть обработчик команды:

```bsl
&НаКлиенте
Процедура Выполнить(Команда)

КонецПроцедуры
```

Сегодня код пишем не только внутри `Выполнить`, но и рядом с ним: новые процедуры и функции добавляем **после** строки `КонецПроцедуры`, каждую отдельным блоком. Вкладывать одну процедуру в другую нельзя.

После каждой правки: `Ctrl+S`, затем `F5`, затем в приложении раздел **Разработка → Учебная консоль** и кнопка **Выполнить**. Сообщения появятся в нижней части окна приложения. Дальше — коротко: «сохраните, запустите и нажмите **Выполнить**».

Код предыдущего занятия из `Выполнить` можно удалить. Функции, которые мы напишем сегодня, понадобятся и на следующих занятиях, поэтому имена и параметры оставляйте в точности такими, как здесь.

## Шаг 1. Первая функция

Вынесем умножение количества на цену в функцию.

```bsl
&НаКлиенте
Процедура Выполнить(Команда)

	Сообщить("Сумма: " + Строка(РассчитатьСумму(20, 12.5)));

КонецПроцедуры

&НаКлиенте
Функция РассчитатьСумму(Количество, Цена)
	Возврат Количество * Цена;
КонецФункции
```

Сохраните, запустите и нажмите **Выполнить**. Вызов `РассчитатьСумму(20, 12.5)` стоит прямо внутри выражения — именно так и используют функции: их результат подставляется туда, где нужно значение.

Поменяйте аргументы местами: `РассчитатьСумму(12.5, 20)`. Результат тот же, потому что умножение не зависит от порядка, но имена параметров теперь врут: 12.5 попало в `Количество`. С делением такая ошибка стоила бы дороже. Верните правильный порядок.

**Проверка:** выведено «Сумма: 250».

## Шаг 2. Параметр со значением по умолчанию

Добавьте после `РассчитатьСумму` вторую функцию:

```bsl
&НаКлиенте
Функция РассчитатьСуммуСНДС(Сумма, Ставка = 20)
	Возврат Сумма + Сумма * Ставка / 100;
КонецФункции
```

А в `Выполнить` вызовите её дважды:

```bsl
Сообщить("Со ставкой 10: " + Строка(РассчитатьСуммуСНДС(1000, 10)));
Сообщить("Без указания ставки: " + Строка(РассчитатьСуммуСНДС(1000)));
```

Во втором вызове вторая цифра не указана, поэтому платформа подставила значение по умолчанию — 20.

**Проверка:** выведено «Со ставкой 10: 1100» и «Без указания ставки: 1200».

## Шаг 3. Процедура вывода

Теперь выделим само оформление сообщения. Добавьте в модуль:

```bsl
&НаКлиенте
Процедура ВывестиИтог(Заголовок, Значение)
	Сообщить(Заголовок + ": " + Строка(Значение));
КонецПроцедуры
```

Это процедура, а не функция: она ничего не возвращает, а только выполняет действие. Вызовите её из `Выполнить` трижды:

```bsl
ВывестиИтог("Количество", 20);
ВывестиИтог("Цена", 12.5);
ВывестиИтог("Сумма", РассчитатьСумму(20, 12.5));
```

Сравните два вида вызова. `ВывестиИтог(...)` стоит отдельной строкой с точкой с запятой — это процедура. `РассчитатьСумму(20, 12.5)` стоит внутри другого вызова, его результат куда-то идёт — это функция.

Заодно `Строка()` теперь написан один раз внутри процедуры, а не в каждой строке вывода.

**Проверка:** выведено три сообщения: «Количество: 20», «Цена: 12,5», «Сумма: 250».

## Шаг 4. Перепишем расчёт из занятия 14

На занятии 14 сумма чисел от 1 до 100 считалась прямо в обработчике. Вынесем её в функцию с параметрами, чтобы границы можно было задавать. Добавьте в модуль:

```bsl
&НаКлиенте
Функция СуммаДиапазона(Начало, Конец)
	Перем Итог;
	Итог = 0;
	Для Счётчик = Начало По Конец Цикл
		Итог = Итог + Счётчик;
	КонецЦикла;
	Возврат Итог;
КонецФункции
```

В `Выполнить` оставьте только вызовы:

```bsl
ВывестиИтог("Сумма от 1 до 100", СуммаДиапазона(1, 100));
ВывестиИтог("Сумма от 1 до 10", СуммаДиапазона(1, 10));
```

Посмотрите, что получилось. Цикл и накопитель спрятались внутрь функции, а в обработчике осталось описание замысла словами. Раньше, чтобы понять, что делает `Выполнить`, нужно было прочитать цикл; теперь достаточно прочитать имя.

**Проверка:** выведено «Сумма от 1 до 100: 5050» и «Сумма от 1 до 10: 55».

## Шаг 5. Передача по ссылке и Знач

Этот шаг объясняет поведение, которое новичков удивляет. Добавьте в модуль процедуру:

```bsl
&НаКлиенте
Процедура УвеличитьНаДесять(ТекущееЗначение)
	ТекущееЗначение = ТекущееЗначение + 10;
КонецПроцедуры
```

Замените текст процедуры `Выполнить` — строки `Перем` обязаны стоять в самом начале процедуры, до остальных операторов:

```bsl
Перем Значение;

Значение = 5;
ВывестиИтог("До вызова", Значение);
УвеличитьНаДесять(Значение);
ВывестиИтог("После вызова", Значение);
```

Сохраните, запустите и нажмите **Выполнить**. После вызова переменная снаружи равна 15: по умолчанию параметр передаётся по ссылке, и присваивание внутри процедуры достало до переменной в месте вызова.

Теперь добавьте в объявление процедуры одно слово:

```bsl
&НаКлиенте
Процедура УвеличитьНаДесять(Знач ТекущееЗначение)
	ТекущееЗначение = ТекущееЗначение + 10;
КонецПроцедуры
```

Сохраните, запустите и нажмите **Выполнить** снова. Теперь после вызова по-прежнему 5: `Знач` сделал параметр копией, и процедура меняла копию.

**Проверка:** без `Знач` выводится «После вызова: 15», со `Знач` — «После вызова: 5». Вы можете объяснить разницу.

## Шаг 6. Соберём всё вместе

Приведём `Выполнить` к виду, в котором нет ни одной формулы:

```bsl
&НаКлиенте
Процедура Выполнить(Команда)

	Перем Количество;
	Перем Цена;
	Перем Сумма;
	Перем СуммаСНДС;

	Количество = 20;
	Цена = 12.5;

	Сумма = РассчитатьСумму(Количество, Цена);
	СуммаСНДС = РассчитатьСуммуСНДС(Сумма);

	ВывестиИтог("Количество", Количество);
	ВывестиИтог("Цена", Цена);
	ВывестиИтог("Сумма без НДС", Сумма);
	ВывестиИтог("Сумма с НДС", СуммаСНДС);

КонецПроцедуры
```

В обработчике не осталось ни `*`, ни `/`, ни `+` — только имена и порядок действий. Все формулы живут в функциях, и каждую можно поправить в одном месте.

**Проверка:** выведено четыре сообщения, последние два — «Сумма без НДС: 250» и «Сумма с НДС: 300».

## Проверка результата

Занятие пройдено, если выполняются пять условий:

1. В модуле формы есть функции `РассчитатьСумму(Количество, Цена)`, `РассчитатьСуммуСНДС(Сумма, Ставка = 20)`, `СуммаДиапазона(Начало, Конец)` и процедура `ВывестиИтог(Заголовок, Значение)` — именно с этими именами и параметрами.
2. `РассчитатьСуммуСНДС(1000)` без второго аргумента даёт 1200.
3. Обработчик `Выполнить` не содержит ни одной формулы, только вызовы.
4. Вы увидели на своём коде оба поведения параметра — со `Знач` и без него.
5. Вы можете по виду вызова сказать, процедура это или функция.
