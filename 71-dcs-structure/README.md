# Занятие 71. Структура отчёта: группировки и детальные записи

## Цель

Понять, как система компоновки строит из плоского набора строк отчёт с группами и промежуточными итогами. Научиться собирать структуру отчёта в настройках схемы: группировки, вложенные группировки и детальные записи — и увидеть, чем группировка отчёта отличается от `СГРУППИРОВАТЬ ПО` запроса.

## Результат занятия

Отчёт `ОстаткиНаСкладах` покажет остатки в виде дерева: склад — строка с итогом по складу, под ним материалы этого склада, внизу общий итог. Пользователь сможет свернуть склад до одной строки. Текст запроса набора данных при этом не изменится.
