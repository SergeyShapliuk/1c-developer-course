# Занятие 74. Вычисляемые поля и выражения ресурсов

## Цель

Научиться получать в отчёте значение, которого нет ни в одном наборе данных, — стоимость остатка как произведение количества и цены из двух разных наборов. Понять, на каком уровне система компоновки вычисляет поле и ресурс, почему стоимость склада — это сумма произведений, а не произведение сумм, и как вывести цену только в строке материала.

## Результат занятия

В схеме отчёта `ОстаткиНаСкладах` появится вычисляемое поле `Стоимость` и ресурс `Сумма(Стоимость)`: отчёт покажет стоимость каждого материала, итог по складу и общий итог. Цена станет ресурсом, который считается только по материалу, и перестанет быть полем группировки. Стоимость цемента и итог «Центрального склада» совпадут с ручным расчётом.
