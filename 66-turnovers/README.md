# Занятие 66. Обороты и остатки с оборотами

## Цель

Научиться получать из регистра накопления движение за период: сколько материала пришло и ушло, с какого остатка период начался и каким закончился. Понять, чем таблица оборотов отличается от таблицы остатков и как параметр периодичности раскладывает обороты по дням и по документам.

## Результат занятия

В обработке `УчебнаяКонсоль` появится оборотная ведомость «Центрального склада» за месяц: по каждому материалу начальный остаток, приход, расход и конечный остаток. Вторая процедура покажет обороты цемента по дням, третья — карточку материала по документам-регистраторам с остатком после каждого документа. Карточка совпадёт с историей материала из занятия 60, но будет получена из регистра, а не из документов.

## Маршрут

1. Прочитайте [теорию](theory.md) — около 30 минут.
2. Выполните [практику](practice.md) — около 60 минут.
3. Ответьте на контрольные вопросы в конце практики, не подглядывая в теорию.

## Ключевые термины

Виртуальная таблица оборотов, `Обороты`, `КоличествоПриход`, `КоличествоРасход`, `КоличествоОборот`, виртуальная таблица остатков и оборотов, `ОстаткиИОбороты`, начальный остаток, конечный остаток, периодичность, поле `Период`, периодичность `Регистратор`, оборотная ведомость, карточка материала.
