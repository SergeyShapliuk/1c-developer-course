# Занятие 50. Расход материалов

## Цель

Понять, почему один регистр накопления получает движения от разных документов и почему расход — это не отрицательный приход. Научиться формировать движения вида «Расход» из второго документа-регистратора.

## Результат занятия

В конфигурации появится документ `ПередачаМатериалов` с реквизитами `Склад`, `ОбъектСтроительства`, `Ответственный` и табличной частью `Материалы`, включённым проведением и формой. Он станет вторым регистратором регистра `ОстаткиМатериалов` из занятия 42, а его `ОбработкаПроведения` будет писать движения с `ВидДвижения = ВидДвиженияНакопления.Расход`. После проведения передачи остаток на «Центральном складе» уменьшится, а приход из занятия 49 останется неизменным.

## Ключевые термины

`ПередачаМатериалов`, второй регистратор, `ВидДвижения`, `ВидДвиженияНакопления.Приход`, `ВидДвиженияНакопления.Расход`, движение, состояние учёта, отрицательный остаток, долг этапа 5.
