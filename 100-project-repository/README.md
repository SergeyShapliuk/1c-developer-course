# Занятие 100. Репозиторий проекта: конфигурация в файлах

## Цель

Завести для учебной конфигурации собственный Git-репозиторий, в котором исходным кодом проекта будет текстовая выгрузка конфигурации и расширения. Разобраться, как устроена выгрузка, зачем нужен файл `ConfigDumpInfo.xml`, чем полная выгрузка отличается от выгрузки изменений и как убедиться, что из репозитория можно собрать конфигурацию заново.

## Результат занятия

Рядом с конспектом появится репозиторий `construction-erp`. В каталоге `src/cf` лежит выгрузка конфигурации, в `src/cfe/ДоработкиСнабжения` — выгрузка расширения, файлы `.gitignore` и `.gitattributes` защищают историю от бинарных файлов и служебного шума. Первый коммит фиксирует состояние конфигурации после этапа 8. Пустая база `УСК_Проверка`, собранная из этих файлов, не отличается от учебной ни на один объект.

## Ключевые термины

Репозиторий проекта, исходный код конфигурации, выгрузка конфигурации в файлы, иерархический формат выгрузки, файл `ConfigDumpInfo.xml`, полная выгрузка, выгрузка изменений, загрузка конфигурации из файлов, выгрузка расширения, `.gitignore`, `.gitattributes`, `core.quotepath`.
