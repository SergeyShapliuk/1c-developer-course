# Теория. Табличные части документов

## Что такое табличная часть

**Табличная часть** — это список строк внутри одного объекта, обычно документа. Она нужна, когда один документ относится к нескольким позициям. Одно поступление может содержать цемент, кирпич и арматуру; создавать для них три отдельных документа было бы неудобно.

У строки табличной части есть собственные реквизиты. Для материалов это обычно товар, количество и цена. Основные реквизиты документа — поставщик, склад, дата — относятся ко всему документу, а не к отдельной строке.

## Заявка на материалы

Заявка фиксирует потребность объекта строительства в материалах. Позднее на её основании можно будет оформлять закупку или перемещение со склада. Пока заявка будет содержать объект строительства и список запрошенных материалов.

## Типы реквизитов строк

`Товар` имеет тип ссылки на справочник «Товары». `Количество` и `Цена` имеют тип `Число`, потому что эти значения участвуют в расчётах. При создании числа в настройке типа можно оставить параметры по умолчанию; точность денежных сумм мы настроим позже.
