# День 8. Табличные части и заявки на материалы

## Цель

Научиться хранить несколько строк в одном документе и создать заявку на материалы для строительного объекта.

## Результат дня

Документ «ПоступлениеМатериалов» получит табличную часть «Материалы». Также появится документ «ЗаявкаНаМатериалы» для запроса материалов на объект.

## Маршрут

1. Прочитайте [теорию](theory.md).
2. Выполните [практику](practice.md).
3. Ответьте на контрольные вопросы в конце практики.
