# Занятие 10. Git и GitHub для Junior 1С-разработчика

## Цель

Освоить контроль версий на том уровне, который ожидают от junior-разработчика: понять модель Git, научиться делать коммиты и ветки и увидеть, как в Git хранят конфигурацию 1С.

## Результат занятия

У вас появится локальный репозиторий с конспектом обучения и не менее четырёх коммитов, созданная ветка, файл `.gitignore` и выгрузка конфигурации «Управление строительной компанией с логистикой» в текстовые файлы под контролем версий. Вторая, дополнительная часть практики отправит репозиторий на GitHub — она необязательна.

## Маршрут

1. Прочитайте [теорию](theory.md) — около 25 минут.
2. Выполните обязательную часть [практики](practice.md) — около 60 минут.
3. При желании выполните дополнительную часть про GitHub — около 20 минут.
4. Ответьте на контрольные вопросы в конце практики, не подглядывая в теорию.

## Ключевые термины

Контроль версий, репозиторий, рабочий каталог, индекс, коммит, история, ветка, `main`, удалённый репозиторий, `origin`, `push`, `.gitignore`, выгрузка конфигурации в файлы.
