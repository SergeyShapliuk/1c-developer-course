# Занятие 7. Перечисления и константы

## Цель

Разобраться в двух объектах метаданных, которые часто путают со справочником: перечисление для фиксированного набора вариантов и константа для одного общего значения на всю базу. Научиться выбирать между ними осознанно.

## Результат занятия

В конфигурации появятся перечисление «Виды клиентов» с тремя значениями и две константы — «Наименование компании» и «Дата начала учёта». Значения констант будут введены в режиме «1С:Предприятие» через команду **Все функции**, которую вы включите сами.

## Маршрут

1. Прочитайте [теорию](theory.md) — около 20 минут.
2. Выполните [практику](practice.md) — около 40 минут.
3. Ответьте на контрольные вопросы в конце практики, не подглядывая в теорию.

## Ключевые термины

Перечисление, значение перечисления, константа, тип значения, состав даты, команда «Все функции», фиксированный набор значений.
