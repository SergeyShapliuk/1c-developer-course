# Занятие 63. Временные таблицы и пакетный запрос

## Цель

Научиться разбивать сложный запрос на шаги: сначала сложить данные во временные таблицы, затем соединить их в итоговом запросе. Понять, что такое пакетный запрос, как проверить результат каждого шага и как один промежуточный результат использовать в нескольких запросах.

## Результат занятия

Исполнение заявок из занятия 62 будет переписано пакетом из трёх запросов: временная таблица заказанного, временная таблица поступившего и итоговое соединение. Вы проверите число строк в каждой временной таблице через `ВыполнитьПакет`, а затем вторым запросом с тем же менеджером временных таблиц выведете заявки, полностью обеспеченные материалами.

## Маршрут

1. Прочитайте [теорию](theory.md) — около 30 минут.
2. Выполните [практику](practice.md) — около 60 минут.
3. Ответьте на контрольные вопросы в конце практики, не подглядывая в теорию.

## Ключевые термины

Временная таблица, `ПОМЕСТИТЬ`, пакетный запрос, разделитель `;`, `ВыполнитьПакет`, `МенеджерВременныхТаблиц`, `УНИЧТОЖИТЬ`, `ИНДЕКСИРОВАТЬ ПО`, таблица значений как параметр запроса.
