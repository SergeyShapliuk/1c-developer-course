# Практика. Исполнение заявок по шагам

## Перед началом

Запустите конфигуратор учебной конфигурации **«Управление строительной компанией с логистикой»** и откройте модуль формы обработки `УчебнаяКонсоль`. Понадобятся данные и процедура `ВывестиИсполнениеЗаявокТочно` из занятия 62: заявка «ЖК Северный» с двумя поступлениями, заявка с двумя строками цемента и заявка без поступлений.

Вопросы, на которые отвечаем: «Сколько по каждой заявке заказано, поступило и осталось получить?» и «Какие заявки обеспечены полностью?»

После каждой правки кода: `Ctrl+S`, затем `F5`, раздел **Разработка → Учебная консоль**, кнопка **Выполнить**.

## Шаг 1. Перепишите исполнение пакетом

1. Добавьте процедуру и вызовите её из `Выполнить` вместо прежних вызовов:

```bsl
&НаСервере
Процедура ВывестиИсполнениеПакетом()

	Запрос = Новый Запрос;
	Запрос.Текст =
		"ВЫБРАТЬ
		|	ЗаявкаМатериалы.Ссылка КАК Заявка,
		|	ЗаявкаМатериалы.Материал КАК Материал,
		|	СУММА(ЗаявкаМатериалы.Количество) КАК Количество
		|ПОМЕСТИТЬ ВТ_Заказано
		|ИЗ
		|	Документ.ЗаявкаНаМатериалы.Материалы КАК ЗаявкаМатериалы
		|ГДЕ
		|	НЕ ЗаявкаМатериалы.Ссылка.ПометкаУдаления
		|	И ЗаявкаМатериалы.Ссылка.Состояние <> ЗНАЧЕНИЕ(Перечисление.СостоянияЗаявок.Отклонена)
		|СГРУППИРОВАТЬ ПО
		|	ЗаявкаМатериалы.Ссылка,
		|	ЗаявкаМатериалы.Материал
		|;
		|
		|////////////////////////////////////////////////////////////////////////////////
		|ВЫБРАТЬ
		|	ПоступлениеМатериалы.Ссылка.ДокументОснование КАК Заявка,
		|	ПоступлениеМатериалы.Материал КАК Материал,
		|	СУММА(ПоступлениеМатериалы.Количество) КАК Количество
		|ПОМЕСТИТЬ ВТ_Поступило
		|ИЗ
		|	Документ.ПоступлениеМатериалов.Материалы КАК ПоступлениеМатериалы
		|ГДЕ
		|	ПоступлениеМатериалы.Ссылка.Проведен
		|СГРУППИРОВАТЬ ПО
		|	ПоступлениеМатериалы.Ссылка.ДокументОснование,
		|	ПоступлениеМатериалы.Материал
		|;
		|
		|////////////////////////////////////////////////////////////////////////////////
		|ВЫБРАТЬ
		|	Заказано.Заявка КАК Заявка,
		|	ПРЕДСТАВЛЕНИЕ(Заказано.Материал) КАК Материал,
		|	Заказано.Количество КАК Заказано,
		|	ЕСТЬNULL(Поступило.Количество, 0) КАК Поступило,
		|	Заказано.Количество - ЕСТЬNULL(Поступило.Количество, 0) КАК ОсталосьПолучить
		|ИЗ
		|	ВТ_Заказано КАК Заказано
		|		ЛЕВОЕ СОЕДИНЕНИЕ ВТ_Поступило КАК Поступило
		|		ПО Поступило.Заявка = Заказано.Заявка
		|			И Поступило.Материал = Заказано.Материал";

	Выборка = Запрос.Выполнить().Выбрать();

	Пока Выборка.Следующий() Цикл
		Сообщить(Строка(Выборка.Заявка) + ", " + Выборка.Материал + ": заказано " + Выборка.Заказано
			+ ", поступило " + Выборка.Поступило + ", осталось " + Выборка.ОсталосьПолучить);
	КонецЦикла;

КонецПроцедуры
```

2. Сохраните, запустите.

Строки из косых черт — комментарий в языке запросов. Конструктор запроса сам ставит такие разделители между запросами пакета, и они помогают глазу находить границы шагов.

3. Сравните вывод с выводом процедуры `ВывестиИсполнениеЗаявокТочно` занятия 62.

**Проверка:** вывод совпадает с выводом занятия 62 строка в строку.

## Шаг 2. Посмотрите пакет в конструкторе

1. Поставьте курсор внутрь текста запроса и откройте **Конструктор запроса**.
2. Перейдите на вкладку **Пакет запросов**: в списке три запроса.
3. Откройте первый запрос и найдите на вкладке **Дополнительно** переключатель **Создание временной таблицы** и имя `ВТ_Заказано`.
4. Откройте третий запрос и посмотрите дерево **База данных**: в нём появилась ветка **Временные таблицы** с `ВТ_Заказано` и `ВТ_Поступило`.
5. Закройте конструктор кнопкой **Отмена**.

**Проверка:** вы нашли в конструкторе три запроса пакета и временные таблицы в дереве источников.

## Шаг 3. Проверьте каждый шаг пакета

1. Замените строку получения выборки так, чтобы сначала выполнить весь пакет:

```bsl
	Результаты = Запрос.ВыполнитьПакет();

	Сообщить("В ВТ_Заказано строк: " + Результаты[0].Выгрузить()[0].Количество);
	Сообщить("В ВТ_Поступило строк: " + Результаты[1].Выгрузить()[0].Количество);

	Выборка = Результаты[2].Выбрать();
```

2. Запустите.

Результаты запросов пакета лежат в массиве по порядку, с нуля. Результат запроса с `ПОМЕСТИТЬ` — одна строка с полем `Количество`: столько строк записано во временную таблицу.

3. Посчитайте руками, сколько строк должно быть во временной таблице заказанного: число разных пар «заявка — материал» в рабочих заявках. Сравните с выводом.
4. Временно отмените проведение одного из поступлений и запустите снова. Число строк в `ВТ_Поступило` уменьшится или останется прежним — объясните почему. Проведите документ обратно.

**Проверка:** выводится число строк каждой временной таблицы, и вы можете объяснить, откуда взялось каждое число.

## Шаг 4. Используйте промежуточный результат дважды

Второй вопрос: «Какие заявки обеспечены полностью?» Ответ строится на том же сопоставлении заказанного и поступившего.

1. Создайте процедуру `ВывестиОбеспеченныеЗаявки`. В начале создайте менеджер временных таблиц и назначьте его запросу:

```bsl
	МенеджерВТ = Новый МенеджерВременныхТаблиц;

	Запрос = Новый Запрос;
	Запрос.МенеджерВременныхТаблиц = МенеджерВТ;
```

2. Скопируйте в `Запрос.Текст` пакет из шага 1, но в третьем запросе пакета добавьте перед `ИЗ` строку `|ПОМЕСТИТЬ ВТ_Исполнение` и замените поле `ПРЕДСТАВЛЕНИЕ(Заказано.Материал) КАК Материал` на `Заказано.Материал КАК Материал`. Выполните запрос: `Запрос.Выполнить();`.
3. Ниже создайте второй запрос с тем же менеджером:

```bsl
	ЗапросОбеспеченных = Новый Запрос;
	ЗапросОбеспеченных.МенеджерВременныхТаблиц = МенеджерВТ;
	ЗапросОбеспеченных.Текст =
		"ВЫБРАТЬ
		|	Исполнение.Заявка КАК Заявка
		|ИЗ
		|	ВТ_Исполнение КАК Исполнение
		|СГРУППИРОВАТЬ ПО
		|	Исполнение.Заявка
		|ИМЕЮЩИЕ
		|	МАКСИМУМ(Исполнение.ОсталосьПолучить) <= 0";

	Выборка = ЗапросОбеспеченных.Выполнить().Выбрать();

	Пока Выборка.Следующий() Цикл
		Сообщить("Обеспечена полностью: " + Строка(Выборка.Заявка));
	КонецЦикла;
```

4. Вызовите процедуру из `Выполнить`, запустите.

Второй запрос не знает, как устроен первый: он читает готовую `ВТ_Исполнение`. Условие `ИМЕЮЩИЕ` оставляет заявки, у которых ни по одному материалу не осталось что получать.

5. Временно удалите строку `ЗапросОбеспеченных.МенеджерВременныхТаблиц = МенеджерВТ;` и запустите. Запрос завершится ошибкой: таблица `ВТ_Исполнение` не найдена. Верните строку.

**Проверка:** выведена заявка с двумя строками цемента. Заявки «ЖК Северный» в списке нет — песок по ней ещё не поступил, — нет и заявки без поступлений.

## Проверка результата

Занятие пройдено, если выполняются пять условий:

1. Процедура `ВывестиИсполнениеПакетом` выдаёт тот же ответ, что и вложенные запросы занятия 62.
2. В пакете три запроса: две временные таблицы с предварительной группировкой и итоговое соединение.
3. Через `ВыполнитьПакет` выводится число строк каждой временной таблицы.
4. Процедура `ВывестиОбеспеченныеЗаявки` строит второй ответ на временной таблице, созданной первым запросом, через общий менеджер.
5. Вы видели ошибку, когда второму запросу не назначен менеджер временных таблиц.
