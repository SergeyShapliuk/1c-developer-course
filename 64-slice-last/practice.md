# Практика. Цены всех строк одним запросом

## Перед началом

Запустите конфигуратор учебной конфигурации **«Управление строительной компанией с логистикой»**.

Понадобятся результаты занятия 41: периодический регистр сведений `ЦеныМатериалов` с ценами цемента `12,50` на `01.09.2026` и `13,10` на `01.10.2026`, кирпича `18,90` и песка `4,30` на сентябрь. Понадобится и форма документа `ЗаявкаНаМатериалы` с функцией `ЦенаМатериала` и командой **Пересчитать заявку** из занятия 34. Если цен в регистре нет, внесите их через форму списка регистра, как на занятии 41.

После каждой правки кода: `Ctrl+S`, затем `F5`.

## Шаг 1. Получите срез в консоли

Вопрос: «Какие цены действовали на заданную дату?» Ответ на него вы уже записывали в конспект на занятии 41 — теперь его даст запрос.

1. Откройте модуль формы обработки `УчебнаяКонсоль` и добавьте процедуру:

```bsl
&НаСервере
Процедура ВывестиЦеныНаДату(ДатаЦен)

	Запрос = Новый Запрос;
	Запрос.Текст =
		"ВЫБРАТЬ
		|	ПРЕДСТАВЛЕНИЕ(Цены.Материал) КАК Материал,
		|	Цены.Период КАК Период,
		|	Цены.Цена КАК Цена
		|ИЗ
		|	РегистрСведений.ЦеныМатериалов.СрезПоследних(&Дата, ) КАК Цены";

	Запрос.УстановитьПараметр("Дата", ДатаЦен);

	Результат = Запрос.Выполнить();

	Сообщить("Цены на " + Формат(ДатаЦен, "ДЛФ=D") + ":");

	Если Результат.Пустой() Тогда
		Сообщить("  цен нет");
		Возврат;
	КонецЕсли;

	Выборка = Результат.Выбрать();
	Пока Выборка.Следующий() Цикл
		Сообщить("  " + Выборка.Материал + ": " + Выборка.Цена + " (действует с " + Формат(Выборка.Период, "ДЛФ=D") + ")");
	КонецЦикла;

КонецПроцедуры
```

2. В процедуре `Выполнить` замените прежние вызовы тремя:

```bsl
	ВывестиЦеныНаДату('20260915');
	ВывестиЦеныНаДату('20261005');
	ВывестиЦеныНаДату('20260815');
```

3. Сохраните, запустите, нажмите **Выполнить** в «Учебной консоли».

Пустой второй параметр после запятой означает «условия нет»: в срез идут все материалы. `Формат` с `ДЛФ=D` выводит дату без времени. Поле `Период` в срезе — дата той записи, которая оказалась последней: по нему видно, с какого числа действует цена.

4. Сравните три ответа с тремя срезами, которые вы выписали в конспект на занятии 41.

**Проверка:** на 15 сентября цемент стоит `12,50`, на 5 октября — `13,10`, на 15 августа выведено «цен нет»; ответы совпадают с конспектом занятия 41.

## Шаг 2. Сравните условие в параметрах и в ГДЕ

Вопрос: «Какие материалы на 5 октября стоят дешевле 13?»

1. Добавьте процедуру `ВывестиДешёвыеМатериалы` с запросом к срезу на `05.10.2026` и условием на цену **в параметре** виртуальной таблицы:

```bsl
		|	РегистрСведений.ЦеныМатериалов.СрезПоследних(&Дата, Цена < 13) КАК Цены";
```

2. Запустите. Цемент попал в ответ с ценой `12,50`, хотя на 5 октября он стоит `13,10`.
3. Перенесите условие в `ГДЕ`:

```bsl
		|	РегистрСведений.ЦеныМатериалов.СрезПоследних(&Дата, ) КАК Цены
		|ГДЕ
		|	Цены.Цена < 13";
```

4. Запустите. Цемента в ответе нет — верно.

Запишите в конспект, что сделало условие в параметрах: оно выбросило октябрьскую запись **до** построения среза, и последней для цемента стала сентябрьская.

**Проверка:** при условии в параметрах цемент выводится по устаревшей цене, при условии в `ГДЕ` — не выводится.

## Шаг 3. Закройте долг консоли

На занятии 41 функция `ПолучитьМатериалыМассивом` стала читать цену каждого материала отдельным вызовом `ПолучитьПоследнее` внутри цикла. Перепишем её одним запросом.

1. Найдите в модуле формы `УчебнаяКонсоль` функцию `ПолучитьМатериалыМассивом` и замените её целиком:

```bsl
&НаСервереБезКонтекста
Функция ПолучитьМатериалыМассивом()

	Запрос = Новый Запрос;
	Запрос.Текст =
		"ВЫБРАТЬ
		|	Товары.Наименование КАК Наименование,
		|	ЕСТЬNULL(Цены.Цена, 0) КАК Цена
		|ИЗ
		|	Справочник.Товары КАК Товары
		|		ЛЕВОЕ СОЕДИНЕНИЕ РегистрСведений.ЦеныМатериалов.СрезПоследних(&Дата, ) КАК Цены
		|		ПО Цены.Материал = Товары.Ссылка
		|ГДЕ
		|	НЕ Товары.ПометкаУдаления
		|УПОРЯДОЧИТЬ ПО
		|	Цена УБЫВ";

	Запрос.УстановитьПараметр("Дата", ТекущаяДата());

	Результат = Новый Массив;

	Выборка = Запрос.Выполнить().Выбрать();
	Пока Выборка.Следующий() Цикл
		Результат.Добавить(Новый Структура("Наименование, Цена", Выборка.Наименование, Выборка.Цена));
	КонецЦикла;

	Возврат Результат;

КонецФункции
```

2. Временно верните в процедуру `Выполнить` вывод из занятия 22: цикл по `ПолучитьМатериалыМассивом()` с `УчебныеФункцииКлиент.ОформитьСообщение`.
3. Запустите.

Сравните с прежней версией. Пропал цикл по справочнику с проверкой пометки удаления — это условие `ГДЕ`. Пропала таблица значений с сортировкой — это `УПОРЯДОЧИТЬ ПО`. Пропали отдельные обращения за ценой — это соединение со срезом. Осталось то, что действительно нужно встроенному языку: переложить ответ в массив структур, который можно вернуть клиенту, как на занятии 22.

**Проверка:** материалы выводятся по убыванию текущей цены, материал без цены — с нулём в конце списка.

## Шаг 4. Добавьте команду «Заполнить цены» в форму заявки

1. Откройте **Документы → ЗаявкаНаМатериалы → Формы**, форму документа, вкладку **Команды**, подвкладку **Команды формы**.
2. Нажмите **Добавить**. Задайте **Имя** — `ЗаполнитьЦены`, **Заголовок** — `Заполнить цены`.
3. Нажмите лупу у свойства **Действие**. Платформа создаст клиентский обработчик `ЗаполнитьЦены`.
4. Перетащите команду в командную панель формы рядом с кнопкой **Пересчитать заявку**.
5. Перейдите на вкладку **Модуль** и добавьте серверную процедуру:

```bsl
&НаСервере
Процедура ЗаполнитьЦеныНаСервере()

	Материалы = Новый Массив;
	Для Каждого СтрокаМатериала Из Объект.Материалы Цикл
		Материалы.Добавить(СтрокаМатериала.Материал);
	КонецЦикла;

	Запрос = Новый Запрос;
	Запрос.Текст =
		"ВЫБРАТЬ
		|	Цены.Материал КАК Материал,
		|	Цены.Цена КАК Цена
		|ИЗ
		|	РегистрСведений.ЦеныМатериалов.СрезПоследних(&Дата, Материал В (&Материалы)) КАК Цены";

	Запрос.УстановитьПараметр("Дата", ?(ЗначениеЗаполнено(Объект.Дата), Объект.Дата, ТекущаяДата()));
	Запрос.УстановитьПараметр("Материалы", Материалы);

	Цены = Новый Соответствие;
	Выборка = Запрос.Выполнить().Выбрать();
	Пока Выборка.Следующий() Цикл
		Цены.Вставить(Выборка.Материал, Выборка.Цена);
	КонецЦикла;

	Для Каждого СтрокаМатериала Из Объект.Материалы Цикл

		Цена = Цены.Получить(СтрокаМатериала.Материал);

		Если Цена = Неопределено Тогда
			Сообщить("Строка " + СтрокаМатериала.НомерСтроки + ": нет цены материала «"
				+ СтрокаМатериала.Материал + "» на дату заявки");
			Цена = 0;
		КонецЕсли;

		СтрокаМатериала.Цена = Цена;
		СтрокаМатериала.Сумма = УчебныеФункции.РассчитатьСумму(СтрокаМатериала.Количество, СтрокаМатериала.Цена);

	КонецЦикла;

КонецПроцедуры
```

6. Заполните клиентский обработчик:

```bsl
&НаКлиенте
Процедура ЗаполнитьЦены(Команда)

	ЗаполнитьЦеныНаСервере();
	ПересчитатьИтогПоЗаявке();

КонецПроцедуры
```

Разберём решения. Условие на материалы стоит в параметре среза, потому что это измерение: платформа не строит срез по материалам, которых нет в заявке. Ответ запроса складывается в `Соответствие` из занятия 17 — так цена каждой строки находится по материалу без повторного обхода выборки. Отсутствие цены видно по `Неопределено` из соответствия, и пользователь получает сообщение с номером строки вместо молчаливого нуля — ответ на вопрос, который вы записали в конспект на шаге 7 занятия 41.

Директива `&НаСервере`, а не `&НаСервереБезКонтекста`: процедура читает и меняет `Объект.Материалы`. Сумма считается той же функцией `УчебныеФункции.РассчитатьСумму`, что и в занятии 32, а итог по заявке — клиентской процедурой `ПересчитатьИтогПоЗаявке` из того же занятия.

**Проверка:** синтаксический контроль проходит, в командной панели формы заявки есть кнопка **Заполнить цены**.

## Шаг 5. Проверьте команду в приложении

1. Запустите приложение и откройте заявку от `25.09.2026` из занятия 41, где цемент стоит по `12,50`. Если вы её не записали, создайте заявку с датой `25.09.2026` на «ЖК Северный» со строками «Цемент М500» — `20` и «Песок речной» — `5` и запишите её.
2. Измените дату заявки на `05.10.2026` и нажмите **Заполнить цены**. Цена цемента стала `13,10`, сумма строки и итог по заявке пересчитаны.
3. Верните дату `25.09.2026` и нажмите кнопку ещё раз — цена вернулась к `12,50`.
4. Поставьте дату `15.08.2026` и нажмите кнопку. По каждой строке пришло сообщение об отсутствии цены, цены стали нулевыми.
5. Закройте заявку без записи.

**Проверка:** команда заполняет цены всех строк на дату заявки и сообщает о строках, для которых цены нет.

## Проверка результата

Занятие пройдено, если выполняются пять условий:

1. Процедура `ВывестиЦеныНаДату` получает срез последних на три даты, и ответы совпадают с конспектом занятия 41.
2. Вы показали разницу между условием на цену в параметрах среза и в `ГДЕ`.
3. Функция `ПолучитьМатериалыМассивом` получает цены всех материалов одним запросом с левым соединением со срезом.
4. Команда **Заполнить цены** формы заявки заполняет цены одним запросом с условием на материалы в параметрах среза.
5. При отсутствии цены пользователь получает сообщение с номером строки.
