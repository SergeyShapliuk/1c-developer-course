# Занятие 64. Виртуальная таблица среза последних

## Цель

Понять, что такое виртуальная таблица регистра и чем её параметры отличаются от условия `ГДЕ`. Получить цены всех материалов на дату одним запросом к срезу последних регистра `ЦеныМатериалов` и закрыть долг занятия 41: цены перестают читаться по одной строке.

## Результат занятия

В форме документа `ЗаявкаНаМатериалы` появится команда **Заполнить цены**: она одним запросом к срезу последних получает цены всех материалов заявки на её дату, проставляет их в строки, пересчитывает суммы и сообщает о материалах без цены. Функция `ПолучитьМатериалыМассивом` обработки `УчебнаяКонсоль` получит цены всех материалов одним запросом вместо вызова `ПолучитьПоследнее` в цикле.
