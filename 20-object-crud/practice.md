# Практика. Создаём и меняем элементы справочника

## Перед началом

Запустите конфигуратор учебной конфигурации **«Управление строительной компанией с логистикой»**.

В дереве конфигурации откройте обработку `УчебнаяКонсоль` (синоним «Учебная консоль»), затем её форму, а в редакторе формы — вкладку **Модуль**. Работаем в процедуре `Выполнить` и в серверных процедурах и функциях рядом с ней.

После каждой правки кода:

1. Сохраните конфигурацию — `Ctrl+S`.
2. Запустите приложение — `F5`.
3. В разделе **Разработка** откройте «Учебную консоль».
4. Нажмите кнопку **Выполнить** и прочитайте сообщения.

На этом занятии код **меняет данные в базе**. Это нормально: база учебная. Но держите открытым список товаров в режиме «1С:Предприятие» — результат будем проверять именно там, через **Продажи → Товары**.

Весь код — серверный, как и на занятии 19: менеджеры справочников на клиенте недоступны.

## Шаг 1. Функция «создать, если нет»

Напишем функцию, которая сначала ищет товар и создаёт его только при отсутствии.

> Имя функции и её параметры важны: ровно `СоздатьТоварЕслиНет(Наименование, Артикул, Цена)`. Эту функцию мы переиспользуем на занятии 25, поэтому не переименовывайте её.

```bsl
&НаКлиенте
Процедура Выполнить(Команда)
	
	СоздатьТоварЕслиНет("Кирпич облицовочный", "KR-001", 18.90);
	
КонецПроцедуры

&НаСервере
Функция СоздатьТоварЕслиНет(Наименование, Артикул, Цена)
	
	// Сначала ищем. Если элемент есть — создавать нельзя,
	// иначе повторный запуск наплодит дубли.
	Товар = Справочники.Товары.НайтиПоНаименованию(Наименование);
	
	Если НЕ Товар.ПустаяСсылка() Тогда
		Сообщить("Найден существующий элемент: " + Наименование);
		Возврат Товар;
	КонецЕсли;
	
	// СоздатьЭлемент() даёт объект в памяти. В базе его пока нет.
	НовыйТовар = Справочники.Товары.СоздатьЭлемент();
	НовыйТовар.Наименование = Наименование;
	НовыйТовар.Артикул = Артикул;
	НовыйТовар.Цена = Цена;
	НовыйТовар.ЕдиницаИзмерения = "шт.";
	
	// Вот здесь элемент появляется в базе
	НовыйТовар.Записать();
	
	Сообщить("Создан элемент: " + Наименование + ", код " + НовыйТовар.Код);
	
	Возврат НовыйТовар.Ссылка;
	
КонецФункции
```

Сохраните, запустите, нажмите **Выполнить**. Если «Кирпича облицовочного» в справочнике не было, выведется сообщение о создании с присвоенным кодом.

**Проверка:** в сообщениях видно, создан элемент или найден существующий.

## Шаг 2. Проверка идемпотентности

Теперь вызовем ту же функцию дважды подряд.

```bsl
&НаКлиенте
Процедура Выполнить(Команда)
	
	СоздатьТоварЕслиНет("Кирпич облицовочный", "KR-001", 18.90);
	СоздатьТоварЕслиНет("Кирпич облицовочный", "KR-001", 18.90);
	
КонецПроцедуры
```

Сохраните, запустите, нажмите **Выполнить**. Во второй раз выведется «Найден существующий элемент» — функция ничего не создала.

Проверьте результат в приложении: откройте **Продажи → Товары**. «Кирпич облицовочный» в списке ровно один. Нажмите **Выполнить** ещё несколько раз и обновите список — второй «Кирпич» не появится.

Это и есть идемпотентность: сколько раз ни запусти, состояние базы одно и то же.

**Проверка:** в списке товаров ровно один «Кирпич облицовочный», сколько бы раз вы ни нажали кнопку.

## Шаг 3. Изменение: поднять цену

Изменим реквизит существующего элемента.

```bsl
&НаСервере
Процедура ПоднятьЦенуЦемента()
	
	Товар = Справочники.Товары.НайтиПоНаименованию("Цемент М500");
	
	Если Товар.ПустаяСсылка() Тогда
		Сообщить("Цемент М500 не найден");
		Возврат;
	КонецЕсли;
	
	// Через ссылку записать нельзя — нужен объект
	Объект = Товар.ПолучитьОбъект();
	
	СтараяЦена = Объект.Цена;
	Объект.Цена = Объект.Цена * 1.1; // плюс 10 процентов
	Объект.Записать();
	
	Сообщить("Цена была: " + Строка(СтараяЦена));
	Сообщить("Цена стала: " + Строка(Объект.Цена));
	
КонецПроцедуры
```

Вызовите процедуру из `Выполнить` и запустите. Цена `12,5` превратится в `13,75`.

Не нажимайте кнопку много раз подряд: цена будет расти при каждом нажатии. Этот код намеренно **не** идемпотентен — он выполняет действие, а не приводит данные к заданному состоянию. Разница между такими задачами важна: «поднять на 10 процентов» и «установить цену 13,75» ведут себя при повторном запуске совершенно по-разному.

**Проверка:** выведены старая и новая цена, и в списке товаров цена цемента изменилась.

## Шаг 4. Запись только при изменении

Теперь задача, где перебираются все товары, а записывать нужно единицы.

```bsl
&НаСервере
Процедура ЗаполнитьПустыеЕдиницы()
	
	Выборка = Справочники.Товары.Выбрать();
	Изменено = 0;
	Проверено = 0;
	
	Пока Выборка.Следующий() Цикл
		
		Проверено = Проверено + 1;
		
		// Если реквизит заполнен — ничего не делаем и объект не получаем.
		// Запись дорогая, и лишние записи ни к чему.
		Если ЗначениеЗаполнено(Выборка.ЕдиницаИзмерения) Тогда
			Продолжить;
		КонецЕсли;
		
		Объект = Выборка.Ссылка.ПолучитьОбъект();
		Объект.ЕдиницаИзмерения = "шт.";
		Объект.Записать();
		
		Изменено = Изменено + 1;
		Сообщить("Заполнена единица у: " + Выборка.Наименование);
		
	КонецЦикла;
	
	Сообщить("Проверено элементов: " + Строка(Проверено));
	Сообщить("Изменено элементов: " + Строка(Изменено));
	
КонецПроцедуры
```

Здесь пригодился оператор `Продолжить` из занятия 14: он переходит к следующему элементу, не выполняя остаток тела цикла.

Вызовите процедуру из `Выполнить` и запустите. Затем нажмите **Выполнить** второй раз: проверенных элементов будет столько же, а изменённых — ноль. Все единицы уже заполнены, и записывать нечего.

**Проверка:** при повторном запуске счётчик изменённых равен нулю.

## Шаг 5. Пометка удаления

Создадим тестовый элемент и пометим его на удаление.

```bsl
&НаСервере
Процедура ПометитьТестовыйМатериал()
	
	// Переиспользуем функцию из шага 1
	Товар = СоздатьТоварЕслиНет("Тестовый материал", "TEST-001", 1.00);
	
	Объект = Товар.ПолучитьОбъект();
	
	// Метод сам записывает объект, отдельный Записать() не нужен
	Объект.УстановитьПометкуУдаления(Истина);
	
	Сообщить("Элемент «Тестовый материал» помечен на удаление");
	
КонецПроцедуры
```

Вызовите процедуру из `Выполнить` и запустите.

Теперь откройте **Продажи → Товары**. «Тестовый материал» в списке есть, но его строка **перечёркнута** — это и есть пометка удаления. Элемент никуда не исчез: на него могли бы ссылаться другие данные, и платформа не рискует.

Удалять его сейчас не нужно. Если захотите убрать, это делается не кодом, а обработкой **Все функции → Стандартные → Удаление помеченных объектов**, которая сначала проверит ссылки.

**Проверка:** в списке товаров «Тестовый материал» отображается перечёркнутым.

## Шаг 6. Итоговая проверка в приложении

Откройте **Продажи → Товары** и пройдите по списку глазами:

1. «Кирпич облицовочный» присутствует ровно один раз.
2. У «Цемента М500» цена отличается от исходных `12,50` — её изменил код.
3. У всех товаров заполнена единица измерения.
4. «Тестовый материал» перечёркнут.

Откройте карточку «Кирпича облицовочного» двойным щелчком и убедитесь, что артикул, цена и единица измерения заполнены теми значениями, которые передавались в функцию.

**Проверка:** все четыре пункта выполняются.

## Проверка результата

Занятие пройдено, если выполняются пять условий:

1. В модуле формы есть функция `СоздатьТоварЕслиНет(Наименование, Артикул, Цена)` ровно с таким именем и параметрами.
2. Повторные нажатия кнопки не создают дублей товара.
3. Цена цемента изменена через `ПолучитьОбъект()` и `Записать()`.
4. Процедура заполнения единиц при повторном запуске показывает ноль изменённых элементов.
5. «Тестовый материал» помечен на удаление и отображается перечёркнутым.
