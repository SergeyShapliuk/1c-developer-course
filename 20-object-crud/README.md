# Занятие 20. Создание, поиск, чтение, изменение и запись объектов

## Цель

Научиться изменять данные справочников из кода: создавать элементы, менять реквизиты, записывать изменения и помечать элементы на удаление, не создавая дублей.

## Результат занятия

В модуле формы обработки `УчебнаяКонсоль` появится функция `СоздатьТоварЕслиНет`, которую можно запускать повторно без появления копий. Вы поднимете цену цемента, заполните пустую единицу измерения только там, где её нет, и пометите тестовый элемент на удаление. Эту функцию мы переиспользуем на занятии 25.

## Маршрут

1. Прочитайте [теорию](theory.md) — около 25 минут.
2. Выполните [практику](practice.md) — около 70 минут.
3. Ответьте на контрольные вопросы в конце практики, не подглядывая в теорию.

## Ключевые термины

`СоздатьЭлемент`, `Записать`, `ПолучитьОбъект`, пометка удаления, `УстановитьПометкуУдаления`, непосредственное удаление, идемпотентность, цена операции записи.
