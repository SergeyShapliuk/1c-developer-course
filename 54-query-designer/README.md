# Занятие 54. Текст запроса и конструктор запроса

## Цель

Научиться читать и писать текст запроса: список полей, источник, псевдонимы. Освоить конструктор запроса, который собирает текст и код обработки результата без ручного набора, и понять, почему ошибку в тексте запроса платформа находит только при выполнении.

## Результат занятия

В обработке `УчебнаяКонсоль` появится процедура, собранная конструктором запроса с обработкой результата: она выводит все строки табличной части `Материалы` всех заявок — заявку, номер строки, материал и количество. Вы научитесь открывать конструктор на уже написанном тексте и дорабатывать запрос в нём.

## Маршрут

1. Прочитайте [теорию](theory.md) — около 25 минут.
2. Выполните [практику](practice.md) — около 45 минут.
3. Ответьте на контрольные вопросы в конце практики, не подглядывая в теорию.

## Ключевые термины

Текст запроса, `ВЫБРАТЬ`, `ИЗ`, поле запроса, источник, псевдоним, `КАК`, табличная часть как таблица запроса, поле `Ссылка`, поле `НомерСтроки`, конструктор запроса, конструктор запроса с обработкой результата.
