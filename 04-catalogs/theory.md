# Теория. Справочники и реквизиты

## Когда нужен справочник

Справочник подходит для повторяющихся, относительно постоянных сущностей: клиентов, товаров, сотрудников, складов. Вместо того чтобы каждый раз вводить название клиента вручную, документ позднее будет хранить ссылку на один элемент справочника.

## Стандартные поля

У большинства справочников 1С уже есть стандартные поля **Код** и **Наименование**. Наименование — главный понятный пользователю заголовок элемента. Не создавайте дополнительный реквизит «Название», пока стандартного наименования достаточно.

## Реквизит и тип данных

Реквизит добавляет одно свойство к каждому элементу справочника. Тип выбирают по тому, какие данные будут храниться:

- `Строка` — текст, артикул, телефон, комментарий;
- `Число` — значение, с которым выполняют арифметические операции;
- `Дата` — календарная дата и время;
- `Булево` — ответ «да» или «нет»;
- ссылка на справочник — выбор ранее созданного элемента.

Тип нужно определить до ввода рабочих данных. Изменение типа в заполненной базе может потребовать преобразования данных.

## Формы по умолчанию

Если отдельную форму не создавали, 1С может сгенерировать форму списка и форму элемента автоматически. Поэтому после добавления реквизита и обновления базы новое поле часто появляется в карточке элемента. Видимость и расположение формы можно будет настраивать позднее.
