# День 4. Справочники и их реквизиты

## Цель

Закрепить устройство справочника и научиться улучшать структуру данных без создания лишних полей.

## Результат дня

Справочник «Клиенты» получит реквизит «Комментарий», а справочник «Товары» — реквизит «Единица измерения». Вы проверите, как новые поля появляются в форме элемента.

## Маршрут

1. Прочитайте [теорию](theory.md).
2. Выполните [практику](practice.md).
3. Ответьте на контрольные вопросы в конце практики.
