# День 2. Конфигуратор и первые объекты

## Цель

Освоить работу с деревом конфигурации и создать первые объекты метаданных проекта «Управление строительной компанией».

## Результат дня

В конфигурации появятся понятное имя и синоним, а также три первых справочника: «Клиенты», «Товары» и «Сотрудники». Вы научитесь открывать свойства объекта, различать имя и синоним, обновлять конфигурацию базы данных.

## Маршрут

1. Прочитайте [теорию](theory.md) — около 25 минут.
2. Выполните [практику](practice.md) — около 60 минут.
3. Запустите приложение и проверьте результат.

## Ключевые термины

Конфигуратор, свойства объекта, имя, синоним, справочник, реквизит, подсистема, обновление конфигурации базы данных.
