# Практика. Остатки из передачи и период по умолчанию

## Перед началом

Запустите конфигуратор учебной конфигурации **«Управление строительной компанией с логистикой»**.

Понадобятся форма документа `ПередачаМатериалов` из занятия 50, отчёт `ОстаткиНаСкладах` с быстрым отбором по складу из занятий 72–78 и отчёт `ОборотнаяВедомостьМатериалов` с параметром «Период» из занятия 75.

После каждой правки: `Ctrl+S`, затем `F5` и проверка в приложении, как описано в шаге.

## Шаг 1. Решите, где будет код

Прежде чем писать код, запишите в конспект две строки — по одной на каждую просьбу из теории:

1. «Остатки склада из передачи»: какой модуль, клиент или сервер, нужен ли серверный вызов.
2. «Нет периода — текущий месяц»: какой модуль, клиент или сервер, и почему не форма отчёта.

Сверьтесь с таблицей «Где живёт код отчёта» в теории. Если ваш ответ отличается — запишите, чем, и почему ответ теории точнее.

**Проверка:** в конспекте для каждой просьбы указаны модуль и сторона выполнения с одной фразой обоснования.

## Шаг 2. Добавьте команду в форму передачи

1. В дереве конфигурации раскройте **Документы → ПередачаМатериалов → Формы** и откройте форму документа.
2. Перейдите на вкладку **Команды**, подвкладку **Команды формы**, и нажмите **Добавить**.
3. Задайте **Имя** — `ОстаткиСклада`, **Заголовок** — «Остатки склада».
4. Нажмите лупу у свойства **Действие**: платформа создаст обработчик `ОстаткиСклада` с директивой `&НаКлиенте`.
5. Перетащите команду в дерево элементов, в группу **Форма.КоманднаяПанель**, — как на занятии 34.

**Проверка:** на командной панели формы передачи есть кнопка **Остатки склада**, в модуле формы — пустой клиентский обработчик.

## Шаг 3. Откройте отчёт с отбором

Заполните обработчик:

```bsl
&НаКлиенте
Процедура ОстаткиСклада(Команда)

	Если Не ЗначениеЗаполнено(Объект.Склад) Тогда
		Сообщить("Сначала выберите склад передачи");
		Возврат;
	КонецЕсли;

	ПараметрыФормы = Новый Структура;
	ПараметрыФормы.Вставить("Отбор", Новый Структура("Склад", Объект.Склад));
	ПараметрыФормы.Вставить("СформироватьПриОткрытии", Истина);

	ОткрытьФорму("Отчет.ОстаткиНаСкладах.Форма", ПараметрыФормы, ЭтаФорма);

КонецПроцедуры
```

В обработчике нет ни одного обращения к базе и ни одного серверного вызова. Склад уже лежит в данных формы, а остатки посчитает сам отчёт — на сервере, во время формирования. Третий параметр `ЭтаФорма` — владелец: отчёт открывается как окно, вызванное из этой передачи.

**Проверка:** обработчик заполнен, синтаксический контроль ошибок не находит.

## Шаг 4. Проверьте команду

1. Сохраните и запустите. Откройте **Логистика → Передачи материалов** и создайте новую передачу.
2. Не выбирая склад, нажмите **Остатки склада**. Появится сообщение «Сначала выберите склад передачи», отчёт не откроется.
3. Выберите «Центральный склад» и нажмите **Остатки склада**. Откроется отчёт, уже сформированный, только по «Центральному складу».
4. Сверьте остатки с отчётом, открытым из раздела **Логистика** с ручным выбором того же склада: числа те же.
5. Закройте отчёт и передачу без записи.
6. Откройте **Остатки на складах** из раздела **Логистика**. Посмотрите на поле склада: в нём сохранён прежний выбор пользователя, а не склад из передачи. Отбор, переданный параметром, действовал только в одном открытии.

**Проверка:** из передачи с заполненным складом отчёт открывается сформированным с отбором по этому складу; без склада — сообщение; сохранённые настройки пользователя не изменились.

## Шаг 5. Найдите проблему пустого периода

1. Откройте **Логистика → Отчеты → Оборотная ведомость материалов**.
2. Снимите флажок у поля «Период» и сформируйте.
3. Посмотрите на начальный остаток: он нулевой у всех материалов, а приход и расход собраны за всю историю. Это не ведомость за месяц, а оборот за всё время.
4. Запишите в конспект, почему так получилось: параметры `НачалоПериода` и `КонецПериода` получили пустые даты.

**Проверка:** вы увидели ведомость за всю историю при пустом периоде и записали причину.

## Шаг 6. Напишите ПриКомпоновкеРезультата

1. Откройте отчёт `ОборотнаяВедомостьМатериалов`, вкладку **Прочее**, **Модуль объекта**.
2. Добавьте код:

```bsl
Процедура ПриКомпоновкеРезультата(ДокументРезультат, ДанныеРасшифровки, СтандартнаяОбработка)

	СтандартнаяОбработка = Ложь;

	Настройки = КомпоновщикНастроек.ПолучитьНастройки();
	УстановитьПериодПоУмолчанию(Настройки);

	КомпоновщикМакета = Новый КомпоновщикМакетаКомпоновкиДанных;
	МакетКомпоновки = КомпоновщикМакета.Выполнить(СхемаКомпоновкиДанных, Настройки, ДанныеРасшифровки);

	ПроцессорКомпоновки = Новый ПроцессорКомпоновкиДанных;
	ПроцессорКомпоновки.Инициализировать(МакетКомпоновки, , ДанныеРасшифровки);

	ДокументРезультат.Очистить();

	ПроцессорВывода = Новый ПроцессорВыводаРезультатаКомпоновкиДанныхВТабличныйДокумент;
	ПроцессорВывода.УстановитьДокумент(ДокументРезультат);
	ПроцессорВывода.Вывести(ПроцессорКомпоновки);

КонецПроцедуры

// Если пользователь не выбрал период, подставляет в настройки текущий месяц.
Процедура УстановитьПериодПоУмолчанию(Настройки)

	ЗначениеПериода = Настройки.ПараметрыДанных.НайтиЗначениеПараметра(
		Новый ПараметрКомпоновкиДанных("ПериодОтчета"));

	Если ЗначениеПериода = Неопределено Тогда
		Возврат;
	КонецЕсли;

	Если ЗначениеПериода.Использование
		И ЗначениеЗаполнено(ЗначениеПериода.Значение.ДатаНачала) Тогда
		Возврат;
	КонецЕсли;

	ЗначениеПериода.Значение = Новый СтандартныйПериод(ВариантСтандартногоПериода.ЭтотМесяц);
	ЗначениеПериода.Использование = Истина;

КонецПроцедуры
```

Прочитайте код по схеме из теории. Первая половина обработчика — настройки: копия, в которой подставлен период. Вторая — та же цепочка, что выполняла платформа: компоновщик макета строит план, процессор компоновки его исполняет, процессор вывода выводит результат на лист `ДокументРезультат`.

Правило о периоде вынесено в отдельную процедуру. Обработчик события остаётся описанием цепочки компоновки, а правило читается само по себе — и при следующем таком правиле рядом появится ещё одна процедура, а не ещё один блок условий в обработчике.

Условие `ЗначениеПериода = Неопределено` защищает от случая, когда параметра с таким именем в настройках нет — например, если его переименуют в схеме. Без него обращение к `ЗначениеПериода.Использование` завершилось бы ошибкой.

**Проверка:** в модуле отчёта есть обработчик `ПриКомпоновкеРезультата` и процедура `УстановитьПериодПоУмолчанию`, синтаксический контроль ошибок не находит.

## Шаг 7. Проверьте период по умолчанию

1. Сохраните и запустите. Откройте оборотную ведомость, снимите флажок «Период» и сформируйте.
2. Теперь начальные остатки не нулевые, а обороты — только за текущий месяц.
3. Отметьте флажок, выберите вариант «Этот месяц» и сформируйте. Числа совпадают с шагом 2.
4. Выберите октябрь 2026 года и сформируйте: ведомость за октябрь, как на занятии 75. Код не вмешался: период был задан.
5. Снова снимите флажок и сформируйте. Откройте окно **Настройки**: флажок «Период» по-прежнему снят. Код поменял копию настроек, а не выбор пользователя.

**Проверка:** без периода ведомость строится за текущий месяц, с периодом — за выбранный, сохранённый выбор пользователя не меняется.

## Шаг 8. Убедитесь, что ничего не потеряно

1. Нажмите **Сформировать** три раза подряд. Отчёт выведен один раз, а не три друг под другом: результат очищается перед выводом.
2. Временно добавьте в схеме вложенную группировку `Регистратор` под `Материал`, сформируйте ведомость за октябрь и дважды щёлкните по документу. Он открывается: данные расшифровки переданы и компоновщику макета, и процессору компоновки. Удалите группировку `Регистратор`.

**Проверка:** повторное формирование не дублирует отчёт, расшифровка до документа работает.

## Проверка результата

Занятие пройдено, если выполняются шесть условий:

1. В форме `ПередачаМатериалов` есть команда **Остатки склада** с клиентским обработчиком без серверных вызовов.
2. Команда открывает `ОстаткиНаСкладах` сформированным, с отбором по складу передачи; без склада выводится сообщение.
3. После открытия из передачи сохранённые настройки отчёта у пользователя не изменились.
4. В модуле отчёта `ОборотнаяВедомостьМатериалов` есть `ПриКомпоновкеРезультата` с цепочкой «компоновщик макета → процессор компоновки → процессор вывода» и процедура `УстановитьПериодПоУмолчанию`.
5. Без выбранного периода ведомость строится за текущий месяц, с выбранным — за выбранный.
6. Повторное формирование не дублирует результат, расшифровка работает.
