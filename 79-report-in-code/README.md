# Занятие 79. Отчёт из кода: открытие с отбором и ПриКомпоновкеРезультата

## Цель

Понять, когда отчёту нужен код и где этот код должен жить. Научиться открывать отчёт из формы документа сразу с нужным отбором и сформированным результатом, увидеть, из каких объектов платформы состоит компоновка отчёта, и в обработчике `ПриКомпоновкеРезультата` задать правило, которое схема выразить не может, — не отнимая у платформы построение отчёта.

## Результат занятия

В форме документа `ПередачаМатериалов` появится команда **Остатки склада**: она открывает отчёт `ОстаткиНаСкладах` с отбором по складу передачи и сразу его формирует. Ведомость `ОборотнаяВедомостьМатериалов` будет открываться за текущий месяц благодаря значению параметра в схеме, без кода. В модуле отчёта появится обработчик `ПриКомпоновкеРезультата`: без периода или с периодом длиннее года ведомость не строится, а пользователь получает сообщение с причиной. С правильным периодом отчёт строит платформа, и расшифровка до документа продолжает работать.

## Ключевые термины

`ОткрытьФорму`, параметры формы отчёта, `Отбор`, `СформироватьПриОткрытии`, модуль отчёта, `ПриКомпоновкеРезультата`, стандартная обработка, `СтандартнаяОбработка`, `КомпоновщикНастроек`, `ПолучитьНастройки`, `ПараметрКомпоновкиДанных`, `КомпоновщикМакетаКомпоновкиДанных`, макет компоновки, `ПроцессорКомпоновкиДанных`, `ПроцессорВыводаРезультатаКомпоновкиДанныхВТабличныйДокумент`, данные расшифровки, значение параметра по умолчанию, `СтандартныйПериод`, `ДобавитьМесяц`.
