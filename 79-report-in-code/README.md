# Занятие 79. Отчёт из кода: открытие с отбором и ПриКомпоновкеРезультата

## Цель

Понять, когда отчёту нужен код и где этот код должен жить. Научиться открывать отчёт из формы документа сразу с нужным отбором и сформированным результатом, увидеть, из каких объектов платформы состоит компоновка отчёта, и выполнить её самостоятельно в обработчике `ПриКомпоновкеРезультата`, чтобы задать правило, которое схема выразить не может.

## Результат занятия

В форме документа `ПередачаМатериалов` появится команда **Остатки склада**: она открывает отчёт `ОстаткиНаСкладах` с отбором по складу передачи и сразу его формирует. В модуле отчёта `ОборотнаяВедомостьМатериалов` появится обработчик `ПриКомпоновкеРезультата`: если пользователь не выбрал период, ведомость строится за текущий месяц, а сохранённые настройки пользователя при этом не меняются. Расшифровка до документа продолжает работать.

## Ключевые термины

`ОткрытьФорму`, параметры формы отчёта, `Отбор`, `СформироватьПриОткрытии`, модуль отчёта, `ПриКомпоновкеРезультата`, `СтандартнаяОбработка`, `КомпоновщикНастроек`, `ПолучитьНастройки`, `ПараметрКомпоновкиДанных`, `КомпоновщикМакетаКомпоновкиДанных`, макет компоновки, `ПроцессорКомпоновкиДанных`, `ПроцессорВыводаРезультатаКомпоновкиДанныхВТабличныйДокумент`, данные расшифровки, `СтандартныйПериод`.
