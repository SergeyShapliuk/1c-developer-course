# Занятие 36. Ввод на основании

## Цель

Освоить механизм ввода на основании: понять, зачем платформа умеет создавать один документ из другого, какие данные при этом переносят, а какие нет, и где живёт код переноса.

## Результат занятия

В конфигурации появится второй документ учебного проекта — `ПоступлениеМатериалов` с реквизитами `Поставщик`, `Склад`, `Ответственный` и табличной частью `Материалы` того же состава, что у заявки из занятия 31. Из формы согласованной заявки по команде **Создать на основании** будет открываться поступление с уже перенесённым списком материалов, а в модуле объекта появится обработчик `ОбработкаЗаполнения`.

## Маршрут

1. Прочитайте [теорию](theory.md) — около 25 минут.
2. Выполните [практику](practice.md) — около 60 минут.
3. Ответьте на контрольные вопросы в конце практики, не подглядывая в теорию.

## Ключевые термины

Ввод на основании, документ-основание, источник, приёмник, `ОбработкаЗаполнения`, `ДанныеЗаполнения`, `ТекстЗаполнения`, `СтандартнаяОбработка`, свойство **Вводится на основании**, `ПолучитьОбъект()`, `ТипЗнач()`.
