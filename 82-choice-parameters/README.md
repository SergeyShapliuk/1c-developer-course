# Занятие 82. Параметры выбора

## Цель

Закрыть технический долг занятия 36: научить поле «Поставщик» предлагать только поставщиков, а не всех контрагентов. Понять, что такое параметры выбора, почему их задают у реквизита объекта, а не у элемента одной формы, и почему ограничение выбора не заменяет проверку данных при записи.

## Результат занятия

В поступлении материалов поле «Поставщик» будет предлагать только клиентов с видом «Поставщик» — и в списке выбора, и при вводе наименования с клавиатуры. Ограничение задано у реквизита документа, поэтому работает в любой форме. Модуль объекта поступления в `ПередЗаписью` откажет в записи документа с непоставщиком, даже если документ записывают из кода.
