# Практика. Форма, которая считает сама

## Перед началом

Запустите конфигуратор учебной конфигурации **«Управление строительной компанией с логистикой»**.

Откройте **Обработки → УчебнаяКонсоль**, раскройте её **Формы** и откройте форму. Понадобятся обе её части: вкладка **Реквизиты** и дерево элементов — для полей и команд, вкладка **Модуль** — для кода. Понадобится также общий модуль `УчебныеФункции` с экспортной функцией `РассчитатьСумму` с занятия 21.

После каждой правки: `Ctrl+S`, затем `F5` — платформа предложит обновить конфигурацию базы данных, согласитесь. В запущенном приложении откройте раздел **Разработка** и выберите обработку **Учебная консоль**.

## Шаг 1. Добавьте реквизиты формы и выведите их

1. Перейдите на вкладку **Реквизиты** формы.
2. Нажмите **Добавить** и создайте реквизит `Количество`, тип **Число**, длина `10`, точность `0`.
3. Так же создайте `Цена`, тип **Число**, длина `15`, точность `2`.
4. Так же создайте `Сумма`, тип **Число**, длина `15`, точность `2`.
5. Перетащите каждый реквизит из списка реквизитов в дерево элементов формы — платформа создаст поле ввода.
6. Выделите поле `Сумма` и в палитре свойств включите флаг **ТолькоПросмотр**: сумма считается программно, руками её менять не нужно.
7. `Ctrl+S`, `F5` и убедитесь, что на форме появились три поля, а «Сумма» недоступна для ввода.

**Проверка:** на форме три числовых поля, «Сумма» показана, но изменить её нельзя.

## Шаг 2. Напишите процедуру пересчёта

Расчёт нужен в двух обработчиках, поэтому вынесем его в отдельную клиентскую процедуру:

```bsl
&НаКлиенте
Процедура ПересчитатьСумму()
	Сумма = УчебныеФункции.РассчитатьСумму(Количество, Цена);
КонецПроцедуры
```

Процедура клиентская, потому что работает только с реквизитами формы и к базе не обращается. Сама формула живёт в общем модуле `УчебныеФункции` с занятия 21 — дублировать её в форме не нужно.

**Проверка:** **Конфигурация → Проверка → Синтаксический контроль** проходит без ошибок.

## Шаг 3. Создайте обработчик `КоличествоПриИзменении`

1. В дереве элементов формы выделите поле `Количество`.
2. В палитре свойств найдите группу **События** и в ней событие **ПриИзменении**.
3. Нажмите кнопку с лупой справа от события.
4. Платформа создаст заготовку обработчика и свяжет её с событием. Впишите внутрь вызов пересчёта:

```bsl
&НаКлиенте
Процедура КоличествоПриИзменении(Элемент)
	ПересчитатьСумму();
КонецПроцедуры
```

Имя `КоличествоПриИзменении` и параметр `Элемент` платформа подставила сама. Не переименовывайте их: связь с событием задана в свойствах элемента формы, а не в тексте модуля.

**Проверка:** в свойстве **ПриИзменении** поля «Количество» указано имя обработчика, и процедура с этим именем есть в модуле.

## Шаг 4. Создайте обработчик `ЦенаПриИзменении`

1. Выделите поле `Цена`.
2. Нажмите лупу у события **ПриИзменении**.
3. Впишите тот же вызов:

```bsl
&НаКлиенте
Процедура ЦенаПриИзменении(Элемент)
	ПересчитатьСумму();
КонецПроцедуры
```

**Проверка:** в модуле формы два обработчика `ПриИзменении`, и оба вызывают `ПересчитатьСумму()`.

## Шаг 5. Задайте значения по умолчанию в `ПриСозданииНаСервере`

1. Выделите в дереве элементов **корень формы** — самый верхний узел.
2. Найдите событие **ПриСозданииНаСервере** и нажмите лупу.
3. Заполните созданный обработчик:

```bsl
&НаСервере
Процедура ПриСозданииНаСервере(Отказ, СтандартнаяОбработка)
	Количество = 1;
	Цена = 0;
КонецПроцедуры
```

Обратите внимание на директиву: платформа поставила `&НаСервере`, а не `&НаСервереБезКонтекста`. Так и должно быть — обработчик работает с реквизитами формы, значит контекст формы ему нужен.

**Проверка:** при открытии обработки в поле «Количество» уже стоит `1`.

## Шаг 6. Поприветствуйте пользователя в `ПриОткрытии`

1. В палитре свойств формы найдите событие **ПриОткрытии** и нажмите лупу.
2. Заполните обработчик:

```bsl
&НаКлиенте
Процедура ПриОткрытии(Отказ)
	Сообщить("Учебная консоль готова");
КонецПроцедуры
```

Событие клиентское, поэтому показать сообщение здесь можно. В `ПриСозданииНаСервере` так делать нельзя: формы на экране ещё нет.

**Проверка:** при открытии обработки появляется сообщение «Учебная консоль готова».

## Шаг 7. Добавьте команду формы «Очистить»

1. Перейдите на вкладку **Команды** формы, подвкладку **Команды формы**.
2. Нажмите **Добавить**.
3. Задайте **Имя** — `Очистить`, **Заголовок** — `Очистить`.
4. Нажмите лупу у свойства **Действие** — платформа создаст обработчик в модуле формы.
5. Заполните его:

```bsl
&НаКлиенте
Процедура Очистить(Команда)
	Количество = 0;
	Цена = 0;
	Сумма = 0;
КонецПроцедуры
```

6. Перетащите команду `Очистить` из списка команд в дерево элементов формы — рядом с кнопкой **Выполнить** появится вторая кнопка.

**Проверка:** на форме две кнопки, и нажатие **Очистить** обнуляет все три поля.

## Шаг 8. Проверьте порядок событий

1. Добавьте `Сообщить` в начало обоих обработчиков:

```bsl
&НаСервере
Процедура ПриСозданииНаСервере(Отказ, СтандартнаяОбработка)
	Сообщить("1. ПриСозданииНаСервере — сервер");
	Количество = 1;
	Цена = 0;
КонецПроцедуры

&НаКлиенте
Процедура ПриОткрытии(Отказ)
	Сообщить("2. ПриОткрытии — клиент");
	Сообщить("Учебная консоль готова");
КонецПроцедуры
```

2. `Ctrl+S`, `F5`, откройте обработку **Учебная консоль** в разделе **Разработка**.
3. Прочитайте окно сообщений: сначала строка про `ПриСозданииНаСервере`, затем про `ПриОткрытии`. Порядок именно такой, потому что форма сначала готовится на сервере и только потом попадает на клиент.

**Проверка:** сообщения выведены в порядке 1, 2.

## Шаг 9. Поработайте с формой как пользователь

1. Запустите приложение `F5` и откройте обработку **Учебная консоль**.
2. Введите в «Количество» число `20` и нажмите `Tab`. Пока вы не ушли из поля, сумма не менялась: событие `ПриИзменении` срабатывает именно при уходе из поля.
3. Введите в «Цена» число `12,50` и нажмите `Tab`. В «Сумме» появится `250`.
4. Поменяйте количество на `30` и снова нажмите `Tab`. Сумма пересчитается без нажатия каких-либо кнопок.
5. Нажмите кнопку **Очистить** — все три поля обнулятся.

**Проверка:** сумма пересчитывается сама, кнопка **Очистить** работает.

## Проверка результата

Занятие пройдено, если выполняются пять условий:

1. На форме есть поля «Количество», «Цена» и «Сумма», причём «Сумма» только для просмотра.
2. Сумма пересчитывается автоматически при изменении количества или цены.
3. При открытии формы в поле «Количество» стоит `1`.
4. Сообщение из `ПриОткрытии` выводится после сообщения из `ПриСозданииНаСервере`.
5. Команда формы **Очистить** выведена на форму и обнуляет все три поля.
