# 1С-разработчик с нуля за 30 дней

Практический курс по разработке в **1С:Предприятие 8.3** для начинающих.

## Цель курса

За 30 дней понять устройство платформы 1С, научиться работать в Конфигураторе, создавать прикладные объекты и писать код на встроенном языке. Результат обучения — собственное учебное решение, которое можно показать как первую работу в портфолио.

## Учебный проект

На протяжении курса мы разрабатываем конфигурацию **«Управление строительной компанией с логистикой»**. Это упрощённая ERP-система для строительной компании: она объединит продажи и работу с клиентами, закупки у поставщиков, номенклатуру, склады, доставку материалов на объекты, сотрудников, строительные работы и управленческие отчёты.

Проект строится небольшими шагами: сначала освоим среду разработки и модель данных, затем создадим логистические и учётные документы, проведём их по регистрам и построим ERP-отчёты.

## Формат учебного дня

Каждый день содержит три файла:

- `README.md` — цель дня, результат и маршрут;
- `theory.md` — короткая теория с терминами и примерами;
- `practice.md` — пошаговая практика и контрольное задание.

Рекомендуемый ритм: 20–30 минут теории, 40–90 минут практики и 10 минут на проверку результата.
