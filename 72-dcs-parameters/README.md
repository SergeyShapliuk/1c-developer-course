# Занятие 72. Параметры и отборы

## Цель

Научиться давать пользователю менять вопрос отчёта: на какую дату и по какому складу. Понять разницу между параметром данных и отбором, увидеть, что система компоновки сама создаёт параметры виртуальных таблиц и сама переносит отбор по измерению в их условие, и вынести нужные настройки прямо на форму отчёта.

## Результат занятия

Над результатом отчёта `ОстаткиНаСкладах` появятся два поля: «Остатки на начало дня» и «Склад». Без даты отчёт покажет текущие остатки, с датой — остатки на начало выбранного дня; без склада — все склады, со складом — только выбранный. Числа совпадут с функцией `ОстатокМатериала` общего модуля `ОстаткиМатериаловСервер` занятия 65. Текст запроса не получит ни одного `ГДЕ`.

## Ключевые термины

Параметр данных, параметр виртуальной таблицы, `Период`, заголовок параметра, ограничение доступности, отбор, вид сравнения, использование элемента настроек, пользовательские настройки, режим редактирования, быстрый доступ, обычный режим.
