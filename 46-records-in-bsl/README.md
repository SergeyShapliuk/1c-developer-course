# Занятие 46. Программное создание движений

## Цель

Научиться формировать движения регистра накопления из кода документа: понять, что такое событие `ОбработкаПроведения`, как устроена коллекция `Движения` и почему регистр нельзя изменить напрямую. Это занятие соединяет документ, регистр, модуль объекта и встроенный язык в одном месте.

## Результат занятия

В модуле объекта документа `ПоступлениеМатериалов` появится процедура `ОбработкаПроведения`, которая обойдёт строки табличной части `Материалы` и добавит в набор записей по движению прихода на каждую строку, взяв период из даты документа, склад из шапки, а материал и количество из строки. После проведения в регистре `ОстаткиМатериалов`, пустовавшем с занятия 42, появятся записи, и остаток материалов на складе наконец станет видимым.

`ОбработкаПроведения`, `Отказ`, `РежимПроведения`, коллекция `Движения`, набор записей, `Записывать`, `Добавить()`, `Период`, `Регистратор`, `ВидДвижения`, `ВидДвиженияНакопления.Приход`, модуль объекта документа.
