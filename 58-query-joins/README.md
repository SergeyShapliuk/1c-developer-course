# Занятие 58. Соединения таблиц

## Цель

Научиться получать в одном ответе данные из двух таблиц, связанных по смыслу: строки заявки и строки поступлений, введённых на её основании. Понять разницу между внутренним, левым и полным соединением, откуда в результате соединения появляется `NULL` и почему условие на вторую таблицу нельзя переносить из `ПО` в `ГДЕ` без размышлений.

## Результат занятия

В обработке `УчебнаяКонсоль` появится процедура «Исполнение заявки»: по каждой строке заявки — сколько заказано, сколько поступило по проведённым поступлениям-основаниям и сколько осталось получить. Строки, по которым ничего не поступило, в ответе остаются с нулём. Вы увидите, как повторное поступление по заявке размножает её строки, и запишете эту проблему как задачу занятия 59.

## Ключевые термины

Соединение таблиц, условие соединения, `ПО`, `ВНУТРЕННЕЕ СОЕДИНЕНИЕ`, `ЛЕВОЕ СОЕДИНЕНИЕ`, `ПОЛНОЕ СОЕДИНЕНИЕ`, `NULL` из соединения, `ЕСТЬNULL`, размножение строк, вкладка **Связи** конструктора.
