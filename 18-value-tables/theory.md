# Теория. Список значений и таблица значений

## Список значений

**Список значений** — коллекция, придуманная для интерфейса: чтобы предложить пользователю выбрать один вариант из нескольких.

```bsl
Единицы = Новый СписокЗначений;
Единицы.Добавить("шт.", "Штука");
Единицы.Добавить("меш.", "Мешок");
```

Метод `Добавить()` принимает два аргумента, и разница между ними важна.

- **Значение** — то, с чем работает код: `"шт."`, `"меш."`.
- **Представление** — то, что читает пользователь: `"Штука"`, `"Мешок"`.

Так можно хранить короткое значение, а показывать понятный текст. Кроме значения и представления у каждого элемента есть **пометка** — признак «флажок установлен»; её используют, когда пользователь выбирает не один вариант, а несколько.

Перебирается список обычным `Для Каждого` из занятия 17, а искать в нём умеет метод `НайтиПоЗначению()`:

```bsl
Для Каждого Элемент Из Единицы Цикл
	Сообщить(Элемент.Представление + " = " + Элемент.Значение);
КонецЦикла;

Найденный = Единицы.НайтиПоЗначению("меш.");
```

Список значений работает **на клиенте**: его можно создать в той же процедуре, которая обслуживает нажатие кнопки.

## Таблица значений

**Таблица значений** — коллекция строк с одинаковым набором колонок. По смыслу это массив структур (занятие 17), но с готовыми методами подсчёта, поиска, сортировки и группировки.

Таблица создаётся пустой, и сначала ей задают колонки:

```bsl
Таблица = Новый ТаблицаЗначений;
Таблица.Колонки.Добавить("Товар", Новый ОписаниеТипов("Строка"));
Таблица.Колонки.Добавить("Количество", Новый ОписаниеТипов("Число"));
Таблица.Колонки.Добавить("Сумма");
```

Если тип колонки не указан, в неё можно положить что угодно; указанный тип — страховка от случайной ошибки, и так пишут чаще.

`Добавить()` у таблицы не принимает значений: он добавляет пустую строку и **возвращает её**. Поля заполняют у возвращённой строки:

```bsl
НоваяСтрока = Таблица.Добавить();
НоваяСтрока.Товар = "Цемент М500";
НоваяСтрока.Количество = 10;
```

Перебирают таблицу по строкам, а к полям обращаются через точку — как к свойствам структуры:

```bsl
Для Каждого СтрокаТаблицы Из Таблица Цикл
	Сообщить(СтрокаТаблицы.Товар + ": " + Строка(СтрокаТаблицы.Количество));
КонецЦикла;
```

Переменную цикла здесь нельзя назвать просто `Строка`: такое имя закрыло бы встроенную функцию `Строка()`, которой мы пользуемся с занятия 11.

## Методы таблицы значений

Эти методы и отличают таблицу от массива структур.

| Метод | Что делает |
| --- | --- |
| `Итог("Сумма")` | Складывает все значения числовой колонки |
| `Найти(Значение, "Товар")` | Возвращает первую подходящую строку или `Неопределено` |
| `НайтиСтроки(Отбор)` | Возвращает массив всех подходящих строк |
| `Сортировать("Сумма Убыв")` | Переупорядочивает строки таблицы |
| `Свернуть("Товар", "Количество, Сумма")` | Объединяет одинаковые строки, складывая числа |
| `Скопировать()` | Создаёт независимую копию таблицы |

У `НайтиСтроки()` отбор задаётся структурой: `Новый Структура("Товар", "Цемент М500")`. Результат — массив, даже если подошла одна строка или не подошла ни одна.

`Свернуть()` принимает два перечня колонок через запятую: по каким группировать и какие суммировать. Строки с одинаковыми значениями группировочных колонок становятся одной строкой, а числа складываются.

## Почему здесь появилась директива `&НаСервере`

> `ТаблицаЗначений` недоступна в тонком и веб-клиенте: платформа сообщит, что в клиентском коде такого типа нет. Поэтому процедуру, которая создаёт и обрабатывает таблицу значений, помечают директивой `&НаСервере`, а вызывают её из обычного клиентского обработчика кнопки.

Строго говоря, этот тип есть не только на сервере: он доступен ещё в толстом клиенте и во внешнем соединении. Но наше приложение работает тонким клиентом, поэтому в учебном сценарии курса таблицу значений всегда создают и обрабатывают на сервере. Это заодно сразу показывает правильное разделение клиентской и серверной логики. Что такое клиент и что такое сервер, почему вызов с клиента на сервер стоит дорого и почему его нельзя делать внутри цикла — полностью разберём на занятии 22.

Пока примите директиву как необходимую пометку, у которой один простой смысл: **этот код выполняется на сервере**. Выглядит это так:

```bsl
&НаКлиенте
Процедура Выполнить(Команда)
	
	ПостроитьТаблицу(); // клиент вызывает серверную процедуру
	
КонецПроцедуры

&НаСервере
Процедура ПостроитьТаблицу()
	
	Таблица = Новый ТаблицаЗначений; // здесь это разрешено
	
КонецПроцедуры
```

## Где что работает

| Коллекция | Тонкий клиент | Сервер |
| --- | --- | --- |
| Массив, структура, соответствие (занятие 17) | да | да |
| Список значений | да | да |
| `ТаблицаЗначений` | нет | да |

Массив и структуру можно вернуть с сервера на клиент. Таблицу значений так передать не получится — поэтому в практике сообщения мы выводим прямо из серверной процедуры. Таблица описывает тонкий клиент, которым работает наше приложение: в толстом клиенте и во внешнем соединении `ТаблицаЗначений` доступна, но в учебном сценарии курса мы её всегда создаём и обрабатываем на сервере. На занятии 22 разберём, какие данные вообще можно передавать между клиентом и сервером и почему в нашем сценарии таблицу удобно превратить в массив структур.

## Где применяют таблицу значений

- **Промежуточные расчёты** — сложить, отсортировать, сгруппировать набор строк перед тем, как показать результат.
- **Подготовка данных для отчёта** — собрать строки, посчитать итоги и вывести.
- **Передача набора строк между процедурами** — одна серверная процедура собирает таблицу, другая её обрабатывает.

## Что важно запомнить

1. У элемента списка значений есть значение (для кода), представление (для пользователя) и пометка.
2. Список значений работает и на клиенте, и на сервере; `ТаблицаЗначений` в тонком клиенте недоступна, поэтому в учебном сценарии курса её создают и обрабатывают на сервере.
3. Процедуру, работающую с таблицей значений, помечают `&НаСервере` и вызывают из клиентского обработчика.
4. Колонки таблицы задают до заполнения; `Добавить()` возвращает новую строку, поля которой заполняют через точку.
5. `Итог()` складывает колонку, `НайтиСтроки()` возвращает массив строк, `Сортировать()` меняет порядок, `Свернуть()` объединяет одинаковые строки и складывает числа.
6. Массив, структура и соответствие доступны везде — о месте выполнения для них думать не нужно.
