# Занятие 18. Списки и таблицы значений

## Цель

Освоить две коллекции платформы со структурой строк: список значений и таблицу значений, и понять, почему таблица значений требует серверного кода.

## Результат занятия

В модуле формы обработки `УчебнаяКонсоль` появятся список значений с единицами измерения и серверная процедура, которая строит таблицу материалов, считает сумму, сортирует строки, ищет нужную и сворачивает одинаковые. Здесь же впервые появляется директива `&НаСервере` — как обязательная пометка, механизм разберём на занятии 22.
