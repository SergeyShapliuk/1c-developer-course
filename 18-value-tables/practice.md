# Практика. Таблица материалов с итогом и группировкой

## Перед началом

Запустите конфигуратор учебной конфигурации **«Управление строительной компанией с логистикой»**.

В дереве конфигурации откройте обработку `УчебнаяКонсоль` (синоним «Учебная консоль»), затем её форму, а в редакторе формы — вкладку **Модуль**. Работаем в процедуре `Выполнить` и в процедуре, которую добавим рядом.

После каждой правки кода:

1. Сохраните конфигурацию — `Ctrl+S`.
2. Запустите приложение — `F5`.
3. В разделе **Разработка** откройте «Учебную консоль».
4. Нажмите кнопку **Выполнить** и прочитайте сообщения.

На шагах 2–8 часть кода будет помечена директивой `&НаСервере`. Если забыли, почему, вернитесь к врезке «Почему здесь появилась директива `&НаСервере`» в [теории](theory.md).

## Шаг 1. Список значений на клиенте

Начнём с коллекции, которой сервер не нужен.

```bsl
&НаКлиенте
Процедура Выполнить(Команда)
	
	Единицы = Новый СписокЗначений;
	Единицы.Добавить("шт.", "Штука");
	Единицы.Добавить("меш.", "Мешок");
	Единицы.Добавить("кг", "Килограмм");
	Единицы.Добавить("м3", "Кубический метр");
	
	Для Каждого Элемент Из Единицы Цикл
		// Значение — для кода, представление — для пользователя
		Сообщить(Элемент.Представление + " (" + Элемент.Значение + ")");
	КонецЦикла;
	
	Найденный = Единицы.НайтиПоЗначению("меш.");
	Если Найденный = Неопределено Тогда
		Сообщить("Единица не найдена");
	Иначе
		Сообщить("Нашли: " + Найденный.Представление);
	КонецЕсли;
	
КонецПроцедуры
```

Сохраните, запустите, нажмите **Выполнить**. Выведутся четыре единицы и строка `Нашли: Мешок`: искали по значению `"меш."`, а вывели представление.

**Проверка:** выведены четыре единицы и результат поиска.

## Шаг 2. Серверная процедура и вызов с клиента

Таблицу значений в тонком клиенте создать нельзя, поэтому работу с ней выносим в процедуру с директивой `&НаСервере`. Клиентский обработчик кнопки её просто вызывает. Приведите модуль к такому виду:

```bsl
&НаКлиенте
Процедура Выполнить(Команда)
	
	// Клиентский код вызывает серверную процедуру по имени,
	// как любую другую процедуру модуля формы.
	ПостроитьТаблицуМатериалов();
	
КонецПроцедуры

&НаСервере
Процедура ПостроитьТаблицуМатериалов()
	
	Сообщить("Серверная процедура запущена");
	
КонецПроцедуры
```

Сохраните, запустите, нажмите **Выполнить**. Появится сообщение о запуске: платформа перешла с клиента на сервер, выполнила процедуру и вернула сообщение обратно.

**Проверка:** сообщение «Серверная процедура запущена» выводится при нажатии кнопки.

## Шаг 3. Колонки и строки таблицы

Теперь наполним серверную процедуру. Клиентскую часть больше не меняем.

```bsl
&НаСервере
Процедура ПостроитьТаблицуМатериалов()
	
	Таблица = Новый ТаблицаЗначений;
	Таблица.Колонки.Добавить("Товар", Новый ОписаниеТипов("Строка"));
	Таблица.Колонки.Добавить("Количество", Новый ОписаниеТипов("Число"));
	Таблица.Колонки.Добавить("Цена", Новый ОписаниеТипов("Число"));
	Таблица.Колонки.Добавить("Сумма", Новый ОписаниеТипов("Число"));
	
	ДобавитьСтроку(Таблица, "Цемент М500", 10, 12.50);
	ДобавитьСтроку(Таблица, "Кирпич облицовочный", 500, 18.90);
	ДобавитьСтроку(Таблица, "Арматура 12", 40, 54.00);
	ДобавитьСтроку(Таблица, "Песок строительный", 3, 320.00);
	
	Сообщить("Строк в таблице: " + Строка(Таблица.Количество()));
	
КонецПроцедуры

&НаСервере
Процедура ДобавитьСтроку(Таблица, Товар, Количество, Цена)
	
	// Добавить() не принимает значений: он создаёт пустую строку
	// и возвращает её, а поля мы заполняем сами.
	НоваяСтрока = Таблица.Добавить();
	НоваяСтрока.Товар = Товар;
	НоваяСтрока.Количество = Количество;
	НоваяСтрока.Цена = Цена;
	
КонецПроцедуры
```

**Проверка:** выведено `Строк в таблице: 4`.

## Шаг 4. Расчёт колонки «Сумма»

Колонка `Сумма` пока пустая. Заполним её перебором строк. Добавьте этот блок в `ПостроитьТаблицуМатериалов` перед выводом количества строк:

```bsl
	Для Каждого СтрокаТаблицы Из Таблица Цикл
		СтрокаТаблицы.Сумма = СтрокаТаблицы.Количество * СтрокаТаблицы.Цена;
		Сообщить(СтрокаТаблицы.Товар + ": " + Строка(СтрокаТаблицы.Сумма));
	КонецЦикла;
```

Переменную цикла называем `СтрокаТаблицы`, а не `Строка`: имя `Строка` закрыло бы встроенную функцию `Строка()`.

Сохраните, запустите, нажмите **Выполнить**. Для цемента выведется `125`, для кирпича `9450`, для арматуры `2160`, для песка `960`.

**Проверка:** по каждому материалу выведена своя сумма.

## Шаг 5. Итог и сортировка

Добавьте после цикла расчёта:

```bsl
	Сообщить("Итого: " + Строка(Таблица.Итог("Сумма")));
	
	// Убыв — по убыванию. Сортировать меняет порядок строк
	// в самой таблице, новую таблицу метод не создаёт.
	Таблица.Сортировать("Сумма Убыв");
	
	Сообщить("--- после сортировки ---");
	Для Каждого СтрокаТаблицы Из Таблица Цикл
		Сообщить(СтрокаТаблицы.Товар + ": " + Строка(СтрокаТаблицы.Сумма));
	КонецЦикла;
```

Сохраните, запустите, нажмите **Выполнить**. Итог равен `12695`, а после сортировки порядок изменится: кирпич, арматура, песок, цемент.

**Проверка:** выведен итог и перечень строк, упорядоченный по сумме от большей к меньшей.

## Шаг 6. Поиск строк по отбору

Добавьте в конец серверной процедуры:

```bsl
	Отбор = Новый Структура("Товар", "Цемент М500");
	НайденныеСтроки = Таблица.НайтиСтроки(Отбор);
	
	// НайтиСтроки всегда возвращает массив (занятие 17),
	// даже если подошла одна строка или не подошла ни одна.
	Сообщить("Найдено строк: " + Строка(НайденныеСтроки.Количество()));
	
	Для Каждого СтрокаТаблицы Из НайденныеСтроки Цикл
		Сообщить("Цена цемента: " + Строка(СтрокаТаблицы.Цена));
	КонецЦикла;
```

Отбор задаётся структурой: имя свойства — имя колонки, значение свойства — искомое значение.

**Проверка:** выведено `Найдено строк: 1` и цена цемента `12,5`.

## Шаг 7. Свернуть одинаковые строки

Посмотрим, как таблица группирует строки. Чтобы не портить исходную таблицу, сделаем копию. Добавьте в конец серверной процедуры:

```bsl
	// Скопировать() создаёт независимую копию:
	// изменения в копии не затронут исходную таблицу.
	Копия = Таблица.Скопировать();
	
	// Вторая поставка того же цемента
	НоваяСтрока = Копия.Добавить();
	НоваяСтрока.Товар = "Цемент М500";
	НоваяСтрока.Количество = 5;
	НоваяСтрока.Цена = 12.50;
	НоваяСтрока.Сумма = 5 * 12.50;
	
	Сообщить("Строк в копии до свёртки: " + Строка(Копия.Количество()));
	
	// Группируем по Товару, числовые колонки складываем
	Копия.Свернуть("Товар", "Количество, Сумма");
	
	Сообщить("Строк в копии после свёртки: " + Строка(Копия.Количество()));
	Для Каждого СтрокаТаблицы Из Копия Цикл
		Сообщить(СтрокаТаблицы.Товар
			+ ": количество " + Строка(СтрокаТаблицы.Количество)
			+ ", сумма " + Строка(СтрокаТаблицы.Сумма));
	КонецЦикла;
```

Сохраните, запустите, нажмите **Выполнить**. До свёртки в копии пять строк, после — четыре. Две строки цемента объединились в одну: количество стало `15`, сумма `187,5`.

Ещё деталь: после `Свернуть()` в таблице остались только перечисленные колонки. Колонки `Цена` в копии больше нет — она не вошла ни в группировочные, ни в суммируемые.

**Проверка:** число строк уменьшилось с пяти до четырёх, а количество и сумма по цементу сложились.

## Шаг 8. Что будет, если создать таблицу на клиенте

Теперь проверим врезку из теории практикой.

1. Добавьте в клиентскую процедуру `Выполнить` строку:

```bsl
	Таблица = Новый ТаблицаЗначений; // на клиенте это запрещено
```

2. Выполните **Конфигурация → Проверка → Синтаксический контроль** и прочитайте сообщение: платформа говорит, что тип недоступен в клиентском коде.
3. **Удалите эту строку.** Она нужна была только для того, чтобы увидеть ограничение своими глазами.

Вот почему вся работа с таблицей живёт в процедуре с директивой `&НаСервере`.

**Проверка:** вы видели сообщение об ошибке и удалили строку, после чего синтаксический контроль проходит чисто.

## Проверка результата

Занятие пройдено, если выполняются пять условий:

1. Список значений выведен на клиенте, поиск по значению работает.
2. Серверная процедура `ПостроитьТаблицуМатериалов` вызывается из клиентского обработчика.
3. Таблица из четырёх строк построена, колонка `Сумма` посчитана, итог выведен.
4. Строки отсортированы по убыванию суммы, поиск по отбору вернул массив из одной строки.
5. Вы видели ошибку создания таблицы значений на клиенте и понимаете, зачем нужна директива `&НаСервере`.
