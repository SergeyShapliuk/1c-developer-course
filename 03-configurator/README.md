# Занятие 3. Конфигуратор и дерево конфигурации

## Цель

Освоиться в Конфигураторе: научиться читать дерево конфигурации, открывать палитру свойств и понимать разницу между конфигурацией и конфигурацией базы данных.

## Результат занятия

Вы зададите корню конфигурации имя `УправлениеСтроительнойКомпанией` и синоним «Управление строительной компанией», впервые пройдёте полный цикл разработки — `Ctrl+S`, `F7`, `F5` — и увидите синоним в заголовке пользовательского приложения.

## Маршрут

1. Прочитайте [теорию](theory.md) — около 25 минут.
2. Выполните [практику](practice.md) — около 40 минут.
3. Ответьте на контрольные вопросы в конце практики, не подглядывая в теорию.

## Ключевые термины

Конфигуратор, дерево конфигурации, корневой узел, группа объектов, палитра свойств, конфигурация базы данных, обновление конфигурации базы данных, цикл разработки.
