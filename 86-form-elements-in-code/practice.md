# Практика. Панель снабженца

## Перед началом

Запустите конфигуратор учебной конфигурации **«Управление строительной компанией с логистикой»**.

Понадобятся общий модуль `СправкиСнабженцаСервер` (занятие 68), форма списка `ФормаСписка` документа `ЗаявкаНаМатериалы` с колонкой объекта строительства (занятие 84) и несколько новых заявок минимум на два объекта.

Откройте журнал заявок и посчитайте вручную по каждому объекту, сколько у него заявок в состоянии «Новая», не помеченных на удаление. Если новые заявки есть только у одного объекта, создайте новую заявку на «ЖК Южный»: «Кирпич облицовочный» — `1` — и запишите, не согласовывая. Запишите ожидаемые числа в конспект.

После каждой правки: `Ctrl+S`, затем `F5` и проверка в приложении, как описано в шаге.

## Шаг 1. Получите данные панели функцией общего модуля

1. Откройте общий модуль `СправкиСнабженцаСервер` и добавьте функцию:

```bsl
// Возвращает объекты строительства с числом заявок, ожидающих согласования.
Функция ЗаявкиНаСогласовании() Экспорт

	Запрос = Новый Запрос;
	Запрос.Текст =
		"ВЫБРАТЬ
		|	Заявка.ОбъектСтроительства КАК ОбъектСтроительства,
		|	Заявка.ОбъектСтроительства.Наименование КАК Наименование,
		|	КОЛИЧЕСТВО(Заявка.Ссылка) КАК ЧислоЗаявок
		|ИЗ
		|	Документ.ЗаявкаНаМатериалы КАК Заявка
		|ГДЕ
		|	НЕ Заявка.ПометкаУдаления
		|	И Заявка.Состояние = ЗНАЧЕНИЕ(Перечисление.СостоянияЗаявок.Новая)
		|СГРУППИРОВАТЬ ПО
		|	Заявка.ОбъектСтроительства,
		|	Заявка.ОбъектСтроительства.Наименование
		|УПОРЯДОЧИТЬ ПО
		|	Наименование";

	Возврат Запрос.Выполнить().Выгрузить();

КонецФункции
```

Запрос живёт в общем модуле, а не в модуле формы панели: это данные, и завтра они могут понадобиться другому экрану. Наименование выбрано отдельным полем и включено в группировку, чтобы упорядочить кнопки по алфавиту.

**Проверка:** функция `ЗаявкиНаСогласовании` добавлена в `СправкиСнабженцаСервер`, синтаксический контроль ошибок не находит.

## Шаг 2. Создайте обработку и её форму

1. В дереве конфигурации выделите ветку **Обработки** и нажмите **Добавить**. Имя — `ПанельСнабженца`, синоним — «Панель снабженца».
2. На вкладке **Подсистемы** отметьте **Логистика**.
3. На вкладке **Формы** создайте основную форму обработки.
4. В редакторе формы добавьте в дерево элементов **обычную группу** с именем `ГруппаОбъекты` и заголовком «Объекты с заявками на согласовании». Группировку задайте вертикальной.
5. Под группой добавьте **декорацию-надпись** с именем `НадписьНетЗаявок` и текстом «Заявок на согласовании нет».
6. В панели реквизитов формы добавьте реквизит `ОбъектыКнопок` с типом `СписокЗначений`.

Группа и надпись нарисованы заранее: они задают место и запасной текст. Код будет только наполнять группу.

**Проверка:** у обработки `ПанельСнабженца` есть основная форма с группой `ГруппаОбъекты`, надписью `НадписьНетЗаявок` и реквизитом `ОбъектыКнопок`.

## Шаг 3. Создайте кнопки при открытии формы

Откройте модуль формы обработки и добавьте код:

```bsl
&НаСервере
Процедура ПриСозданииНаСервере(Отказ, СтандартнаяОбработка)

	СоздатьКнопкиОбъектов();

КонецПроцедуры

// Создаёт по команде и кнопке на каждый объект с заявками на согласовании.
&НаСервере
Процедура СоздатьКнопкиОбъектов()

	Объекты = СправкиСнабженцаСервер.ЗаявкиНаСогласовании();
	Номер = 0;

	Для Каждого ДанныеОбъекта Из Объекты Цикл

		Номер = Номер + 1;
		ИмяКоманды = "ОткрытьЗаявкиОбъекта" + Формат(Номер, "ЧГ=0");

		Команда = Команды.Добавить(ИмяКоманды);
		Команда.Действие = "Подключаемый_ОткрытьЗаявкиОбъекта";
		Команда.Заголовок = ДанныеОбъекта.Наименование + ": на согласовании "
			+ Формат(ДанныеОбъекта.ЧислоЗаявок, "ЧГ=0");

		Кнопка = Элементы.Добавить("Кнопка" + ИмяКоманды, Тип("КнопкаФормы"), Элементы.ГруппаОбъекты);
		Кнопка.ИмяКоманды = ИмяКоманды;

		ОбъектыКнопок.Добавить(ДанныеОбъекта.ОбъектСтроительства, ИмяКоманды);

	КонецЦикла;

	Элементы.НадписьНетЗаявок.Видимость = (Номер = 0);

КонецПроцедуры
```

Разберём по строкам. Имя команды получает номер, чтобы не повторяться; `Формат(Номер, "ЧГ=0")` убирает разделитель разрядов, иначе десятая кнопка получила бы имя с пробелом. `Команда.Действие` — имя процедуры, которую мы напишем в шаге 4. Кнопка добавляется внутрь `ГруппаОбъекты` и связывается с командой через `ИмяКоманды`. В `ОбъектыКнопок` запоминается пара «объект — имя команды»: по ней обработчик найдёт объект.

Надпись «Заявок на согласовании нет» видна, только если не создано ни одной кнопки, — приём занятия 81.

**Проверка:** синтаксический контроль ошибок не находит.

## Шаг 4. Напишите один обработчик для всех кнопок

Добавьте в модуль формы:

```bsl
&НаКлиенте
Процедура Подключаемый_ОткрытьЗаявкиОбъекта(Команда)

	Для Каждого ЭлементСписка Из ОбъектыКнопок Цикл

		Если ЭлементСписка.Представление = Команда.Имя Тогда
			Отбор = Новый Структура("ОбъектСтроительства", ЭлементСписка.Значение);
			ОткрытьФорму("Документ.ЗаявкаНаМатериалы.ФормаСписка", Новый Структура("Отбор", Отбор), ЭтаФорма);
			Возврат;
		КонецЕсли;

	КонецЦикла;

КонецПроцедуры
```

Обработчик клиентский: открытие формы — действие клиента (занятие 22). Серверного вызова нет: объект найден в реквизите формы, который уже на клиенте. Параметр `Отбор` знаком по занятию 79: форма списка, как и форма отчёта, принимает отбор структурой «поле — значение».

**Проверка:** в модуле формы есть процедура `Подключаемый_ОткрытьЗаявкиОбъекта`, синтаксический контроль ошибок не находит.

## Шаг 5. Проверьте панель

1. Сохраните и запустите. Откройте **Логистика → Панель снабженца**.
2. Сверьте кнопки с конспектом: по кнопке на каждый объект с новыми заявками, число в подписи совпадает с вашим подсчётом, кнопки по алфавиту.
3. Нажмите кнопку «ЖК Южный…». Открылся журнал заявок только по «ЖК Южный».
4. Нажмите кнопку другого объекта. Открылся журнал по нему.
5. В конфигураторе откройте форму обработки: в дереве элементов внутри `ГруппаОбъекты` пусто. Кнопки существуют только в открытой форме.

**Проверка:** кнопки и подписи совпадают с ручным подсчётом, каждая кнопка открывает заявки своего объекта, в конфигурации созданных кнопок нет.

## Шаг 6. Добавьте команду «Обновить»

1. Не закрывая панель, согласуйте в журнале одну новую заявку «ЖК Южный». Вернитесь в панель: подпись не изменилась. Панель показывает данные момента открытия.
2. В редакторе формы обработки создайте команду формы `Обновить` с заголовком «Обновить», создайте обработчик и перетащите команду в командную панель формы.
3. Заполните обработчик и добавьте серверную процедуру:

```bsl
&НаКлиенте
Процедура Обновить(Команда)

	ОбновитьНаСервере();

КонецПроцедуры

&НаСервере
Процедура ОбновитьНаСервере()

	Для Каждого ЭлементСписка Из ОбъектыКнопок Цикл
		ИмяКоманды = ЭлементСписка.Представление;
		Элементы.Удалить(Элементы.Найти("Кнопка" + ИмяКоманды));
		Команды.Удалить(Команды.Найти(ИмяКоманды));
	КонецЦикла;

	ОбъектыКнопок.Очистить();
	СоздатьКнопкиОбъектов();

КонецПроцедуры
```

Метод `Найти` возвращает элемент или команду по имени, а `Удалить` убирает найденное из формы. Удаляются только элементы и команды из `ОбъектыКнопок` — те, что создал код. Команда **Обновить**, группа и надпись остаются. После удаления та же `СоздатьКнопкиОбъектов` строит кнопки заново, поэтому правило построения записано один раз.

**Проверка:** синтаксический контроль ошибок не находит, команда **Обновить** есть на панели формы.

## Шаг 7. Проверьте обновление

1. Сохраните, запустите и откройте панель.
2. Согласуйте одну новую заявку «ЖК Южный» и нажмите в панели **Обновить**. Число в подписи уменьшилось на единицу.
3. Согласуйте все остальные новые заявки «ЖК Южный» и нажмите **Обновить**. Кнопка «ЖК Южный» исчезла.
4. Если согласовать новые заявки всех объектов, после **Обновить** появится надпись «Заявок на согласовании нет». Это проверять не обязательно: достаточно увидеть, что кнопки исчезают.
5. Нажмите **Обновить** несколько раз подряд. Ошибок нет: старые кнопки удаляются до создания новых.

**Проверка:** **Обновить** перестраивает кнопки по свежим данным и не падает при повторном нажатии.

## Проверка результата

Занятие пройдено, если выполняются шесть условий:

1. В общем модуле `СправкиСнабженцаСервер` есть функция `ЗаявкиНаСогласовании`, и запрос панели живёт только в ней.
2. Обработка `ПанельСнабженца` входит в подсистему **Логистика**, её форма при открытии создаёт по команде и кнопке на каждый объект с новыми заявками.
3. Подписи кнопок совпадают с ручным подсчётом, кнопки упорядочены по наименованию объекта.
4. Один подключаемый обработчик открывает журнал заявок с отбором по объекту нажатой кнопки без серверного вызова.
5. Команда **Обновить** удаляет созданные кодом элементы и команды и строит их заново.
6. Надпись «Заявок на согласовании нет» видна, только когда кнопок нет.
