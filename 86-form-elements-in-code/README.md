# Занятие 86. Элементы формы из кода

## Цель

Научиться создавать команды и элементы формы программно — когда их число и подписи зависят от данных и не известны разработчику заранее. Понять, где и когда это делают, как обработчик узнаёт, какую из одинаковых кнопок нажали, как пересоздать элементы при обновлении и когда вместо кнопок из кода лучше выбрать таблицу.

## Результат занятия

В разделе **Логистика** появится обработка «Панель снабженца». Её форма при открытии строит по кнопке на каждый объект строительства, у которого есть заявки на согласовании: «ЖК Южный: на согласовании 2». Кнопка открывает журнал заявок с отбором по этому объекту. Команда **Обновить** пересоздаёт кнопки по свежим данным. Если заявок на согласовании нет, форма так и пишет.

## Маршрут

1. Прочитайте [теорию](theory.md) — около 25 минут.
2. Выполните [практику](practice.md) — около 60 минут.

## Ключевые термины

Программное создание элементов, `Элементы.Добавить`, `Элементы.Удалить`, `Команды.Добавить`, `Команды.Удалить`, `КнопкаФормы`, `ИмяКоманды`, `Действие`, подключаемый обработчик, `СписокЗначений`, параметр формы списка `Отбор`.
