# Занятие 70. Схема компоновки данных: набор данных, поля, ресурсы

## Цель

Разобраться, из чего состоит схема компоновки данных: чем поле набора данных отличается от ресурса, откуда берутся заголовки колонок и как отчёт получает реквизиты связанных объектов, которых нет в запросе. Понять, почему итог в отчёте появляется только у ресурса.

## Результат занятия

Отчёт `ОстаткиНаСкладах` покажет понятные заголовки колонок, единицу измерения материала — без изменения текста запроса — и строку общего итога по остатку. Поле `Остаток` станет ресурсом с выражением `Сумма(Остаток)`, и вы убедитесь, что по ресурсу нельзя группировать, а по полю — можно.
