# Занятие 61. Итоги и обход по группировкам

## Цель

Научиться получать в одном ответе и детальные строки, и итоги по ним: потребность по каждому материалу объекта, итог по объекту и общий итог по всем объектам. Понять, чем итоги отличаются от группировки и как обходить результат с итогами уровень за уровнем.

## Результат занятия

В обработке `УчебнаяКонсоль` появится «сводка для закупки»: по каждому объекту строительства — строка итога с общей потребностью, под ней материалы объекта с количеством, а в самом начале — общий итог по всем объектам. Вывод построен вложенными циклами по группировкам результата.

## Маршрут

1. Прочитайте [теорию](theory.md) — около 25 минут.
2. Выполните [практику](practice.md) — около 50 минут.
3. Ответьте на контрольные вопросы в конце практики, не подглядывая в теорию.

## Ключевые термины

Итоги, `ИТОГИ … ПО`, контрольная точка итогов, `ОБЩИЕ`, итоговая запись, детальная запись, обход результата, `ОбходРезультатаЗапроса.ПоГруппировкам`, `ОбходРезультатаЗапроса.Прямой`, вложенная выборка.
