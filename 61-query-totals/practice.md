# Практика. Сводка для закупки

## Перед началом

Запустите конфигуратор учебной конфигурации **«Управление строительной компанией с логистикой»** и откройте модуль формы обработки `УчебнаяКонсоль`. Понадобятся рабочие заявки минимум на два объекта строительства с цементом, кирпичом и песком в строках и процедура `ВывестиПотребностьПоОбъектам` из занятия 59.

Вопрос, на который отвечаем: «Сколько материалов нужно всего, сколько — каждому объекту и из чего складывается потребность объекта?»

После каждой правки кода: `Ctrl+S`, затем `F5`, раздел **Разработка → Учебная консоль**, кнопка **Выполнить**.

## Шаг 1. Подготовьте запрос с группировкой

1. Добавьте процедуру `ВывестиСводкуДляЗакупки` с запросом, сгруппированным по объекту и материалу, без условия `ИМЕЮЩИЕ`:

```bsl
&НаСервере
Процедура ВывестиСводкуДляЗакупки()

	Запрос = Новый Запрос;
	Запрос.Текст =
		"ВЫБРАТЬ
		|	ЗаявкаМатериалы.Ссылка.ОбъектСтроительства КАК ОбъектСтроительства,
		|	ЗаявкаМатериалы.Материал КАК Материал,
		|	ПРЕДСТАВЛЕНИЕ(ЗаявкаМатериалы.Материал) КАК МатериалПредставление,
		|	СУММА(ЗаявкаМатериалы.Количество) КАК Потребность
		|ИЗ
		|	Документ.ЗаявкаНаМатериалы.Материалы КАК ЗаявкаМатериалы
		|ГДЕ
		|	НЕ ЗаявкаМатериалы.Ссылка.ПометкаУдаления
		|	И ЗаявкаМатериалы.Ссылка.Состояние <> ЗНАЧЕНИЕ(Перечисление.СостоянияЗаявок.Отклонена)
		|СГРУППИРОВАТЬ ПО
		|	ЗаявкаМатериалы.Ссылка.ОбъектСтроительства,
		|	ЗаявкаМатериалы.Материал
		|УПОРЯДОЧИТЬ ПО
		|	ОбъектСтроительства,
		|	Материал";

	Выборка = Запрос.Выполнить().Выбрать();

	Пока Выборка.Следующий() Цикл
		Сообщить(Строка(Выборка.ОбъектСтроительства) + " / " + Выборка.МатериалПредставление + ": " + Выборка.Потребность);
	КонецЦикла;

КонецПроцедуры
```

2. Вызовите её из `Выполнить` вместо прежних вызовов, запустите.

Объект и материал выбраны самими ссылками, а не их представлениями: по ссылкам будем упорядочивать и считать итоги. Упорядочивание по ссылке идёт по её представлению, как на занятии 56. Представление материала нужно только для вывода, поэтому оно отдельное поле.

**Проверка:** выведены строки «объект / материал: потребность» без итогов.

## Шаг 2. Добавьте итоги по объектам

1. Допишите в конец текста запроса, после `УПОРЯДОЧИТЬ ПО`:

```bsl
		|ИТОГИ
		|	СУММА(Потребность)
		|ПО
		|	ОбъектСтроительства";
```

Точку с запятой и закрывающую кавычку перенесите с прежней последней строки.

2. Запустите, ничего не меняя в цикле вывода.

Вывод изменился: перед материалами каждого объекта появилась строка, где материал пустой, а потребность равна сумме по объекту. Это итоговая запись. Обычная выборка — прямой обход — вернула итоговые и детальные записи подряд.

**Проверка:** перед материалами каждого объекта выведена строка с суммой потребности объекта.

## Шаг 3. Обойдите результат по группировкам

1. Замените код после текста запроса:

```bsl
	ВыборкаОбъекты = Запрос.Выполнить().Выбрать(ОбходРезультатаЗапроса.ПоГруппировкам);

	Пока ВыборкаОбъекты.Следующий() Цикл

		Сообщить(Строка(ВыборкаОбъекты.ОбъектСтроительства) + " — всего " + ВыборкаОбъекты.Потребность);

		ВыборкаМатериалы = ВыборкаОбъекты.Выбрать();

		Пока ВыборкаМатериалы.Следующий() Цикл
			Сообщить("    " + ВыборкаМатериалы.МатериалПредставление + ": " + ВыборкаМатериалы.Потребность);
		КонецЦикла;

	КонецЦикла;
```

2. Запустите.

Внешний цикл получил только итоговые записи объектов, внутренний — материалы текущего объекта. Отступ из четырёх пробелов в начале сообщения показывает вложенность.

`Строка()` на уровне объекта дочитывает его наименование — по одному обращению на объект, а не на каждую строку материалов. Для сводки из нескольких объектов это приемлемо.

**Проверка:** каждый объект выведен строкой «всего», под ним с отступом — его материалы.

## Шаг 4. Добавьте общий итог

1. Замените контрольные точки:

```bsl
		|ПО
		|	ОБЩИЕ,
		|	ОбъектСтроительства";
```

2. Запустите, не меняя кода обхода. Внешний цикл теперь выводит одну запись — общий итог, а во внутреннем вместо материалов оказались итоги объектов.
3. Добавьте третий уровень обхода:

```bsl
	ВыборкаВсего = Запрос.Выполнить().Выбрать(ОбходРезультатаЗапроса.ПоГруппировкам);

	Пока ВыборкаВсего.Следующий() Цикл

		Сообщить("Всего по всем объектам: " + ВыборкаВсего.Потребность);

		ВыборкаОбъекты = ВыборкаВсего.Выбрать(ОбходРезультатаЗапроса.ПоГруппировкам);

		Пока ВыборкаОбъекты.Следующий() Цикл

			Сообщить("  " + Строка(ВыборкаОбъекты.ОбъектСтроительства) + " — всего " + ВыборкаОбъекты.Потребность);

			ВыборкаМатериалы = ВыборкаОбъекты.Выбрать();

			Пока ВыборкаМатериалы.Следующий() Цикл
				Сообщить("    " + ВыборкаМатериалы.МатериалПредставление + ": " + ВыборкаМатериалы.Потребность);
			КонецЦикла;

		КонецЦикла;

	КонецЦикла;
```

4. Запустите.

**Проверка:** первой строкой выведен общий итог, под ним объекты со своими итогами, под каждым объектом — его материалы.

## Шаг 5. Проверьте итоги руками

1. Сложите итоги объектов из вывода и сравните с общим итогом.
2. Для одного объекта сложите потребность по материалам и сравните с итогом объекта.
3. Ответьте в конспекте: имеет ли смысл общий итог, если складываются мешки цемента, штуки кирпича и кубометры песка?

Последний вопрос важен. Платформа честно сложила числа, но единицы измерения у материалов разные, и «всего 920» ничего не значит для закупки. Итог по объекту и общий итог полезны для одного материала или для денежных сумм. Поэтому в рабочей сводке разумнее считать итог по полю `Сумма` строк заявки: деньги складываются всегда.

4. Добавьте в запрос поле `СУММА(ЗаявкаМатериалы.Сумма) КАК Сумма`, в итоги — `СУММА(Сумма)` через запятую после `СУММА(Потребность)`, и выведите сумму на уровнях объекта и общего итога вместо количества.

**Проверка:** итоги объектов и общий итог выводятся в деньгах, и сумма итогов объектов равна общему итогу.

## Проверка результата

Занятие пройдено, если выполняются пять условий:

1. Процедура `ВывестиСводкуДляЗакупки` выводит общий итог, итоги по объектам и материалы каждого объекта.
2. Запрос использует и `СГРУППИРОВАТЬ ПО`, и `ИТОГИ … ПО ОБЩИЕ, ОбъектСтроительства`.
3. Вывод построен вложенными выборками с обходом `ОбходРезультатаЗапроса.ПоГруппировкам`.
4. Вы видели, как выглядит тот же результат при прямом обходе.
5. Вы можете объяснить, почему итог в количестве по разным материалам бессмыслен, а итог в деньгах осмыслен.

## Контрольные вопросы

Не подглядывая в теорию, ответьте устно или в заметках:

1. Чем `ИТОГИ … ПО` отличается от `СГРУППИРОВАТЬ ПО` по тому, что происходит с детальными строками?
2. Что такое контрольная точка итогов и что добавляет слово `ОБЩИЕ`?
3. Что возвращает выборка с обходом `ПоГруппировкам` и что — вложенная выборка, полученная методом `Выбрать()` у её записи?
4. Почему для вывода сводки удобнее обход по группировкам, чем прямой обход?
5. Коду проведения нужна общая сумма заявки по объекту. Брать её из итоговой записи запроса или получать группировкой? Почему?
