# Теория. Итоги и обход по группировкам

## Какую задачу мы решаем

На занятии 59 снабженец получил потребность в разрезе «объект — материал». Для переговоров с поставщиком ему нужна сводка другого вида: сначала объект и его общая потребность, под ним — материалы объекта, а над всем — сколько нужно всего.

Группировка такую форму не даёт. Она **сворачивает** строки: если сгруппировать по объекту, материалы исчезнут; если по объекту и материалу, исчезнет итог объекта. Нужны одновременно и детали, и суммы над ними. Это задача **итогов**.

## Итоги не сворачивают, а добавляют

Секция `ИТОГИ` пишется в самом конце запроса и говорит платформе: посчитай суммы по указанным полям и **добавь** их в результат отдельными строками.

```bsl
ИТОГИ
	СУММА(Потребность)
ПО
	ОбъектСтроительства
```

После `ИТОГИ` перечисляют агрегатные функции над полями результата, после `ПО` — **контрольные точки**: поля, по изменению значения которых считается итог. Не путайте их с контрольной точкой курса — занятием-зачётом вроде 52 или 68: здесь это термин языка запросов, и означает он только место подсчёта итога. Если в результате три объекта, в нём появятся три **итоговые записи**, по одной на объект, а исходные строки останутся на месте как **детальные записи**.

| Что сравниваем | `СГРУППИРОВАТЬ ПО` | `ИТОГИ … ПО` |
| --- | --- | --- |
| Что делает со строками | сворачивает в одну на группу | оставляет и добавляет итоговые записи |
| Где считается | в основном запросе | дополнительным расчётом поверх результата |
| Детали после выполнения | недоступны | доступны под своим итогом |

Обе секции часто встречаются в одном запросе. Сначала `СГРУППИРОВАТЬ ПО` получает строки «объект — материал — потребность», затем `ИТОГИ` добавляет над ними итоги по объектам.

## Общий итог

Слово `ОБЩИЕ` в списке контрольных точек добавляет итог по всему результату:

```bsl
ИТОГИ
	СУММА(Потребность)
ПО
	ОБЩИЕ,
	ОбъектСтроительства
```

Теперь у результата три уровня: общий итог, итоги по объектам, детальные записи. Порядок контрольных точек задаёт порядок вложенности: первая — самая внешняя.

## Обход по группировкам

Результат с итогами — это дерево: общий итог, в нём объекты, в каждом объекте материалы. Обходить его удобно уровень за уровнем, и для этого у метода `Выбрать` есть параметр — **вид обхода**.

```bsl
ВыборкаОбъекты = Результат.Выбрать(ОбходРезультатаЗапроса.ПоГруппировкам);
Пока ВыборкаОбъекты.Следующий() Цикл
	// Итоговая запись объекта.
	ВыборкаМатериалы = ВыборкаОбъекты.Выбрать();
	Пока ВыборкаМатериалы.Следующий() Цикл
		// Детальные записи этого объекта.
	КонецЦикла;
КонецЦикла;
```

`ОбходРезультатаЗапроса.ПоГруппировкам` возвращает записи **только верхнего уровня** — итоговые записи первой контрольной точки. У каждой такой записи есть свой метод `Выбрать()`, который возвращает **вложенную выборку** — записи следующего уровня внутри этой группы. На последнем уровне вложенная выборка возвращает детальные записи.

Если вложенной выборке тоже передать `ОбходРезультатаЗапроса.ПоГруппировкам`, она вернёт следующий уровень итогов, а не детали. Так обходят три уровня: общий итог → объекты → материалы.

Для сравнения: `ОбходРезультатаЗапроса.Прямой` — вид обхода по умолчанию. Он возвращает все записи подряд — итоговые и детальные вперемешку, в порядке дерева, и отличать их приходится самому. Для вывода сводки удобнее обход по группировкам.

## Где место итогам

Итоги — инструмент **представления** ответа: они нужны, когда человек читает сводку сверху вниз. Для расчётов внутри программы они не нужны: если коду нужна сумма по объекту, её получают группировкой, а не итоговой записью.

Полноценные отчёты с итогами, группировками и настройками пользователя в 1С строят другим механизмом — системой компоновки данных, ей посвящён этап 6. Но в её основе тот же запрос, и понимание контрольных точек и уровней понадобится там напрямую.

## Что важно запомнить

1. `ИТОГИ … ПО` добавляет итоговые записи к детальным, а `СГРУППИРОВАТЬ ПО` сворачивает строки.
2. После `ПО` перечисляют контрольные точки; `ОБЩИЕ` добавляет итог по всему результату.
3. Порядок контрольных точек задаёт вложенность уровней.
4. `ОбходРезультатаЗапроса.ПоГруппировкам` возвращает записи одного уровня, а метод `Выбрать()` записи — вложенную выборку следующего уровня.
5. Итоги нужны для показа сводки человеку; для расчётов в коде используют группировку.
