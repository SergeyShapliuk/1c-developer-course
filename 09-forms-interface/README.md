# Занятие 9. Управляемые формы и командный интерфейс

## Цель

Перейти от автогенерируемых форм к собственным: понять устройство управляемой формы, научиться группировать поля, выводить колонки в список и добавлять на форму команду. Подготовить площадку для работы со встроенным языком.

## Результат занятия

У справочника «Клиенты» появится собственная форма элемента с группой «Контакты», у справочника «Товары» — форма списка с колонками артикула и цены. Будет создана обработка «Учебная консоль» с формой и кнопкой «Выполнить», включённая в раздел «Разработка». Обработчик команды останется пустым — код мы начнём писать на занятии 11.

## Маршрут

1. Прочитайте [теорию](theory.md) — около 25 минут.
2. Выполните [практику](practice.md) — около 70 минут.
3. Ответьте на контрольные вопросы в конце практики, не подглядывая в теорию.

## Ключевые термины

Управляемое приложение, панель разделов, панель навигации, панель действий, управляемая форма, форма элемента, форма списка, основная форма, редактор формы, реквизиты формы, элементы формы, команда формы, группа элементов, обработка, обработчик команды.
