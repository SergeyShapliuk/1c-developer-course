# Занятие 106. Тест-кейсы на проведение и остатки

## Цель

Научиться проверять прикладную логику не на глаз, а по заранее написанным тест-кейсам: с набором тестовых данных, шагами и ожидаемым результатом в числах, рассчитанным до прогона. Разобраться, зачем нужна отдельная тестовая база, что такое регрессионный набор и как записывают результат прогона.

## Результат занятия

В тестовой базе `УСК_Тест`, восстановленной из `.dt`, появится свой набор данных: «Склад испытаний», материал «Доска обрезная», объект «ЖК Пробный». В конспекте — десять тест-кейсов на цепочку «Поступление → Передача → остаток» и на задачу «Завершённые объекты», ожидаемые остатки для каждого шага, протокол прогона с фактическими результатами и регрессионный набор, который нужно повторять при каждой следующей версии.

## Маршрут

1. Прочитайте [теорию](theory.md) — около 25 минут.
2. Выполните [практику](practice.md) — около 70 минут.
3. Ответьте на контрольные вопросы в конце практики, не подглядывая в теорию.

## Ключевые термины

Тестирование, тест-кейс, идентификатор тест-кейса, предусловие, набор тестовых данных, ожидаемый результат, фактический результат, статус прогона, сценарий из связанных тест-кейсов, тестовая база, протокол прогона, регрессия, регрессионный набор.
