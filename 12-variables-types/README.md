# Занятие 12. Переменные, типы и преобразование значений

## Цель

Научиться хранить значения в переменных, различать примитивные типы, узнавать тип значения во время выполнения и безопасно преобразовывать одно к другому.

## Результат занятия

Обработка `УчебнаяКонсоль` считает сумму по переменным, превращает текст в число, выводит тип шести разных значений, проверяет заполненность и воспроизводит типичную ошибку преобразования. Вы знаете, почему `Число("12,5")` падает, а `Число("12.5")` — нет.

## Маршрут

1. Прочитайте [теорию](theory.md) — около 25 минут.
2. Выполните [практику](practice.md) — около 50 минут.
3. Ответьте на контрольные вопросы в конце практики, не подглядывая в теорию.

## Ключевые термины

Переменная, `Перем`, присваивание, тип значения, `ТипЗнач()`, `Тип()`, примитивные типы, `Число()`, `Строка()`, `Дата()`, `Булево()`, `СтрЗаменить()`, `Неопределено`, `ЗначениеЗаполнено()`, значение перечисления.
