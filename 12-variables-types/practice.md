# Практика. Переменные, типы и преобразования

## Перед началом

Как и на занятии 11, работаем в одном месте. В дереве конфигурации откройте **Обработки → УчебнаяКонсоль**, затем её форму и вкладку **Модуль**. Весь код пишем внутри процедуры `Выполнить`:

```bsl
&НаКлиенте
Процедура Выполнить(Команда)

КонецПроцедуры
```

После каждой правки: `Ctrl+S`, затем `F5`, затем в приложении раздел **Разработка → Учебная консоль** и кнопка **Выполнить**. Сообщения появятся в нижней части окна приложения. Дальше — коротко: «сохраните, запустите и нажмите **Выполнить**».

Код предыдущего занятия можно удалить: каждый шаг сегодня начинаем с чистой процедуры, если не сказано иначе.

## Шаг 1. Переменные и сумма

Объявим переменные явно и посчитаем сумму.

```bsl
&НаКлиенте
Процедура Выполнить(Команда)

	Перем Количество;
	Перем Цена;
	Перем Сумма;

	Количество = 20;
	Цена = 12.5;
	Сумма = Количество * Цена;

	Сообщить("Количество: " + Строка(Количество));
	Сообщить("Цена: " + Строка(Цена));
	Сообщить("Сумма: " + Строка(Сумма));

КонецПроцедуры
```

Все три `Перем` стоят в самом начале процедуры — так требует платформа. Попробуйте для интереса перенести `Перем Сумма;` после строки `Количество = 20;` и выполнить **Конфигурация → Проверка → Синтаксический контроль**: контроль сообщит об ошибке. Верните объявление на место.

**Проверка:** выведены три сообщения, последнее — «Сумма: 250».

## Шаг 2. Текст в число через нормализацию

Часто число приходит текстом — например, его ввёл пользователь, и ввёл неаккуратно. Полагаться на то, что строка уже в нужном виде, нельзя: представление чисел зависит от региональных настроек базы. Поэтому строку сначала нормализуют, а потом преобразуют.

Добавьте в конец процедуры:

```bsl
ЦенаТекстом = "12.5";
Сообщить("Уже в нужном виде: " + Строка(Число(ЦенаТекстом) * 2));

ВводПользователя = "  12,5  ";
Нормализованная = СокрЛП(ВводПользователя);                  // убрали пробелы по краям
Нормализованная = СтрЗаменить(Нормализованная, ",", ".");    // привели разделитель
Сообщить("После нормализации: " + Строка(Число(Нормализованная) * 2));
```

Сохраните, запустите и нажмите **Выполнить**. Оба сообщения должны показать 25.

Обратите внимание на порядок: сначала `СокрЛП()`, потом `СтрЗаменить()`. Если сделать наоборот, пробелы останутся и преобразование может не пройти.

**Проверка:** оба сообщения выводят 25, и вы можете объяснить, зачем нужна каждая из двух строк нормализации.

## Шаг 3. Приведение регистра

`ВРег()` и `НРег()` меняют регистр строки, и это понадобится, когда данные вводили разные люди. Добавьте:

```bsl
Артикул1 = " цем-500 ";
Артикул2 = "ЦЕМ-500";

Сообщить("Как ввели: [" + Артикул1 + "] и [" + Артикул2 + "]");
Сообщить("Совпадают до нормализации: " + Строка(Артикул1 = Артикул2));

Ключ1 = ВРег(СокрЛП(Артикул1));
Ключ2 = ВРег(СокрЛП(Артикул2));

Сообщить("Совпадают после нормализации: " + Строка(Ключ1 = Ключ2));
```

Сохраните, запустите и нажмите **Выполнить**. До нормализации строки не равны, после — равны. Именно так один и тот же артикул перестаёт выглядеть как два разных.

**Проверка:** первое сравнение даёт `Ложь`, второе — `Истина`.

## Шаг 4. Шесть типов

Выведем тип шести разных значений. Замените текст процедуры на такой:

```bsl
Сообщить(Строка(ТипЗнач(250)));
Сообщить(Строка(ТипЗнач("Цемент М500")));
Сообщить(Строка(ТипЗнач('20260101')));
Сообщить(Строка(ТипЗнач(Истина)));
Сообщить(Строка(ТипЗнач(Неопределено)));
Сообщить(Строка(ТипЗнач(Перечисления.ВидыКлиентов.Заказчик)));
```

Последняя строка — не чтение базы данных. Состав перечисления `ВидыКлиентов` задан в конфигурации на занятии 7, поэтому значение `Заказчик` доступно сразу.

**Проверка:** выведено шесть строк: `Число`, `Строка`, `Дата`, `Булево`, `Неопределено`, `ПеречислениеСсылка.ВидыКлиентов`.

## Шаг 5. Сравнение типа

Проверять тип нужно, когда значение могло прийти откуда угодно. Замените текст процедуры:

```bsl
Значение = 250;

Если ТипЗнач(Значение) = Тип("Число") Тогда
	Сообщить("Это число, можно считать: " + Строка(Значение * 2));
КонецЕсли;
```

Здесь впервые встретился оператор `Если`. Подробно условия разберём на занятии 13 — сейчас достаточно прочитать строку как «если тип значения есть Число, тогда сделать то, что внутри».

Теперь поменяйте первую строку на `Значение = "250";` и выполните снова. Сообщение не появится: тип уже не `Число`, а `Строка`, и ветка не сработала.

**Проверка:** с числом сообщение выводится, со строкой — нет.

## Шаг 6. Заполненность

Замените текст процедуры:

```bsl
Сообщить("Пустая строка: " + Строка(ЗначениеЗаполнено("")));
Сообщить("Ноль: " + Строка(ЗначениеЗаполнено(0)));
Сообщить("Пустая дата: " + Строка(ЗначениеЗаполнено('00010101')));
Сообщить("Заполненная строка: " + Строка(ЗначениеЗаполнено("Центральный склад")));
```

`'00010101'` — пустая дата: именно её платформа хранит в незаполненном реквизите типа `Дата`.

**Проверка:** первые три сообщения показывают `Ложь`, последнее — `Истина`.

## Шаг 7. Воспроизведите ошибку преобразования

Эту ошибку вы будете встречать постоянно, поэтому лучше увидеть её сейчас осознанно. Сначала посмотрите, как `+` ведёт себя без ошибки. Замените текст процедуры:

```bsl
Сообщить("Итого: " + 100);
Сообщить(Строка(100 + "5"));
```

Сохраните, запустите и нажмите **Выполнить**. Первое сообщение — «Итого: 100»: слева строка, и платформа превратила число в строку. Второе — «105»: слева число, и строку `"5"` платформа превратила в число и сложила. Порядок операндов поменял смысл операции.

Теперь поставьте число слева от текста:

```bsl
Сообщить(100 + " шт.");
```

Запустите и нажмите **Выполнить**. Приложение сообщит: «Преобразование значения к типу Число не может быть выполнено». Слева число — значит, платформа складывает и пытается превратить « шт.» в число, а это невозможно.

Исправьте:

```bsl
Сообщить(Строка(100) + " шт.");
```

**Проверка:** первые два сообщения — «Итого: 100» и «105»; третья строка кода завершилась ошибкой преобразования к типу Число, после исправления выводится «100 шт.».

## Проверка результата

Занятие пройдено, если выполняются пять условий:

1. Вы умеете объявить переменную словом `Перем` и знаете, где в процедуре стоят объявления.
2. Вы вывели тип шести значений, включая `Неопределено` и значение перечисления, и можете назвать их словами.
3. Вы получили число из неаккуратного текста через `СокрЛП()` и `СтрЗаменить()` и понимаете, почему на представление чисел нельзя полагаться.
4. Вы привели два по-разному написанных артикула к одному виду через `ВРег()` и `СокрЛП()`.
5. Вы увидели, что тип результата `+` задаёт левый операнд, воспроизвели ошибку «Преобразование значения к типу Число не может быть выполнено» и исправили её явным `Строка()`.
