# Практика. Переменные, типы и преобразования

## Перед началом

Как и на занятии 11, работаем в одном месте. В дереве конфигурации откройте **Обработки → УчебнаяКонсоль**, затем её форму и вкладку **Модуль**. Весь код пишем внутри процедуры `Выполнить`:

```bsl
&НаКлиенте
Процедура Выполнить(Команда)

КонецПроцедуры
```

После каждой правки: `Ctrl+S`, затем `F5`, затем в приложении раздел **Разработка → Учебная консоль** и кнопка **Выполнить**. Сообщения появятся в нижней части окна приложения. Дальше — коротко: «сохраните, запустите и нажмите **Выполнить**».

Код предыдущего занятия можно удалить: каждый шаг сегодня начинаем с чистой процедуры, если не сказано иначе.

## Шаг 1. Переменные и сумма

Объявим переменные явно и посчитаем сумму.

```bsl
&НаКлиенте
Процедура Выполнить(Команда)

	Перем Количество;
	Перем Цена;
	Перем Сумма;

	Количество = 20;
	Цена = 12.5;
	Сумма = Количество * Цена;

	Сообщить("Количество: " + Строка(Количество));
	Сообщить("Цена: " + Строка(Цена));
	Сообщить("Сумма: " + Строка(Сумма));

КонецПроцедуры
```

Все три `Перем` стоят в самом начале процедуры — так требует платформа. Попробуйте для интереса перенести `Перем Сумма;` после строки `Количество = 20;` и выполнить **Конфигурация → Проверка → Синтаксический контроль**: контроль сообщит об ошибке. Верните объявление на место.

**Проверка:** выведены три сообщения, последнее — «Сумма: 250».

## Шаг 2. Текст в число

Часто число приходит текстом — например, его ввёл пользователь. Добавьте в конец процедуры:

```bsl
ЦенаТекстом = "12.5";
Сообщить("С точкой: " + Строка(Число(ЦенаТекстом) * 2));

ЦенаСЗапятой = "12,5";
ЦенаИсправленная = СтрЗаменить(ЦенаСЗапятой, ",", ".");
Сообщить("После замены: " + Строка(Число(ЦенаИсправленная) * 2));
```

Теперь проверим, что без замены не получится. Временно добавьте строку:

```bsl
Сообщить(Строка(Число("12,5")));  // эта строка вызовет ошибку
```

Сохраните, запустите и нажмите **Выполнить**. Приложение покажет ошибку преобразования: запятая в преобразуемой строке недопустима. Прочитайте текст ошибки и удалите эту строку.

**Проверка:** оба рабочих сообщения выводят 25, а строка с запятой без `СтрЗаменить` даёт ошибку.

## Шаг 3. Шесть типов

Выведем тип шести разных значений. Замените текст процедуры на такой:

```bsl
Сообщить(Строка(ТипЗнач(250)));
Сообщить(Строка(ТипЗнач("Цемент М500")));
Сообщить(Строка(ТипЗнач('20260101')));
Сообщить(Строка(ТипЗнач(Истина)));
Сообщить(Строка(ТипЗнач(Неопределено)));
Сообщить(Строка(ТипЗнач(Перечисления.ВидыКлиентов.Заказчик)));
```

Последняя строка — не чтение базы данных. Состав перечисления `ВидыКлиентов` задан в конфигурации на занятии 7, поэтому значение `Заказчик` доступно сразу.

**Проверка:** выведено шесть строк: `Число`, `Строка`, `Дата`, `Булево`, `Неопределено`, `ПеречислениеСсылка.ВидыКлиентов`.

## Шаг 4. Сравнение типа

Проверять тип нужно, когда значение могло прийти откуда угодно. Замените текст процедуры:

```bsl
Значение = 250;

Если ТипЗнач(Значение) = Тип("Число") Тогда
	Сообщить("Это число, можно считать: " + Строка(Значение * 2));
КонецЕсли;
```

Здесь впервые встретился оператор `Если`. Подробно условия разберём на занятии 13 — сейчас достаточно прочитать строку как «если тип значения есть Число, тогда сделать то, что внутри».

Теперь поменяйте первую строку на `Значение = "250";` и выполните снова. Сообщение не появится: тип уже не `Число`, а `Строка`, и ветка не сработала.

**Проверка:** с числом сообщение выводится, со строкой — нет.

## Шаг 5. Заполненность

Замените текст процедуры:

```bsl
Сообщить("Пустая строка: " + Строка(ЗначениеЗаполнено("")));
Сообщить("Ноль: " + Строка(ЗначениеЗаполнено(0)));
Сообщить("Пустая дата: " + Строка(ЗначениеЗаполнено('00010101')));
Сообщить("Заполненная строка: " + Строка(ЗначениеЗаполнено("Центральный склад")));
```

`'00010101'` — пустая дата: именно её платформа хранит в незаполненном реквизите типа `Дата`.

**Проверка:** первые три сообщения показывают `Ложь`, последнее — `Истина`.

## Шаг 6. Воспроизведите ошибку преобразования

Эту ошибку вы будете встречать постоянно, поэтому лучше увидеть её сейчас осознанно. Замените текст процедуры:

```bsl
Сообщить("Итого: " + 100);
```

Сохраните, запустите и нажмите **Выполнить**. Приложение сообщит: «Преобразование значения к типу Строка не может быть выполнено». Причина — слева от `+` строка, справа число, и платформа не берётся угадывать, чего вы хотели.

Исправьте:

```bsl
Сообщить("Итого: " + Строка(100));
```

**Проверка:** после исправления выводится «Итого: 100», ошибки нет.

## Проверка результата

Занятие пройдено, если выполняются четыре условия:

1. Вы умеете объявить переменную словом `Перем` и знаете, где в процедуре стоят объявления.
2. Вы вывели тип шести значений, включая `Неопределено` и значение перечисления, и можете назвать их словами.
3. Вы знаете, почему `Число("12,5")` падает, и умеете обойти это через `СтрЗаменить()`.
4. Вы воспроизвели ошибку «Преобразование значения к типу Строка не может быть выполнено» и исправили её.
