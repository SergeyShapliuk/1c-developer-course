# Теория. Переменные и типы значений

## Переменная

**Переменная** — имя, под которым хранится значение. Чтобы значение можно было использовать дальше, его **присваивают** переменной знаком `=`:

```bsl
Перем Количество;  // объявление: имя есть, значения пока нет
Количество = 20;   // присваивание
```

Объявлять переменную словом `Перем` не обязательно: она появится сама при первом присваивании. Но явное объявление читается лучше: сверху процедуры виден список участвующих величин, а опечатка в имени при неявном объявлении просто создаёт новую переменную вместо ошибки — написали `Количесвто = 20`, и платформа послушно завела ещё одну.

Объявления `Перем` размещают в самом начале процедуры, до первого оператора.

## Тип принадлежит значению, а не переменной

В 1С у переменной нет закреплённого типа. Тип есть у **значения**, которое в ней лежит прямо сейчас:

```bsl
Значение = 20;        // сейчас внутри число
Значение = "двадцать"; // а теперь строка, и это допустимо
```

Отсюда правило: если значение могло прийти откуда-то извне, его тип приходится проверять во время работы программы, а не рассчитывать на него заранее.

## ТипЗнач() и Тип()

`ТипЗнач(Значение)` возвращает тип того, что лежит в значении. `Тип("Число")` возвращает тип по его имени. Сравнение этих двух и даёт проверку:

```bsl
Сообщить(Строка(ТипЗнач(20)));   // Число
Сообщить(Строка(ТипЗнач("20"))); // Строка
```

## Примитивные типы

Основных примитивных типов четыре: `Число`, `Строка`, `Дата`, `Булево`. Это те же самые типы, которые вы выбирали на занятии 8, когда задавали тип реквизита справочника: `Телефон` получил тип `Строка`, `Цена` — `Число`, `ДатаПриёма` — `Дата`. Язык и метаданные здесь говорят одними словами.

## Преобразования

Для перевода значения из одного типа в другой есть четыре функции: `Строка()`, `Число()`, `Дата()`, `Булево()`.

```bsl
Сообщить(Строка(Число("12.5") * 2)); // 25
```

`Число("12.5")` работает, а `Число("12,5")` вызывает ошибку: десятичный разделитель в коде и в преобразуемой строке — точка, запятая не подходит. Если текст пришёл с запятой, её сначала заменяют:

```bsl
Текст = "12,5";
Текст = СтрЗаменить(Текст, ",", ".");  // стало "12.5"
Сообщить(Строка(Число(Текст)));         // 12,5 — так число выводится на экран
```

`СтрЗаменить(Где, Что, НаЧто)` возвращает новую строку, в которой все вхождения заменены.

## Почему «Итого: » + 100 падает

Оператор `+` не догадывается, чего вы хотели. Слева строка — значит, он пытается привести к строке и правую часть, а сложение строки с числом платформа выполнять отказывается и выдаёт: «Преобразование значения к типу Строка не может быть выполнено». Правильно — преобразовать явно:

```bsl
Сообщить("Итого: " + Строка(100));
```

## Неопределено и ЗначениеЗаполнено()

`Неопределено` — отдельное значение со смыслом «ничего не задано». Его возвращают функции, которым нечего вернуть, и оно же лежит в переменной формы, которую ещё не заполнили.

`ЗначениеЗаполнено(Значение)` отвечает, заполнено ли значение, и понимает все типы сразу: пустая строка, ноль, пустая дата, `Неопределено` и пустая ссылка — не заполнены; всё остальное заполнено.

```bsl
Сообщить(Строка(ЗначениеЗаполнено("")));     // Ложь
Сообщить(Строка(ЗначениеЗаполнено("Склад"))); // Истина
```

Пустая строка и `Неопределено` — разные вещи. `""` — это строка, просто без символов. `Неопределено` — вообще не строка, а признак отсутствия значения.

## Значение перечисления

На занятии 7 вы создали перечисление `ВидыКлиентов` со значениями `Заказчик`, `Поставщик`, `Подрядчик`, а на занятии 8 реквизит `ВидКлиента` получил тип `ПеречислениеСсылка.ВидыКлиентов`.

Во встроенном языке к любому из этих значений обращаются так:

```bsl
Вид = Перечисления.ВидыКлиентов.Заказчик;
Сообщить(Строка(ТипЗнач(Вид))); // ПеречислениеСсылка.ВидыКлиентов
```

Важно понять: это **значение**, а не чтение базы данных. Состав перечисления задан в конфигурации, он не меняется при работе пользователей, поэтому платформе не нужно никуда обращаться — значение просто есть. Поэтому такую запись можно использовать уже сейчас, задолго до занятий 19–20, где начнётся настоящая работа с данными.

## Что важно запомнить

1. Переменная — имя для значения; `Перем` объявляет её явно и защищает от опечаток.
2. Тип принадлежит значению, а не переменной: в одну переменную можно положить сначала число, потом строку.
3. `ТипЗнач(Х)` даёт тип значения, `Тип("Число")` — тип по имени; сравнение этих двух и есть проверка типа.
4. Преобразования делают явно: `Строка()`, `Число()`, `Дата()`, `Булево()`.
5. `Число("12,5")` — ошибка; запятую сначала меняют на точку через `СтрЗаменить()`.
6. `Неопределено` — это «значение не задано», и это не пустая строка; универсальная проверка — `ЗначениеЗаполнено()`.
7. `Перечисления.ВидыКлиентов.Заказчик` — готовое значение ссылочного типа, обращения к базе здесь нет.
