# Занятие 37. Связь документов

## Цель

Понять, зачем документ должен помнить, из какого документа он создан, и научиться хранить эту связь реквизитом типа `ДокументСсылка`, а не полагаться на совпадение данных.

## Результат занятия

У документа `ПоступлениеМатериалов` появится реквизит `ДокументОснование` типа `ДокументСсылка.ЗаявкаНаМатериалы`, который заполняется при вводе на основании из занятия 36 и выводится на форму только для просмотра. Из поступления можно будет открыть заявку одним щелчком, из заявки — увидеть список связанных документов, а запись поступления по отклонённой заявке конфигурация запретит.

## Маршрут

1. Прочитайте [теорию](theory.md) — около 25 минут.
2. Выполните [практику](practice.md) — около 60 минут.
3. Ответьте на контрольные вопросы в конце практики, не подглядывая в теорию.

## Ключевые термины

Связь документов, документ-основание, прослеживаемость, `ДокументСсылка`, `ДокументОснование`, структура подчинённости, **Связанные документы**, `ОбработкаПроверкиЗаполнения`, `Отказ`, разыменование.
