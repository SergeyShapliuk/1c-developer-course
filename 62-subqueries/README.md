# Занятие 62. Вложенные запросы

## Цель

Научиться использовать результат одного запроса внутри другого: как список значений в условии и как источник данных в секции `ИЗ`. Довести до конца исправление «исполнения заявки»: сначала сложить заказанное и поступившее по материалу, потом соединять. Понять, почему вложенные запросы трудно читать и проверять.

## Результат занятия

В обработке `УчебнаяКонсоль` появятся две процедуры. Первая находит рабочие заявки, по которым ещё не было ни одного проведённого поступления. Вторая выводит исполнение заявок правильно при любом числе строк и поступлений: заказанное и поступившее складываются по заявке и материалу во вложенных запросах, а затем соединяются.

## Маршрут

1. Прочитайте [теорию](theory.md) — около 25 минут.
2. Выполните [практику](practice.md) — около 55 минут.
3. Ответьте на контрольные вопросы в конце практики, не подглядывая в теорию.

## Ключевые термины

Вложенный запрос, вложенный запрос в условии, `В (ВЫБРАТЬ …)`, `НЕ В`, вложенный запрос в источнике, псевдоним вложенного запроса, предварительная группировка, читаемость запроса.
