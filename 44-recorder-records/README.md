# Занятие 44. Регистратор и движения

## Цель

Понять, кто имеет право менять состояние учёта: разобраться, что такое движение регистра, почему движения принадлежат документу, а не регистру, и что означает слово «регистратор». Связать документ `ПоступлениеМатериалов` с регистром `ОстаткиМатериалов`.

## Результат занятия

Документ `ПоступлениеМатериалов` станет регистратором регистра накопления `ОстаткиМатериалов`, структуру которого мы спроектировали в занятии 43. У документа появится вкладка **Движения** с отмеченным регистром, а у регистра — непустой список регистраторов. Записей в регистре по-прежнему не будет: связь только разрешает документу создавать движения, а создавать их мы научимся в занятии 46.
