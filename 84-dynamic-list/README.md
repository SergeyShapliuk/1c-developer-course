# Занятие 84. Динамический список и своя форма списка

## Цель

Научиться делать журнал документов, который отвечает на вопросы пользователя без открытия каждого документа. Понять, что такое динамический список, почему он не загружает все документы сразу, когда ему нужен произвольный запрос и какую цену за вычисляемую колонку платят на больших данных.

## Результат занятия

У документа `ЗаявкаНаМатериалы` появится своя форма списка `ФормаСписка`. Журнал **Логистика → Заявки на материалы** покажет по каждой заявке дату, номер, объект строительства, состояние, приоритет, ответственного, число строк материалов и сумму заявки. Сумма считается запросом динамического списка из строк табличной части и совпадает с итогом в форме заявки. Сортировка, поиск и создание документов работают, как в стандартном журнале.

## Маршрут

1. Прочитайте [теорию](theory.md) — около 25 минут.
