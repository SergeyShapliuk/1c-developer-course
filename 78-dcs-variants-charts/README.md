# Занятие 78. Варианты отчёта и диаграмма

## Цель

Понять, как один отчёт отвечает разным пользователям по-разному, не превращаясь в несколько отчётов с одинаковым запросом. Научиться создавать варианты отчёта со своей структурой и настройками, выводить ресурс диаграммой и выбирать, где картинка помогает, а где мешает.

## Результат занятия

У отчёта `ВыдачаПоОбъектам` будет три варианта: «Материалы по объектам» — кросс-таблица занятия 76, «Объекты по месяцам» и «Диаграмма выдачи» — гистограмма, где по каждому объекту столбцы материалов. У отчёта `ОстаткиНаСкладах` появится второй вариант «По материалам» со структурой «Материал → Склад» из занятия 71. Пользователь переключает варианты в форме отчёта, а набор данных у всех вариантов один.
