# Занятие 83. Вопрос пользователю и описание оповещения

## Цель

Научиться спрашивать пользователя перед необратимым действием так, как этого требует платформа: без модального окна, через `ПоказатьВопрос` и описание оповещения. Понять, почему код после `ПоказатьВопрос` не ждёт ответа, куда переносится продолжение действия и когда вопрос вообще стоит задавать.

## Результат занятия

Команда **Отклонить** в форме заявки сначала спрашивает «Отклонить заявку?» и отклоняет её только после ответа «Да». Команда **Заполнить цены** спрашивает подтверждение, только если в строках уже есть цены, которые будут заменены; пустые цены она заполняет без вопроса. Продолжение каждой команды живёт в отдельной экспортной процедуре-обработчике оповещения.

## Маршрут

1. Прочитайте [теорию](theory.md) — около 25 минут.
2. Выполните [практику](practice.md) — около 45 минут.
3. Ответьте на контрольные вопросы в конце практики, не подглядывая в теорию.

## Ключевые термины

Модальное окно, немодальный диалог, `ПоказатьВопрос`, `ПоказатьПредупреждение`, `ОписаниеОповещения`, обработчик оповещения, `Экспорт`, `РежимДиалогаВопрос`, `КодВозвратаДиалога`, дополнительные параметры оповещения.
