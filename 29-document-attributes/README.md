# Занятие 29. Реквизиты документа и выбор типов

## Цель

Научиться выбирать тип для каждого реквизита документа и обосновывать выбор: почему объект строительства — ссылка на справочник, приоритет — перечисление, а комментарий — строка. Понять цену составного типа и назначение свойства **Проверка заполнения**.

## Результат занятия

В конфигурации появится перечисление `ПриоритетыЗаявок` со значениями `Низкий`, `Обычный`, `Срочный` и четыре реквизита документа `ЗаявкаНаМатериалы`: `ОбъектСтроительства`, `Ответственный`, `Приоритет`, `Комментарий`. В приложении заявка перестанет быть пустой: вы заполните её по объекту «ЖК Северный» и увидите, что платформа сама предложила список объектов и список приоритетов. Табличная часть `Материалы` появится в занятии 31.

## Маршрут

1. Прочитайте [теорию](theory.md) — около 25 минут.
2. Выполните [практику](practice.md) — около 60 минут.
3. Ответьте на контрольные вопросы в конце практики, не подглядывая в теорию.

## Ключевые термины

Реквизит документа, ссылочный тип, `СправочникСсылка.ОбъектыСтроительства`, `СправочникСсылка.Сотрудники`, перечисление, `ПеречислениеСсылка.ПриоритетыЗаявок`, неограниченная длина строки, составной тип, **Проверка заполнения**, значение по умолчанию.
