# Занятие 75. Периоды в отчёте: оборотная ведомость

## Цель

Перенести оборотную ведомость склада из учебной консоли в отчёт, где период выбирает пользователь. Понять, как система компоновки работает с таблицей остатков и оборотов: откуда берутся параметры начала и конца периода, как стандартный период управляет ими, что даёт периодичность `Авто` и почему начальный остаток месяца нельзя получить суммой начальных остатков дней.

## Результат занятия

В конфигурации появится отчёт `ОборотнаяВедомостьМатериалов` в разделе **Логистика**. Пользователь выбирает период одним полем «Период», отчёт показывает по складу и материалу начальный остаток, приход, расход и конечный остаток, а при необходимости раскладывает обороты по дням и по документам. Двойной щелчок по документу открывает его. Числа совпадают с ведомостью и карточкой материала занятия 66.

## Ключевые термины

Таблица остатков и оборотов в отчёте, `НачалоПериода`, `КонецПериода`, стандартный период, `СтандартныйПериод`, выражение параметра, ограничение доступности, периодичность `Авто`, `ПериодДень`, `ПериодМесяц`, `Регистратор`, роль поля, остаток, расшифровка.
