# Теория. Запросы и отчёты на одной странице

## Какую задачу мы решаем

Запросы — тема, в которой экзамен особенно любит ловушки: почти каждый вопрос предлагает два ответа, которые оба «работают», но дают разное число строк. На этапах 5–6 вы видели это на своих данных — справка снабженца расходилась с отчётом, пока условие не переехало в параметры виртуальной таблицы. На экзамене данных нет, и разницу нужно увидеть в тексте запроса.

Страница собирает правила запросов и схемы компоновки в утверждения с ловушками. Эксперимент практики — три запроса к одной и той же паре таблиц, которые отличаются только местом условия.

## Текст запроса

| Утверждение | Ловушка | Занятие |
| --- | --- | --- |
| Запрос выполняется на сервере; параметр в тексте обозначают `&Имя` и задают методом `УстановитьПараметр` | склеивать значения в текст запроса | 53, 55 |
| Ошибку в тексте запроса видно только при выполнении | ждать её от синтаксического контроля модуля | 54 |
| `ПЕРВЫЕ` без `УПОРЯДОЧИТЬ ПО` возвращает какие-то строки, а не первые по смыслу | брать «первые пять» без сортировки | 56 |
| Обращение через точку к реквизиту ссылки — неявное соединение с таблицей объекта | считать его бесплатным | 57 |
| `NULL` — «значения нет»; `ЕСТЬNULL(Поле, 0)` подставляет замену | сравнивать с `NULL` знаком `=` | 57 |

## Соединения, группировка, объединение

| Утверждение | Ловушка | Занятие |
| --- | --- | --- |
| Левое соединение сохраняет все строки левой таблицы; у строк без пары поля правой — `NULL` | ждать нулей вместо `NULL` | 58 |
| Условие на правую таблицу в `ГДЕ` отбрасывает строки без пары — соединение фактически становится внутренним; в `ПО` оно только сужает пары | переносить условие из `ПО` в `ГДЕ` «для красоты» | 58 |
| Каждое поле `ВЫБРАТЬ` без агрегатной функции должно быть в `СГРУППИРОВАТЬ ПО` | группировать не по всем неагрегированным полям | 59 |
| `ГДЕ` отбирает строки до группировки, `ИМЕЮЩИЕ` — группы после | писать условие на `СУММА` в `ГДЕ` | 59 |
| `ОБЪЕДИНИТЬ` убирает повторы, `ОБЪЕДИНИТЬ ВСЕ` — нет; у частей одинаковое число полей | терять строки, считая суммы через `ОБЪЕДИНИТЬ` | 60 |
| `ПОМЕСТИТЬ` сохраняет результат во временную таблицу, которую видят следующие запросы пакета | ждать её в другом запросе без общего менеджера | 63 |

## Виртуальные таблицы и контроль

| Утверждение | Ловушка | Занятие |
| --- | --- | --- |
| Условие на измерения виртуальной таблицы ставят в её параметры: результат тот же, что с `ГДЕ`, но платформа не считает лишнего; условие на ресурс среза последних ставят в `ГДЕ` | перенести в параметры условие на ресурс — тогда срез возьмёт уже не действующее значение | 64, 65 |
| Таблица остатков не возвращает строк с нулевым остатком | ждать строку с `0` | 65 |
| `Остатки(&Момент)` даёт остаток до момента; движения самого документа учитывает граница `Новый Граница(МоментВремени(), ВидГраницы.Включая)` | брать момент документа без границы | 65, 67 |
| Таблица остатков и оборотов даёт начальный остаток, обороты и конечный остаток за период | собирать то же из двух запросов | 66 |
| Современный контроль остатков: записать движения, затем найти отрицательные остатки | сравнивать количество строк документа с остатком до записи | 67 |

## Система компоновки данных

| Утверждение | Ловушка | Занятие |
| --- | --- | --- |
| Ресурс схемы считает итоги групп по своему выражению; поле без ресурса итогов не имеет | ждать итога у обычного поля | 70 |
| Параметр данных передаёт значение в запрос, например в параметры виртуальной таблицы; отбор накладывается на поля результата | задавать дату остатков отбором | 72 |
| Остатки за период не складывают: итог конечного остатка за квартал — остаток на конец квартала | суммировать остатки по месяцам | 75 |
| Вычисляемое поле схемы считается системой компоновки, а не запросом | путать его с выражением в тексте запроса | 74 |
| В `ПриКомпоновкеРезультата` отчёт строят кодом, установив `СтандартнаяОбработка = Ложь` | забыть флаг и получить отчёт дважды или не получить вовсе | 79 |

## Что важно запомнить

1. Параметр — `&Имя` и `УстановитьПараметр`; ошибка текста запроса видна только при выполнении.
2. Левое соединение даёт `NULL` у строк без пары; условие на правую таблицу в `ГДЕ` делает его внутренним.
3. Неагрегированные поля — в `СГРУППИРОВАТЬ ПО`; условие на агрегат — в `ИМЕЮЩИЕ`.
4. `ОБЪЕДИНИТЬ` убирает повторы, `ОБЪЕДИНИТЬ ВСЕ` — нет.
5. Условия на измерения — в параметры виртуальной таблицы, условие на ресурс среза — в `ГДЕ`; нулевые остатки таблица не возвращает.
6. Движения документа в его момент учитывает граница «Включая».
7. Контроль остатков: сначала записать движения, потом искать минус.
8. Параметр данных — в запрос, отбор — на результат; остатки за период не складывают.
