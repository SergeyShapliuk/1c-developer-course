## Шаг 1. Решите билет

**1.** Как в тексте запроса обозначается параметр?

- А) `#Склад`
- Б) `?Склад`
- В) `$Склад`
- Г) `&Склад`

**2.** Таблица материалов соединена с таблицей остатков левым соединением. Что будет в полях таблицы остатков у материала, которого на складе нет?

- А) `0`
- Б) `NULL`
- В) Пустая строка
- Г) Строки этого материала в результате не будет

**3.** В запросе с левым соединением материалов и остатков в `ГДЕ` добавили условие `Остатки.КоличествоОстаток > 0`. Что изменилось?

- А) Пропали материалы без остатка: соединение фактически стало внутренним
- Б) Ничего: условие на правую таблицу в `ГДЕ` и в `ПО` равнозначно
- В) Запрос перестанет выполняться
- Г) У материалов без остатка количество станет `0`

**4.** Запрос группирует по складу и выбирает поля `Склад`, `Материал` и `СУММА(Количество)`. Что не так?

- А) Ничего
- Б) `СУММА` нельзя использовать с группировкой
- В) `Материал` не обёрнут агрегатной функцией и должен быть в `СГРУППИРОВАТЬ ПО`
- Г) Группировать можно только по одному полю, и оно должно быть первым

**5.** Нужно оставить только склады, где суммарное количество больше 100. Где поставить условие `СУММА(Количество) > 100`?

- А) В `ГДЕ`
- Б) В `ИМЕЮЩИЕ`
- В) В `ПО`
- Г) В `УПОРЯДОЧИТЬ ПО`

**6.** Два запроса объединены `ОБЪЕДИНИТЬ`. В результатах обоих есть одинаковая строка. Сколько раз она попадёт в итог?

- А) Один раз
- Б) Два раза
- В) Ни разу
- Г) Запрос завершится ошибкой

**7.** Что делает платформа, когда запрос обращается к `Материалы.Материал.ЕдиницаИзмерения`?

- А) Выполняет отдельный запрос на каждую строку
- Б) Обращение через точку в запросе недопустимо
- В) Берёт значение из кэша формы
- Г) Неявно соединяет таблицу с таблицей справочника материалов

**8.** Запрос `ВЫБРАТЬ ПЕРВЫЕ 5 Наименование ИЗ Справочник.Товары` без `УПОРЯДОЧИТЬ ПО`. Какие пять элементов он вернёт?

- А) Первые пять по алфавиту
- Б) Первые пять по коду
- В) Какие-то пять элементов; порядок не гарантирован
- Г) Последние созданные пять элементов

**9.** Первый запрос пакета заканчивается словом `ПОМЕСТИТЬ ВТ_Материалы`. Где можно использовать `ВТ_Материалы`?

- А) В следующих запросах того же пакета
- Б) Только в этом же запросе
- В) В любом запросе базы до перезапуска сервера
- Г) Только в отчётах системы компоновки данных

**10.** Нужны последние цены только материалов документа. Где поставить условие `Материал В (&Материалы)`?

- А) В `ГДЕ` после виртуальной таблицы среза последних
- Б) В параметрах виртуальной таблицы среза последних
- В) В `ИМЕЮЩИЕ`
- Г) Не важно: результат и скорость одинаковы

**11.** Как в проведении документа получить остаток с учётом движений самого документа, записанных в его момент?

- А) `Остатки(Новый Граница(МоментВремени(), ВидГраницы.Включая))`
- Б) `Остатки(МоментВремени())`
- В) `Остатки(Дата)`
- Г) `Остатки()` без параметров даёт то же самое всегда

**12.** Какой порядок контроля остатков при проведении расходного документа рекомендует современная методика?

- А) Сначала запросить остатки, сравнить со строками документа, затем записать движения
- Б) Записать движения и не проверять: регистр не даст уйти в минус сам
- В) Сначала записать движения, затем запросом найти отрицательные остатки
- Г) Проверять остатки в форме документа перед проведением

**13.** Поле `Количество` в схеме компоновки данных объявлено ресурсом с выражением `Сумма(Количество)`. Что это даёт?

- А) Поле можно выбирать в отборе
- Б) Поле нельзя выводить в детальных записях
- В) Поле становится параметром данных
- Г) В итогах групп отчёта количество суммируется

**14.** Отчёт об остатках должен строиться на дату, которую выбирает пользователь. Как передать эту дату?

- А) Отбором по полю «Период»
- Б) Параметром данных, который подставляется в параметр виртуальной таблицы остатков
- В) Вычисляемым полем
- Г) Условным оформлением

**15.** Отчёт показывает конечный остаток по месяцам квартала. Что должен показать итог за квартал?

- А) Конечный остаток на конец квартала
- Б) Сумму конечных остатков трёх месяцев
- В) Среднее из трёх остатков
- Г) Конечный остаток первого месяца

**Проверка:** на все пятнадцать вопросов записаны ответы, время записано.

## Шаг 3. Проверьте спорное экспериментом

Вопросы 2 и 3 — самые частые ошибки в запросах. Проверим их на данных учебной базы.

1. Откройте отчёт «Остатки на складах» по «Центральному складу» и посчитайте, у скольких материалов остаток больше нуля. Запишите число.
2. Добавьте в модуль формы `УчебнаяКонсоль` серверную процедуру:

```bsl
&НаСервереБезКонтекста
Процедура СравнитьУсловия()

	Склад = Справочники.Склады.НайтиПоНаименованию("Центральный склад");

	Шаблон =
		"ВЫБРАТЬ
		|	Товары.Ссылка КАК Материал,
		|	ЕСТЬNULL(Остатки.КоличествоОстаток, 0) КАК Остаток
		|ИЗ
		|	Справочник.Товары КАК Товары
		|		ЛЕВОЕ СОЕДИНЕНИЕ РегистрНакопления.ОстаткиМатериалов.Остатки(, Склад = &Склад) КАК Остатки
		|		ПО Товары.Ссылка = Остатки.Материал
		|			%ПО
		|ГДЕ
		|	НЕ Товары.ПометкаУдаления
		|	%ГДЕ";

	Варианты = Новый Соответствие;
	Варианты.Вставить("Без условия", Новый Структура("ПО, ГДЕ", "", ""));
	Варианты.Вставить("Условие в ПО", Новый Структура("ПО, ГДЕ", "И Остатки.КоличествоОстаток > 0", ""));
	Варианты.Вставить("Условие в ГДЕ", Новый Структура("ПО, ГДЕ", "", "И Остатки.КоличествоОстаток > 0"));

	Для Каждого Вариант Из Варианты Цикл
		Запрос = Новый Запрос;
		Запрос.Текст = СтрЗаменить(СтрЗаменить(Шаблон, "%ПО", Вариант.Значение.ПО), "%ГДЕ", Вариант.Значение.ГДЕ);
		Запрос.УстановитьПараметр("Склад", Склад);
		Сообщить(Вариант.Ключ + ": строк " + Строка(Запрос.Выполнить().Выгрузить().Количество()));
	КонецЦикла;

КонецПроцедуры
```

Тексту запроса здесь подставляются не значения, а части условия, которые различают варианты; значения по-прежнему идут параметром `&Склад`.

3. Вызовите процедуру из команды консоли и выполните её.
4. Сравните три числа. «Без условия» и «Условие в ПО» совпадают — это все не помеченные на удаление строки справочника: левое соединение сохранило каждую, у материалов без пары `ЕСТЬNULL` дал `0`. «Условие в ГДЕ» меньше и равно числу из пункта 1: материалы без положительного остатка отброшены, как при внутреннем соединении.
5. Удалите процедуру и её вызов, `Ctrl+S`, `F7`, выгрузите конфигурацию и убедитесь, что `git status` чист.

**Проверка:** «Без условия» и «Условие в ПО» дали одинаковое число строк; «Условие в ГДЕ» — меньше, равное числу материалов с положительным остатком из отчёта; `git status` чист.
