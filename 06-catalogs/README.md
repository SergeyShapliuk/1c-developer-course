# Занятие 6. Справочники и элементы справочников

## Цель

Освоить главный объект для хранения данных в 1С — справочник. Понять разницу между справочником и его элементом, разобраться со стандартными полями **Код** и **Наименование** и впервые увидеть разделы приложения в работе.

## Результат занятия

В конфигурации появятся пять справочников: «Клиенты», «Товары», «Сотрудники», «Склады» и «Объекты строительства». Они будут включены в состав подсистем занятия 5, и в работающем приложении наконец появятся разделы. В каждом справочнике будет по одному введённому элементу.

## Маршрут

1. Прочитайте [теорию](theory.md) — около 25 минут.
2. Выполните [практику](practice.md) — около 60 минут.
3. Ответьте на контрольные вопросы в конце практики, не подглядывая в теорию.

## Ключевые термины

Справочник, элемент справочника, стандартный реквизит, Код, Наименование, длина кода, длина наименования, форма списка, форма элемента, иерархический справочник, предопределённый элемент.
