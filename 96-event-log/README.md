# Занятие 96. Журнал регистрации

## Цель

Научиться отвечать на вопрос «кто и когда это сделал»: находить в журнале регистрации проведение, отмену проведения и вход пользователя, отбирать события по пользователю, документу и виду. Понять, что платформа записывает сама, когда нужно писать своё событие, почему его пишут при записи объекта, а не в форме, и почему журнал регистрации — не место для учётных данных.

## Результат занятия

В журнале регистрации вы найдёте, кто провёл и отменил проведение передачи и когда кладовщики входили в программу. Модуль объекта заявки при отклонении запишет в журнал событие `Снабжение.ОтклонениеЗаявки` с заявкой и объектом строительства. Проверка состояния заявки в модуле объекта будет обобщена одной функцией перехода в состояние.
