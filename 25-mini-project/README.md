# Занятие 25. Мини-проект: автоматизация справочника и ручное тестирование

## Цель

Это **контрольная точка** первых двух этапов курса. Нового материала здесь нет: задачу нужно собрать самостоятельно из того, что изучено в занятиях 1–24, а затем проверить свою работу по чек-листу, как это делает разработчик перед сдачей задачи.

## Результат занятия

Готовая обработка `НормализацияСправочников` с двумя командами: «Проверить» собирает статистику по справочнику «Товары», «Исправить» приводит данные в порядок и записывает только изменённые элементы. Плюс заполненный чек-лист с фактическими результатами, включая негативные сценарии. К этапу 3 стоит переходить **только после выполненного чек-листа**: дальше материал опирается на всё перечисленное.

## Маршрут

1. Прочитайте [теорию](theory.md) — около 20 минут. Она не про язык, а про то, как разработчик сдаёт работу.
2. Выполните [практику](practice.md): сначала решите задачу сами, потом пройдите чек-лист.
3. **Раздел «Разбор и эталонный вариант» открывайте только после своей попытки.** Посмотреть готовое решение заранее — значит потратить контрольную точку впустую: она проверяет умение, а не память.

## Ключевые термины

Контрольная точка, критерий готовности, тест-кейс, ожидаемый результат, фактический результат, негативный сценарий, идемпотентность, нормализация данных.
