# Теория. Группировка и агрегатные функции

## Какую задачу мы решаем

Снабженец готовит закупку на месяц. Ему не нужны отдельные строки заявок, ему нужна сводка: сколько всего цемента, кирпича и песка просят объекты, сколько заявок за этим стоит и какая самая крупная разовая потребность. Пять строк цемента по разным заявкам должны превратиться в одну строку с суммой.

Вторая задача осталась от занятия 58: строка заявки размножилась, когда по ней пришло два поступления кирпича. Числа нужно сложить, а не перечислить.

Обе задачи решает **группировка** — сворачивание нескольких строк в одну с вычислением итоговых значений.

## Группировка и агрегатные функции

Секция `СГРУППИРОВАТЬ ПО` перечисляет поля, по которым строки собираются в группы. Все строки с одинаковыми значениями этих полей становятся одной строкой результата.

```bsl
ВЫБРАТЬ
	ЗаявкаМатериалы.Материал КАК Материал,
	СУММА(ЗаявкаМатериалы.Количество) КАК Потребность
ИЗ
	Документ.ЗаявкаНаМатериалы.Материалы КАК ЗаявкаМатериалы
СГРУППИРОВАТЬ ПО
	ЗаявкаМатериалы.Материал
```

Что делать с остальными полями свёрнутых строк, говорит **агрегатная функция**. Она получает значения поля из всех строк группы и возвращает одно значение.

| Функция | Что возвращает для группы |
| --- | --- |
| `СУММА(Поле)` | сумму значений |
| `КОЛИЧЕСТВО(Поле)` | число строк, где поле не `NULL` |
| `КОЛИЧЕСТВО(РАЗЛИЧНЫЕ Поле)` | число разных значений поля |
| `МАКСИМУМ(Поле)` | наибольшее значение |
| `МИНИМУМ(Поле)` | наименьшее значение |
| `СРЕДНЕЕ(Поле)` | среднее арифметическое |

`КОЛИЧЕСТВО(РАЗЛИЧНЫЕ ЗаявкаМатериалы.Ссылка)` в нашей сводке посчитает, во скольких **разных заявках** встречается материал. Просто `КОЛИЧЕСТВО` посчитало бы строки, и заявка с двумя строками цемента дала бы двойку.

## Главное правило группировки

Каждое поле в списке `ВЫБРАТЬ` должно быть либо **полем группировки**, либо **аргументом агрегатной функции**. Третьего не дано.

Причина простая. В группе «цемент» пять строк с пятью разными количествами. Если поставить в запрос `ЗаявкаМатериалы.Количество` без функции, платформе неоткуда взять одно значение для одной строки результата: какое из пяти? Поэтому такой запрос не выполнится, и сообщение об ошибке скажет, что поле не входит в группу.

Обратное тоже верно: поле, добавленное в `СГРУППИРОВАТЬ ПО`, дробит группы. Если группировать по материалу **и** объекту строительства, цемент «ЖК Северный» и цемент другого объекта станут разными строками. Поля группировки — это и есть ответ на вопрос «в разрезе чего нужна сводка».

## ГДЕ и ИМЕЮЩИЕ

У запроса с группировкой два места для условий.

- **`ГДЕ`** отбирает **строки до группировки**. «Только рабочие заявки», «только этот месяц» — условия на отдельные строки, и пишутся они в `ГДЕ`.
- **`ИМЕЮЩИЕ`** отбирает **группы после группировки**. «Только материалы с общей потребностью больше `200`» — условие на итог группы, и знать итог до группировки нельзя.

```bsl
СГРУППИРОВАТЬ ПО
	ЗаявкаМатериалы.Материал
ИМЕЮЩИЕ
	СУММА(ЗаявкаМатериалы.Количество) > 200
```

В `ИМЕЮЩИЕ` пишут агрегатную функцию полностью, а не псевдоним поля: условие относится к группе, а не к колонке результата.

## Группировка после соединения

Вернёмся к размножению строк. В занятии 58 строка заявки «кирпич, 500» получила две пары: поступления на `300` и на `200`. Если сгруппировать результат соединения **по строке заявки** и сложить поступившее, две строки свернутся в одну:

```bsl
СГРУППИРОВАТЬ ПО
	ЗаявкаМатериалы.Ссылка,
	ЗаявкаМатериалы.НомерСтроки,
	ЗаявкаМатериалы.Материал,
	ЗаявкаМатериалы.Количество
```

Поле `НомерСтроки` здесь обязательно: оно отличает строки одной заявки. Заказанное количество становится полем группировки — оно одно на строку заявки, а `СУММА(ЕСТЬNULL(ПоступлениеМатериалы.Количество, 0))` складывает все пришедшие поступления.

У этого решения есть граница. Если в одной заявке материал записан двумя строками, каждая из них получит в пары все поступления этого материала, и поступившее посчитается дважды. Полное решение — сначала сложить обе стороны по материалу, потом соединять. Для этого нужен запрос внутри запроса, и он появится на занятиях 62–63.

## Что важно запомнить

1. `СГРУППИРОВАТЬ ПО` сворачивает строки с одинаковыми значениями полей группировки в одну строку.
2. Агрегатные функции `СУММА`, `КОЛИЧЕСТВО`, `МАКСИМУМ`, `МИНИМУМ`, `СРЕДНЕЕ` вычисляют одно значение по всем строкам группы.
3. Каждое поле результата — либо поле группировки, либо аргумент агрегатной функции.
4. `ГДЕ` отбирает строки до группировки, `ИМЕЮЩИЕ` — группы после неё.
5. `КОЛИЧЕСТВО(РАЗЛИЧНЫЕ …)` считает разные значения, а не строки.
6. Группировка по ключу строки заявки сворачивает размножение из соединения.
