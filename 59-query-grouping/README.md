# Занятие 59. Группировка и агрегатные функции

## Цель

Научиться складывать строки в запросе: получать общую потребность в каждом материале, считать заявки и находить максимальные значения. Понять, чем условие `ГДЕ` отличается от условия `ИМЕЮЩИЕ`, и исправить размножение строк из занятия 58.

## Результат занятия

В обработке `УчебнаяКонсоль` появится сводная потребность в материалах по всем рабочим заявкам: материал, общее количество, число заявок и самая крупная разовая потребность. Вторая процедура покажет потребность по объектам строительства, а отбор `ИМЕЮЩИЕ` оставит только крупные итоги. Процедура «Исполнение заявки» из занятия 58 перестанет размножать строки при нескольких поступлениях.
