# Занятие 91. Пользователи и роль администратора

## Цель

Понять, почему рабочей базе нужны пользователи и роли, и включить их в учебной базе, не потеряв к ней доступ. Научиться делать резервную копию информационной базы, создавать роль с полными правами, первого пользователя-администратора и обычного пользователя, а также увидеть, что пользователь без ролей в программу не попадает.

## Результат занятия

У информационной базы появится резервная копия в файле `.dt`. В конфигурации появится роль `ПолныеПрава` со всеми правами, включая администрирование, и с флагом прав для новых объектов. В списке пользователей появятся «Администратор» с этой ролью и «Петров Пётр» без ролей. Конфигуратор и приложение будут спрашивать имя пользователя при входе, а Петров не сможет войти, пока ему не назначат роль на занятии 92.
