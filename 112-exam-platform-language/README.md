# Занятие 112. Билет 1: платформа, модель данных и встроенный язык

## Цель

Повторить темы этапов 1–2 так, как их спрашивает экзамен: конфигурация и база данных, объекты метаданных, справочники, перечисления, константы, типы, встроенный язык, коллекции, модули, клиент и сервер, исключения. Научиться проверять спорный ответ экспериментом, а не памятью.

## Результат занятия

В конспекте появятся ответы на тренировочный билет из пятнадцати вопросов с временем решения, разбор каждой ошибки и новые карточки повторения. Три спорных утверждения будут проверены в «Учебной консоли», а сама консоль после эксперимента вернётся к прежнему виду — это подтвердит чистый `git status` репозитория проекта.

## Маршрут

1. Перечитайте занятия, отмеченные в `exam/plan.md` для этого билета, затем [теорию](theory.md) — около 30 минут.
2. Выполните [практику](practice.md) — около 60 минут.
3. Ответьте на контрольные вопросы в конце практики, не подглядывая в теорию.

## Ключевые термины

Конфигурация, конфигурация базы данных, подсистема, предопределённый элемент, константа, составной тип, пустая ссылка, `Знач`, функция и процедура, массив, структура, соответствие, таблица значений, флаги общего модуля, директивы компиляции, контекст формы, серверный вызов, исключение.
