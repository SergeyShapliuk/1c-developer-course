# Практика. Тренировочный билет 1

## Перед началом

Понадобятся конспект с файлами `exam/plan.md` и `exam/cards.md` из занятия 111, учебная база с обработкой `УчебнаяКонсоль` (занятие 9) и репозиторий `construction-erp`. Убедитесь, что база совпадает с `main`: выгрузите конфигурацию в `src\cf` и выполните `git status` — изменений нет.

Создайте в конспекте файл `exam/ticket-1.md` для ответов. Засеките 22 минуты на пятнадцать вопросов — немного больше, чем на экзамене, потому что вопросов больше.

## Шаг 1. Решите билет

**1.** Что такое конфигурация?

- А) Программа, которая исполняет прикладное решение на компьютере пользователя
- Б) Описание прикладного решения — объекты, формы, модули, — которое исполняет платформа
- В) Файл с данными компании
- Г) Список пользователей и их прав

**2.** Что делает клавиша `F7` в конфигураторе?

- А) Запускает 1С:Предприятие в режиме отладки
- Б) Обновляет конфигурацию базы данных
- В) Выполняет синтаксический контроль модуля
- Г) Сохраняет основную конфигурацию

**3.** Разработчик создал подсистему «Склад», но в приложении такого раздела нет. Какая причина возможна?

- А) В подсистему не включён ни один объект
- Б) У подсистемы не заполнен синоним
- В) Подсистема создана позже справочников
- Г) У подсистемы нет модуля

**4.** Как надёжнее всего хранить в документе связь с элементом справочника «Склады»?

- А) Реквизитом типа «Строка» с кодом склада
- Б) Реквизитом типа «Строка» с наименованием склада
- В) Реквизитом типа «Число» с номером склада в списке
- Г) Реквизитом типа `СправочникСсылка.Склады`

**5.** Чем предопределённый элемент справочника отличается от обычного?

- А) Его создаёт разработчик в конфигураторе, и код может обратиться к нему по имени
- Б) Он хранится не в базе, а в файле конфигурации
- В) Его создаёт первый пользователь, вошедший в базу
- Г) У него нет кода и наименования

**6.** Сколько значений хранит одна константа?

- А) Одно
- Б) По одному на каждого пользователя
- В) Сколько угодно, как справочник
- Г) Одно на каждую дату

**7.** Реквизит имеет составной тип `СправочникСсылка.Склады` и `СправочникСсылка.ОбъектыСтроительства`. Что в нём хранится?

- А) Одно значение одного из двух типов
- Б) Два значения: склад и объект строительства
- В) Строка с представлением выбранного значения
- Г) Тип значения без самого значения

**8.** Что вернёт `ЗначениеЗаполнено(Справочники.Склады.ПустаяСсылка())`?

- А) `Истина`
- Б) `Ложь`
- В) `Неопределено`
- Г) Ошибку: пустую ссылку нельзя проверять

**9.** Что выведет код?

```bsl
Процедура Увеличить(Знач Число)
	Число = Число + 1;
КонецПроцедуры

А = 1;
Увеличить(А);
Сообщить(А);
```

- А) `1`
- Б) `2`
- В) Ошибку: параметр с `Знач` нельзя изменять
- Г) Ничего: `Сообщить` не выводит числа

**10.** По ссылке на материал нужно быстро получать его цену. Какая коллекция подходит лучше всего?

- А) Массив цен
- Б) Структура, где ключ — наименование материала
- В) Соответствие, где ключ — ссылка на материал
- Г) Список значений с представлением-ценой

**11.** Где в управляемой форме можно создать и заполнить таблицу значений?

- А) В любой клиентской процедуре
- Б) В серверной процедуре
- В) Только в модуле приложения
- Г) Таблицу значений в управляемом приложении создать нельзя

**12.** Экспортную процедуру общего модуля нужно вызвать из клиентской процедуры формы, а выполнить на сервере. Какие флаги общего модуля нужны?

- А) **Клиент (управляемое приложение)**
- Б) **Сервер** и **Вызов сервера**
- В) **Глобальный**
- Г) **Привилегированный**

**13.** Что недоступно в процедуре формы с директивой `&НаСервереБезКонтекста`?

- А) Обращение к базе данных
- Б) Запросы
- В) Параметры процедуры
- Г) Реквизиты формы, в том числе `Объект`

**14.** Что выведет код?

```bsl
Попытка
	ВызватьИсключение "Не указан склад";
	Сообщить("Проверка пройдена");
Исключение
	Сообщить(ОписаниеОшибки());
КонецПопытки;
```

- А) «Проверка пройдена»
- Б) Описание ошибки, содержащее «Не указан склад»
- В) «Проверка пройдена» и затем описание ошибки
- Г) Ничего: исключение остановит программу

**15.** Правило «наименование склада не может быть пустым» должно срабатывать при записи склада из формы, из обработки и из кода. Где его разместить?

- А) В модуле формы элемента справочника
- Б) В модуле объекта справочника, в `ПередЗаписью`
- В) В модуле приложения
- Г) В обработке, которая создаёт склады

**Проверка:** на все пятнадцать вопросов записаны ответы, время записано.

## Шаг 3. Проверьте спорное экспериментом

Проверим три ответа, в которых чаще всего сомневаются. Работаем в модуле формы обработки `УчебнаяКонсоль` учебной базы.

1. **Передача параметра.** Добавьте в модуль формы процедуры и вызовите `ПроверитьПараметры()` из любой команды консоли — например, временно допишите вызов в обработчик существующей команды:

```bsl
&НаКлиенте
Процедура УвеличитьКопию(Знач Число)
	Число = Число + 1;
КонецПроцедуры

&НаКлиенте
Процедура УвеличитьСсылку(Число)
	Число = Число + 1;
КонецПроцедуры

&НаКлиенте
Процедура ПроверитьПараметры()
	А = 1;
	УвеличитьКопию(А);
	Сообщить("Со Знач: " + Строка(А));
	УвеличитьСсылку(А);
	Сообщить("Без Знач: " + Строка(А));
КонецПроцедуры
```

Запустите приложение и выполните команду. Сообщения — `1` и `2`.

2. **Ключ структуры.** Допишите в `ПроверитьПараметры()` строки и выполните команду ещё раз:

```bsl
	Цены = Новый Соответствие;
	Цены.Вставить("Цемент М500", 12.5);
	Сообщить("Соответствие: " + Строка(Цены.Получить("Цемент М500")));

	ЦеныСтруктурой = Новый Структура;
	ЦеныСтруктурой.Вставить("Цемент М500", 12.5);
```

Соответствие вернуло цену, а вставка в структуру завершилась ошибкой: ключ структуры должен быть правильным именем, а пробел в имени недопустим.

3. **Пустая ссылка.** Чтение пустой ссылки — серверная работа, поэтому добавьте серверную функцию и выведите её результат:

```bsl
&НаСервереБезКонтекста
Функция ПустойСкладЗаполнен()
	Возврат ЗначениеЗаполнено(Справочники.Склады.ПустаяСсылка());
КонецФункции
```

Вызовите её из `ПроверитьПараметры()` строкой `Сообщить("Пустой склад заполнен: " + Строка(ПустойСкладЗаполнен()));`, предварительно убрав строки со структурой, которые падают. Сообщение — «Нет».

4. Удалите все добавленные процедуры и вызов из обработчика команды. `Ctrl+S`, `F7`. Выгрузите конфигурацию и выполните `git status` в `construction-erp`: изменений нет. Если Git видит изменения модуля консоли, вы удалили не всё — `git diff` покажет, что осталось.

**Проверка:** три эксперимента дали ожидаемый результат; после уборки `git status` чист.
