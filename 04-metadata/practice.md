# Практика. Настраиваем свойства конфигурации

## Перед началом

Нужна база `УправлениеСтроительнойКомпанией` с заданными на занятии 3 именем и синонимом конфигурации. Если имя и синоним ещё не заданы, вернитесь к практике занятия 3.

Откройте окно запуска, выделите базу и нажмите **Конфигуратор**. При необходимости откройте дерево командой **Конфигурация → Открыть конфигурацию**.

Сегодня мы по-прежнему **не создаём объекты метаданных**. Задача занятия — настроить свойства конфигурации целиком и научиться узнавать группы в дереве. Первый собственный объект появится на занятии 5.

Перед изменением свойств полезно сделать выгрузку: **Администрирование → Выгрузить информационную базу**. Сегодняшние правки безопасны, но привычка нужна.

## Шаг 1. Откройте палитру свойств корня конфигурации

1. Выделите в дереве корневой узел — верхнюю строку со значком жёлтого кубика.
2. Сделайте двойной щелчок, чтобы открыть палитру свойств. Если палитра не появилась, вызовите контекстное меню правой кнопкой мыши и выберите **Свойства**.
3. Убедитесь, что в палитре уже заполнены **Имя** и **Синоним** — их вы задали на занятии 3.

**Проверка:** палитра свойств конфигурации открыта, имя и синоним на месте.

## Шаг 2. Задайте основной режим запуска

1. Найдите в палитре свойство **Основной режим запуска**.
2. Раскройте список значений. В нём два варианта: **Управляемое приложение** и **Обычное приложение**.
3. Выберите **Управляемое приложение**.

Почему именно он. Управляемое приложение — современный интерфейс платформы: у приложения есть панель разделов, рабочий стол и формы, которые платформа умеет показывать и в тонком клиенте, и в браузере. Именно этот режим используют все новые решения, и весь курс рассчитан на него — например, разделы приложения, которыми мы займёмся на занятии 5, существуют только в управляемом приложении. Обычное приложение оставлено для совместимости со старыми решениями и нам не понадобится.

**Проверка:** в свойстве **Основной режим запуска** стоит значение «Управляемое приложение».

## Шаг 3. Задайте вариант встроенного языка

1. Найдите свойство **Вариант встроенного языка**.
2. Выберите значение **Русский**.

Зачем это нужно. Встроенный язык 1С существует в двух вариантах — русском и английском: один и тот же оператор пишется либо `Если`, либо `If`. Свойство задаёт, какой вариант платформа считает основным для этой конфигурации. Курс использует русский вариант, и весь код в последующих занятиях будет написан по-русски. Если оставить английский, примеры из занятий придётся переписывать.

**Проверка:** в свойстве **Вариант встроенного языка** стоит значение «Русский».

## Шаг 4. Заполните краткую информацию

1. Найдите свойство **Краткая информация**.
2. Введите текст: «Учебная конфигурация курса: управление строительной компанией с логистикой».
3. Если поле открывается в отдельном окне ввода, введите текст там и нажмите **ОК**.

Свойство справочное: на работу решения оно не влияет, но отвечает на вопрос «что это за конфигурация», когда вы вернётесь к ней через месяц.

**Проверка:** в свойстве **Краткая информация** виден введённый текст.

## Шаг 5. Пройдите по дереву и заполните карту своими словами

Раскройте дерево конфигурации и найдите перечисленные группы. Затем заполните таблицу: во второй колонке — что в группе хранится, своими словами, в третьей — когда это изучается по курсу. Подсказки есть в [теории](theory.md), но сначала попробуйте по памяти.

| Группа дерева | Что в ней хранится | Когда изучим |
| --- | --- | --- |
| Справочники | | |
| Перечисления | | |
| Константы | | |
| Подсистемы | | |
| Документы | | |
| Регистры накопления | | |

Не копируйте формулировки из теории дословно: смысл шага в том, чтобы объяснить своими словами. Если по какой-то строке объяснить не получается, перечитайте раздел «Карта объектов метаданных».

**Проверка:** все шесть строк заполнены, и вы можете назвать вопрос, на который отвечает каждая группа.

## Шаг 6. Пройдите цикл разработки

1. Нажмите `Ctrl+S`, чтобы сохранить конфигурацию.
2. Нажмите `F7` (**Конфигурация → Обновить конфигурацию базы данных**). Прочитайте список изменений — в нём должны быть упомянуты изменённые свойства конфигурации — и подтвердите обновление.
3. Нажмите `F5` (**Отладка → Начать отладку**), чтобы запустить режим «1С:Предприятие».
4. Посмотрите на запустившееся приложение. В заголовке окна виден синоним конфигурации «Управление строительной компанией». Само окно оформлено как управляемое приложение: сверху область для панели разделов, в центре рабочая область.
5. Разделов пока нет, и это нормально: мы ещё не создали ни одной подсистемы. Панель разделов появится на занятии 5.
6. Закройте приложение и вернитесь в Конфигуратор.

**Проверка:** приложение запускается в управляемом режиме, в заголовке виден синоним конфигурации.

## Проверка результата

Занятие пройдено, если выполняются три условия:

1. Заполнены три свойства конфигурации: **Основной режим запуска**, **Вариант встроенного языка**, **Краткая информация**.
2. Таблица групп дерева заполнена своими словами.
3. Приложение запускается в управляемом режиме, в заголовке отображается синоним конфигурации.

## Контрольные вопросы

Не подглядывая в теорию, ответьте устно или в заметках:

1. Чем объект метаданных отличается от данных пользователя?
2. Почему конкретный клиент ООО «СтройСнаб» — не объект метаданных?
3. Чем имя отличается от синонима и что из них рискованнее менять позже?
4. Зачем нужно свойство «Основной режим запуска» и какое значение мы выбрали?
5. Какой объект метаданных отвечает на вопрос «что произошло и когда»?

Сверьте ответы с [теорией](theory.md). Если на каждый вопрос получается ответить одним-двумя предложениями, переходите к занятию 5.
