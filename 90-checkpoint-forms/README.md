# Занятие 90. Контрольная точка: формы и печатные формы

## Цель

Это **контрольная точка** этапа 7 и шестая в курсе. Нового материала здесь нет: нужно самостоятельно довести до рабочего состояния интерфейс документа `ПоступлениеМатериалов` — журнал, форму и печатную форму, — используя то, что изучено в занятиях 81–89, а затем принять свою работу по чек-листу.

## Результат занятия

Журнал поступлений показывает по каждому документу поставщика, склад, заявку-основание, объект строительства этой заявки, число позиций и сумму, а поступления без заявки выделены. В форме поступления поле «Заявка-основание» видно только у поступлений по заявке. Команда **Приходный ордер** печатает выделенные проведённые поступления одним окном, каждое на своей странице, а для непроведённых сообщает, сколько пропущено. Плюс заполненный чек-лист с фактическими результатами.

## Маршрут

1. Прочитайте [теорию](theory.md) — около 20 минут. Она не про новые возможности, а про то, как принимают формы и печатные формы.
2. Выполните [практику](practice.md): сначала решите задачу сами, потом пройдите чек-лист.
3. **Раздел «Разбор и эталонный вариант» открывайте только после своей попытки.** Готовое решение, прочитанное заранее, не научит его находить: контрольная точка проверяет умение, а не память.

## Ключевые термины

Контрольная точка, приёмка интерфейса, форма списка, динамический список, произвольный запрос, условное оформление формы, видимость элемента, макет, область, параметр области, модуль менеджера, команда объекта, множественный параметр, разделитель страниц.
