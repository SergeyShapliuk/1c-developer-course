# Занятие 88. Команда печати

## Цель

Научиться делать печать доступной везде, где пользователь видит документ: в его форме и в журнале. Понять, чем команда объекта с параметром отличается от команды формы, как платформа передаёт ей документ, куда она встраивается сама и почему команда печати остаётся тонкой, а лист по-прежнему собирает модуль менеджера.

## Результат занятия

У документа `ЗаявкаНаМатериалы` появится команда объекта **Печать заявки** с параметром типа `ДокументСсылка.ЗаявкаНаМатериалы`. Она сама появится и в форме заявки, и в журнале заявок: снабженец печатает заявку из списка, не открывая её. Команда формы занятия 87 удалена, правило «не печатать несохранённое» перенесено в модуль команды. Функция `ПечатнаяФормаЗаявки` модуля менеджера не изменилась.
