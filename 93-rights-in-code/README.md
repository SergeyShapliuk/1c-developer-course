# Занятие 93. Права в коде

## Цель

Научиться выражать в коде правила доступа, которых нет среди прав на объекты: «согласовывать заявки может только руководитель снабжения». Понять, как роль служит разрешением на действие, почему проверку роли прячут в функцию общего модуля, где проверка в форме — удобство, а где проверка в модуле объекта — гарантия, и что такое привилегированный режим.

## Результат занятия

В конфигурации появятся роль `СогласованиеЗаявок` без единого права на объекты и общий модуль `ПраваПользователей` с функцией `МожноСогласовыватьЗаявки`. Кнопка **Согласовать** видна только тем, кому разрешено согласование; серверная часть команды отказывает остальным; `ПередЗаписью` заявки не даёт записать согласование без разрешения никаким путём. Руководитель снабжения Кузнецов Олег согласует заявки, снабженец Сидорова Анна — нет.

## Ключевые термины

Роль-разрешение, `РольДоступна`, `ПравоДоступа`, `Метаданные`, функция проверки прав, проверка в форме и в модуле объекта, привилегированный режим, `УстановитьПривилегированныйРежим`, привилегированный общий модуль.
