# Занятие 17. Массивы, структуры и соответствия

## Цель

Научиться хранить много значений в одной переменной: освоить массив, структуру и соответствие и понимать, какая коллекция подходит для какой задачи.

## Результат занятия

В модуле формы обработки `УчебнаяКонсоль` вы соберёте массив наименований материалов, структуру одной позиции, массив структур с расчётом суммы и соответствие «наименование → цена». Здесь же появится третий вид цикла — `Для Каждого`, обещанный на занятии 14.

## Маршрут

1. Прочитайте [теорию](theory.md) — около 25 минут.
2. Выполните [практику](practice.md) — около 60 минут.
3. Ответьте на контрольные вопросы в конце практики, не подглядывая в теорию.

## Ключевые термины

Коллекция, массив, индекс, `Для Каждого`, структура, свойство структуры, соответствие, ключ, массив структур.
