# Практика. Собираем список материалов

## Перед началом

Запустите конфигуратор учебной конфигурации **«Управление строительной компанией с логистикой»**.

В дереве конфигурации откройте обработку `УчебнаяКонсоль` (синоним «Учебная консоль»), затем её форму, а в редакторе формы — вкладку **Модуль**. Работаем в процедуре `Выполнить`.

После каждой правки кода:

1. Сохраните конфигурацию — `Ctrl+S`.
2. Запустите приложение — `F5`.
3. В разделе **Разработка** откройте «Учебную консоль».
4. Нажмите кнопку **Выполнить** и прочитайте сообщения.

Весь код занятия — клиентский, с директивой `&НаКлиенте`, как и раньше. На шаге 4 нам понадобится функция `РассчитатьСумму(Количество, Цена)`, написанная на занятии 15: убедитесь, что она в модуле есть.

Код каждого шага заменяет код предыдущего внутри `Выполнить`, если не сказано иначе.

## Шаг 1. Массив наименований

Создадим массив и переберём его.

```bsl
&НаКлиенте
Процедура Выполнить(Команда)
	
	Материалы = Новый Массив;
	Материалы.Добавить("Цемент М500");
	Материалы.Добавить("Кирпич облицовочный");
	Материалы.Добавить("Арматура 12");
	Материалы.Добавить("Песок строительный");
	
	Сообщить("Материалов в списке: " + Строка(Материалы.Количество()));
	
	// Номер в списке считаем отдельной переменной:
	// Для Каждого выдаёт значения, но не их номера.
	Номер = 0;
	Для Каждого Материал Из Материалы Цикл
		Номер = Номер + 1;
		Сообщить(Строка(Номер) + ". " + Материал);
	КонецЦикла;
	
КонецПроцедуры
```

Сохраните, запустите, нажмите **Выполнить**. В сообщениях появятся количество `4` и четыре пронумерованные строки.

**Проверка:** выведено `Материалов в списке: 4` и нумерованный перечень из четырёх наименований.

## Шаг 2. Обращение по индексу

Теперь достанем первое и последнее значение напрямую.

```bsl
&НаКлиенте
Процедура Выполнить(Команда)
	
	Материалы = Новый Массив;
	Материалы.Добавить("Цемент М500");
	Материалы.Добавить("Кирпич облицовочный");
	Материалы.Добавить("Арматура 12");
	Материалы.Добавить("Песок строительный");
	
	ПоследнийИндекс = Материалы.Количество() - 1;
	
	Сообщить("Первый: " + Материалы[0]);
	Сообщить("Последний индекс: " + Строка(ПоследнийИндекс));
	Сообщить("Последний: " + Материалы[ПоследнийИндекс]);
	
КонецПроцедуры
```

Выведется `Первый: Цемент М500`, `Последний индекс: 3`, `Последний: Песок строительный`.

Почему последний индекс равен `3`, а не `4`? Потому что счёт идёт с нуля: четыре элемента получили номера `0`, `1`, `2`, `3`. Количество элементов и последний индекс всегда различаются на единицу — это самая частая ошибка новичков.

Хотите убедиться — замените `ПоследнийИндекс` на `Материалы.Количество()` и запустите. Платформа сообщит, что индекс находится за границами массива. После этого верните корректный вариант.

**Проверка:** выведены первый и последний элементы, и вы видели ошибку выхода за границу массива.

## Шаг 3. Структура одной позиции

Опишем одну позицию поставки структурой.

```bsl
&НаКлиенте
Процедура Выполнить(Команда)
	
	Позиция = Новый Структура;
	Позиция.Вставить("Товар", "Цемент М500");
	Позиция.Вставить("Количество", 10);
	Позиция.Вставить("Цена", 12.50);
	
	Сообщить("Товар: " + Позиция.Товар);
	Сообщить("Количество: " + Строка(Позиция.Количество));
	Сообщить("Цена: " + Строка(Позиция.Цена));
	
	// Свойства "Скидка" мы не вставляли.
	// Обращение Позиция.Скидка привело бы к ошибке,
	// поэтому сначала спрашиваем, есть ли такое свойство.
	Если Позиция.Свойство("Скидка") Тогда
		Сообщить("Скидка: " + Строка(Позиция.Скидка));
	Иначе
		Сообщить("Скидка для этой позиции не задана");
	КонецЕсли;
	
КонецПроцедуры
```

**Проверка:** выведены три поля позиции и сообщение о том, что скидка не задана.

## Шаг 4. Массив структур и расчёт итога

Соберём три позиции и посчитаем сумму каждой и общий итог. Сумму считает функция `РассчитатьСумму` из занятия 15.

```bsl
&НаКлиенте
Процедура Выполнить(Команда)
	
	СписокПозиций = Новый Массив;
	СписокПозиций.Добавить(СоздатьПозицию("Цемент М500", 10, 12.50));
	СписокПозиций.Добавить(СоздатьПозицию("Кирпич облицовочный", 500, 18.90));
	СписокПозиций.Добавить(СоздатьПозицию("Арматура 12", 40, 54.00));
	
	Итог = 0;
	Для Каждого Позиция Из СписокПозиций Цикл
		Сумма = РассчитатьСумму(Позиция.Количество, Позиция.Цена);
		Сообщить(Позиция.Товар + ": " + Строка(Сумма));
		Итог = Итог + Сумма;
	КонецЦикла;
	
	Сообщить("Итого: " + Строка(Итог));
	
КонецПроцедуры

&НаКлиенте
Функция СоздатьПозицию(Товар, Количество, Цена)
	
	// Отдельная функция избавляет от трёх одинаковых блоков Вставить.
	Позиция = Новый Структура;
	Позиция.Вставить("Товар", Товар);
	Позиция.Вставить("Количество", Количество);
	Позиция.Вставить("Цена", Цена);
	
	Возврат Позиция;
	
КонецФункции
```

Обратите внимание на сочетание: массив даёт список, структура описывает одну позицию, `Для Каждого` проходит по списку, а функция занятия 15 считает одну строку.

**Проверка:** выведены три суммы по позициям и строка «Итого» с их суммой.

## Шаг 5. Соответствие «наименование → цена»

Теперь задача другая: цена нужна по наименованию, без перебора.

```bsl
&НаКлиенте
Процедура Выполнить(Команда)
	
	Цены = Новый Соответствие;
	Цены.Вставить("Цемент М500", 12.50);
	Цены.Вставить("Кирпич облицовочный", 18.90);
	Цены.Вставить("Арматура 12", 54.00);
	Цены.Вставить("Песок строительный", 320.00);
	
	ВывестиЦену(Цены, "Цемент М500");
	ВывестиЦену(Цены, "Гипсокартон");
	
КонецПроцедуры

&НаКлиенте
Процедура ВывестиЦену(Цены, Наименование)
	
	Цена = Цены.Получить(Наименование);
	
	// Получить для отсутствующего ключа возвращает Неопределено,
	// а не вызывает ошибку. Это и проверяем.
	Если Цена = Неопределено Тогда
		Сообщить(Наименование + ": цена не задана");
	Иначе
		Сообщить(Наименование + ": " + Строка(Цена));
	КонецЕсли;
	
КонецПроцедуры
```

Для цемента выведется цена, для гипсокартона — понятное сообщение. Код не упал, потому что отсутствующий ключ вернул `Неопределено`, а мы это предусмотрели.

**Проверка:** выведены цена цемента и сообщение о том, что цена гипсокартона не задана.

## Шаг 6. Выберите коллекцию сами

Заполните последнюю колонку своими словами.

| Задача | Какая коллекция подойдёт |
| --- | --- |
| Список наименований складов, чтобы перебрать их по очереди | |
| Карточка одной позиции: товар, количество, цена | |
| Узнать цену по наименованию материала, не перебирая весь список | |

Верные направления: список для перебора — массив; карточка с именованными полями — структура; поиск по ключу — соответствие.

## Проверка результата

Занятие пройдено, если выполняются четыре условия:

1. Вы вывели массив материалов и `Для Каждого`, и по индексу.
2. Вы видели ошибку обращения за границу массива и понимаете, откуда берётся `Количество() - 1`.
3. Массив структур обработан циклом, суммы и итог посчитаны.
4. Соответствие корректно отработало отсутствующий ключ, а не упало с ошибкой.
