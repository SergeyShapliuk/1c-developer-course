# Теория. Коллекции значений

## Зачем нужны коллекции

Пока в переменной лежало одно значение: число, строка, дата. Но задачи звучат иначе: «вывести все материалы», «посчитать сумму по всем позициям», «найти цену по наименованию».

Писать отдельные переменные `Материал1`, `Материал2`, `Материал3` бессмысленно: их всегда окажется либо мало, либо много, и перебрать их циклом нельзя — цикл умеет считать числа, а не придумывать имена переменных.

**Коллекция** — это одно значение, которое содержит внутри себя много других значений. Переменная одна, а значений в ней сколько нужно.

## Массив

**Массив** — упорядоченный список значений. Создаётся словом `Новый`:

```bsl
Материалы = Новый Массив;
Материалы.Добавить("Цемент М500");
Материалы.Добавить("Кирпич облицовочный");
Материалы.Добавить("Арматура 12");

Сообщить("Материалов в списке: " + Строка(Материалы.Количество()));
```

`Добавить()` кладёт значение в конец списка, `Количество()` возвращает, сколько значений в массиве лежит.

К значению обращаются по **индексу** — его номеру в квадратных скобках. Главное, что надо запомнить: **индексы начинаются с нуля**.

```bsl
Сообщить(Материалы[0]); // Цемент М500   — первый элемент
Сообщить(Материалы[2]); // Арматура 12   — третий элемент
```

У массива из трёх элементов индексы `0`, `1`, `2`, а последний индекс равен `Количество() - 1`. Обращение `Материалы[3]` вызовет ошибку: такого индекса нет.

## Для Каждого

На занятии 14 мы разобрали два цикла, `Для` и `Пока`, и обещали третий. Вот он — цикл **`Для Каждого`**, созданный специально для коллекций:

```bsl
Для Каждого Материал Из Материалы Цикл
	Сообщить(Материал);
КонецЦикла;
```

Читается как русская фраза: для каждого материала из массива материалов сделать то, что внутри. Имя `Материал` вы придумываете сами — это переменная, в которую по очереди попадает каждое значение коллекции.

Тот же перебор можно сделать и циклом по индексу:

```bsl
Для Индекс = 0 По Материалы.Количество() - 1 Цикл
	Сообщить(Строка(Индекс) + ". " + Материалы[Индекс]);
КонецЦикла;
```

Когда что выбирать:

- нужно только значение — берите `Для Каждого`, он короче и в нём невозможно ошибиться с границами;
- нужен сам номер позиции (вывести нумерацию, сравнить соседние элементы, обратиться к элементу другого массива с тем же номером) — нужен цикл по индексу.

## Структура

Массив хранит список однотипных значений. Но позиция поставки — это не одно значение: у неё есть товар, количество и цена. Для такого случая есть **структура** — набор именованных полей одного объекта.

```bsl
Позиция = Новый Структура;
Позиция.Вставить("Товар", "Цемент М500");
Позиция.Вставить("Количество", 10);
Позиция.Вставить("Цена", 12.50);

Сообщить(Позиция.Товар); // обращение через точку
```

`Вставить()` принимает имя свойства и его значение; дальше к значению обращаются через точку: `Позиция.Цена`.

Имя свойства — **идентификатор**, то есть имя по правилам встроенного языка: буквы, цифры и подчёркивание, без пробелов, и не начинается с цифры. `"Цена"` подходит, `"Цена за единицу"` — нет.

Обращаться через точку к свойству, которого может не быть, опасно: это ошибка. Безопасная проверка — метод `Свойство()`:

```bsl
Если Позиция.Свойство("Скидка") Тогда
	Сообщить("Скидка задана");
Иначе
	Сообщить("Скидки нет");
КонецЕсли;
```

## Соответствие

**Соответствие** хранит пары «ключ — значение» и быстро находит значение по ключу. Ключом может быть строка, число, дата — любое значение, не только идентификатор.

```bsl
Цены = Новый Соответствие;
Цены.Вставить("Цемент М500", 12.50);
Цены.Вставить("Кирпич облицовочный", 18.90);

Сообщить(Строка(Цены.Получить("Цемент М500"))); // 12,5
```

Главное отличие от структуры: если ключа нет, `Получить()` не падает с ошибкой, а возвращает `Неопределено` — значение, знакомое с занятия 12. Проверяется оно обычным условием:

```bsl
Цена = Цены.Получить("Гипсокартон");
Если Цена = Неопределено Тогда
	Сообщить("Цена не найдена");
КонецЕсли;
```

## Что когда применять

| Коллекция | Для чего | Как достают значение |
| --- | --- | --- |
| Массив | Упорядоченный список однородных значений | По индексу: `Материалы[0]` |
| Структура | Один объект с набором именованных полей | Через точку: `Позиция.Цена` |
| Соответствие | Поиск значения по ключу | `Цены.Получить("Цемент М500")` |

## Массив структур

Самый частый приём на практике — **массив структур**. Массив задаёт список позиций, а структура описывает одну позицию:

```bsl
СписокПозиций = Новый Массив;

Позиция = Новый Структура;
Позиция.Вставить("Товар", "Цемент М500");
Позиция.Вставить("Количество", 10);
СписокПозиций.Добавить(Позиция);

Для Каждого ТекущаяПозиция Из СписокПозиций Цикл
	Сообщить(ТекущаяПозиция.Товар);
КонецЦикла;
```

Так удобно передавать набор позиций между процедурами: одна собирает, другая обрабатывает.

## Где они работают

Массив, структура и соответствие доступны везде — и в клиентском коде, и в серверном. О месте выполнения для них думать не приходится.

Так бывает не со всеми коллекциями: уже на занятии 18 мы встретим коллекцию, которая существует только на сервере.

## Что важно запомнить

1. Коллекция — одно значение, которое содержит внутри много других значений.
2. Индексы массива начинаются с нуля, последний индекс равен `Количество() - 1`, обращение за границу — ошибка.
3. `Для Каждого … Из … Цикл` перебирает коллекцию без индексов; цикл по индексу нужен, когда важен сам номер позиции.
4. Структура — именованные поля одного объекта, обращение через точку, наличие поля проверяется методом `Свойство()`.
5. Соответствие ищет значение по ключу и для отсутствующего ключа возвращает `Неопределено`, а не ошибку.
6. Массив структур — обычный способ описать список позиций, у каждой из которых есть свои поля.
7. Все три коллекции работают и на клиенте, и на сервере.
