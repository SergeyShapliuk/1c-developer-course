# Практика. Выносим код в общие модули

## Перед началом

Запустите конфигуратор учебной конфигурации **«Управление строительной компанией с логистикой»**.

Код проверяем в обработке `УчебнаяКонсоль`, созданной на занятии 9. Откройте **Обработки → УчебнаяКонсоль**, раскройте её **Формы**, откройте форму и перейдите на вкладку **Модуль**. В модуле уже есть обработчик команды, и весь клиентский код занятия пишем внутри него:

```bsl
&НаКлиенте
Процедура Выполнить(Команда)

КонецПроцедуры
```

После каждой правки: `Ctrl+S`, затем `F5` — платформа предложит обновить конфигурацию базы данных, согласитесь. В запущенном приложении откройте раздел **Разработка**, выберите обработку **Учебная консоль** и нажмите **Выполнить**.

## Шаг 1. Создайте серверный общий модуль

1. Найдите в дереве конфигурации узел **Общие → Общие модули**.
2. Нажмите **Добавить** (или `Insert`).
3. В палитре свойств задайте **Имя** — `УчебныеФункции`. Синоним платформа подставит сама: «Учебные функции».
4. Выставьте флаги: **Сервер** — включён, **Вызов сервера** — включён, **Клиент (управляемое приложение)** — снят, **Глобальный** — снят.
5. Нажмите `Ctrl+S`.

Мы сказали платформе: процедуры модуля живут на сервере, и клиенту разрешено их вызывать.

**Проверка:** модуль `УчебныеФункции` создан, флаги **Сервер** и **Вызов сервера** включены.

## Шаг 2. Перенесите расчёт суммы в общий модуль

На занятии 15 функция `РассчитатьСумму` появилась в модуле формы. Расчёт нужен не только в консоли, поэтому его место — в общем модуле.

1. Откройте модуль `УчебныеФункции` двойным щелчком и напишите:

```bsl
Функция РассчитатьСумму(Количество, Цена) Экспорт
	Возврат Количество * Цена;
КонецФункции
```

2. Вернитесь в модуль формы и **удалите** оттуда одноимённую функцию. Две копии одной функции — источник будущих расхождений.
3. Вызовите функцию через имя модуля:

```bsl
&НаКлиенте
Процедура Выполнить(Команда)
	Итог = УчебныеФункции.РассчитатьСумму(20, 12.50);
	Сообщить("Сумма: " + Строка(Итог));
КонецПроцедуры
```

4. `Ctrl+S`, `F5`, нажмите **Выполнить**.

Клиентская процедура спокойно вызвала серверную функцию — это работает именно из-за флага **Вызов сервера**.

**Проверка:** выведено `Сумма: 250`.

## Шаг 3. Посмотрите, что бывает без `Экспорт`

1. В модуле `УчебныеФункции` уберите слово `Экспорт`.
2. Выполните **Конфигурация → Проверка → Синтаксический контроль**.
3. Прочитайте ошибку: процедура или функция с таким именем не обнаружена. Для внешнего кода её как будто не существует.
4. Верните `Экспорт` и повторите синтаксический контроль — ошибок быть не должно.

**Проверка:** ошибка воспроизведена, и её причина понятна.

## Шаг 4. Посмотрите, что бывает без флага «Вызов сервера»

1. Выделите модуль `УчебныеФункции` и **снимите** флаг **Вызов сервера**.
2. Выполните синтаксический контроль.
3. Прочитайте ошибку: метод недоступен из клиентского кода. Функция существует и по-прежнему экспортная — но дороги с клиента к ней больше нет.
4. Верните флаг и повторите синтаксический контроль.

`Экспорт` открывает процедуру другим модулям, а **Вызов сервера** открывает её клиенту. Нужны оба условия.

**Проверка:** ошибка появлялась при снятом флаге и исчезла после его возврата.

## Шаг 5. Создайте клиентский общий модуль

Диалоги с пользователем на сервере недоступны, поэтому для клиентского кода делают отдельный модуль.

1. В узле **Общие → Общие модули** нажмите **Добавить**.
2. Имя — `УчебныеФункцииКлиент`, синоним — «Учебные функции клиент».
3. Флаги: **Клиент (управляемое приложение)** включён, **Сервер** и **Вызов сервера** сняты.
4. Напишите функцию, которая собирает готовую строку сообщения:

```bsl
Функция ОформитьСообщение(Заголовок, Значение) Экспорт
	Возврат Заголовок + ": " + Строка(Значение);
КонецФункции
```

5. Используйте её в обработчике команды:

```bsl
&НаКлиенте
Процедура Выполнить(Команда)
	Итог = УчебныеФункции.РассчитатьСумму(20, 12.50);
	Сообщить(УчебныеФункцииКлиент.ОформитьСообщение("Сумма", Итог));
КонецПроцедуры
```

6. `Ctrl+S`, `F5`, **Выполнить**.

**Проверка:** выведено `Сумма: 250`, но текст собрал клиентский общий модуль.

## Шаг 6. Попробуйте `&НаСервереБезКонтекста`

Цена товара лежит в базе, значит читать её можно только на сервере. Контекст формы для этого не нужен: достаточно наименования.

1. Добавьте в модуль формы функцию:

```bsl
&НаСервереБезКонтекста
Функция ПолучитьЦенуТовара(Наименование)
	Товар = Справочники.Товары.НайтиПоНаименованию(Наименование);
	Если Товар = Справочники.Товары.ПустаяСсылка() Тогда
		Возврат 0;
	КонецЕсли;
	Возврат Товар.Цена;
КонецФункции
```

2. Вызовите её из обработчика команды:

```bsl
&НаКлиенте
Процедура Выполнить(Команда)
	Цена = ПолучитьЦенуТовара("Цемент М500");
	Сообщить(УчебныеФункцииКлиент.ОформитьСообщение("Цена цемента", Цена));
КонецПроцедуры
```

3. `Ctrl+S`, `F5`, **Выполнить** — вы увидите цену элемента «Цемент М500».
4. Теперь нарушьте правило намеренно: добавьте в начало функции `ПолучитьЦенуТовара` обращение к реквизиту формы `Счётчик` (он создан на занятии 16).

```bsl
	Счётчик = Счётчик + 1;
```

5. Выполните синтаксический контроль и прочитайте ошибку: переменная не определена.
6. Удалите добавленную строку и повторите синтаксический контроль.

Причина ошибки проста: процедура с директивой `&НаСервереБезКонтекста` исполняется без контекста формы, реквизитов формы для неё не существует, и имя `Счётчик` платформа считает неизвестной переменной. Всё нужное такой процедуре передают параметрами.

**Проверка:** цена выводится, ошибка с реквизитом формы воспроизведена и устранена.

## Шаг 7. Зафиксируйте, что куда положили

| Что делает код | Куда положили | Почему |
| --- | --- | --- |
| Расчёт суммы | Общий модуль `УчебныеФункции` (сервер) | Нужен больше чем в одном месте |
| Оформление текста сообщения | Общий модуль `УчебныеФункцииКлиент` | Касается только показа пользователю |
| Чтение цены товара | `&НаСервереБезКонтекста` в модуле формы | Нужна база, но не нужен контекст формы |
| Реакция на нажатие кнопки | `&НаКлиенте` в модуле формы | Поведение одной конкретной формы |

## Проверка результата

Занятие пройдено, если выполняются пять условий:

1. В конфигурации есть общие модули `УчебныеФункции` и `УчебныеФункцииКлиент` с правильными флагами.
2. `РассчитатьСумму` живёт в общем модуле и вызывается с клиента, а в модуле формы её больше нет.
3. Вы воспроизвели и устранили ошибку из-за отсутствия `Экспорт`.
4. Вы воспроизвели и устранили ошибку из-за снятого флага **Вызов сервера**.
5. `ПолучитьЦенуТовара` объявлена с директивой `&НаСервереБезКонтекста` и возвращает цену «Цемента М500».
