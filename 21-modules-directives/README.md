# Занятие 21. Модули и директивы компиляции

## Цель

Разобраться, где в конфигурации живёт код: какие бывают модули, зачем нужен общий модуль, что делает слово `Экспорт` и что означают директивы компиляции.

## Результат занятия

В конфигурации появятся общие модули `УчебныеФункции` (серверный) и `УчебныеФункцииКлиент` (клиентский), а расчёт суммы переедет из модуля формы в общий модуль. Вы увидите две ошибки компиляции: процедура без `Экспорт` и серверная процедура без флага **Вызов сервера**. Директива `&НаСервере`, которую занятие 18 дало как простую пометку, наконец получит объяснение.
