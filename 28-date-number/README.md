# Занятие 28. Дата, номер и нумераторы

## Цель

Понять, почему дата документа — это момент события, а номер — удобство для человека, а не бизнес-идентификатор. Научиться настраивать автонумерацию, длину и периодичность номера и объяснять, какой номер получит очередной документ.

## Результат занятия

У документа `ЗаявкаНаМатериалы` из занятия 26 будет настроена нумерация: тип и длина номера, автонумерация, контроль уникальности и периодичность «В пределах года». В приложении появится несколько заявок, и вы увидите своими глазами, как платформа выдаёт номера подряд, как нумерация начинается заново в новом году и почему номер не меняется при смене даты документа.
