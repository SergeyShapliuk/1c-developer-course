# Занятие 85. Условное оформление формы

## Цель

Научиться выделять в формах то, на что пользователь обязан обратить внимание: отклонённые и срочные заявки в журнале, строки без цены в документе. Понять, как устроено условное оформление формы, чем оно похоже на условное оформление отчёта из занятия 77 и почему для строк динамического списка это единственный способ поменять вид строки без кода.

## Результат занятия

В журнале заявок отклонённые заявки выводятся серым текстом всей строкой, а приоритет срочных заявок — жирным красным. В форме заявки ячейка цены, равной нулю, подсвечивается фоном, пока цена не заполнена. Все три правила заданы в условном оформлении форм, без строки кода.
