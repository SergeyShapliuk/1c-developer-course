# Занятие 56. Результат запроса: порядок, количество, повторы

## Цель

Научиться управлять тем, каким вернётся ответ: в каком порядке идут строки, сколько их, есть ли среди них повторы. Понять, когда результат обходят выборкой, а когда выгружают в таблицу значений, и как проверить, что ответ пуст.

## Результат занятия

В обработке `УчебнаяКонсоль` появятся три процедуры: список материалов, которые хоть раз заказывались, без повторов и по алфавиту; пять самых крупных строк заявок по количеству; проверка заявок объекта с отдельным сообщением на случай, когда заявок нет. Одна из процедур выгружает результат в таблицу значений и сообщает количество строк.
