# Теория. Результат запроса

## Какую задачу мы решаем

Отбирать строки мы научились на занятии 55, но ответ всё ещё бывает неудобным. Снабженец хочет знать, какие материалы вообще заказывались, а получает «Цемент М500» столько раз, сколько было строк с цементом. Начальник участка просит пять самых крупных позиций, а получает все строки в случайном порядке. А когда по объекту нет ни одной заявки, консоль молчит, и непонятно, сработал ли код вообще.

Всё это — вопросы не к отбору строк, а к **форме ответа**: порядок, количество, повторы и пустой результат.

## Порядок строк: УПОРЯДОЧИТЬ ПО

Без явного указания **порядок строк результата не гарантирован**. Сегодня строки придут в порядке ввода, завтра — в другом, если база перестроит свои индексы. Полагаться на «так получилось» нельзя.

Порядок задаёт секция `УПОРЯДОЧИТЬ ПО`, которая пишется в конце запроса:

```bsl
ВЫБРАТЬ
	Товары.Наименование КАК Наименование
ИЗ
	Справочник.Товары КАК Товары
УПОРЯДОЧИТЬ ПО
	Наименование
```

После `УПОРЯДОЧИТЬ ПО` указывают псевдоним поля результата или поле источника. Направление задают словами `ВОЗР` (по возрастанию, подразумевается по умолчанию) и `УБЫВ` (по убыванию). Полей сортировки может быть несколько через запятую: сначала строки упорядочиваются по первому, при равенстве — по второму.

## Количество строк: ПЕРВЫЕ

`ПЕРВЫЕ N` сразу после `ВЫБРАТЬ` ограничивает результат первыми `N` строками:

```bsl
ВЫБРАТЬ ПЕРВЫЕ 5
	ЗаявкаМатериалы.Материал КАК Материал,
	ЗаявкаМатериалы.Количество КАК Количество
ИЗ
	Документ.ЗаявкаНаМатериалы.Материалы КАК ЗаявкаМатериалы
УПОРЯДОЧИТЬ ПО
	Количество УБЫВ
```

`ПЕРВЫЕ` без `УПОРЯДОЧИТЬ ПО` почти всегда ошибка: «первые пять» в негарантированном порядке — это пять случайных строк. Вместе они дают осмысленный ответ: пять строк с наибольшим количеством.

## Повторы: РАЗЛИЧНЫЕ

`РАЗЛИЧНЫЕ` после `ВЫБРАТЬ` убирает из результата полностью совпадающие строки. Запрос «какие материалы заказывались» по таблице строк заявок вернёт цемент трижды, если он есть в трёх строках; с `РАЗЛИЧНЫЕ` — один раз.

Важно слово «полностью». Совпадение проверяется по **всем полям** результата. Если в запрос добавить поле `Количество`, строки «цемент — 100» и «цемент — 40» станут разными, и обе останутся. `РАЗЛИЧНЫЕ` отвечает на вопрос «какие сочетания значений встречаются», а не «сколько всего». Сложить количества по материалу — задача группировки, она появится на занятии 59.

## Два способа взять результат

Метод `Выполнить()` возвращает объект `РезультатЗапроса`. Работать с ним можно двумя способами.

| Способ | Что получаем | Когда подходит |
| --- | --- | --- |
| `Выбрать()` | выборку: курсор, который один раз проходит строки по порядку | нужно обработать каждую строку и забыть |
| `Выгрузить()` | `ТаблицаЗначений` со всеми строками в памяти | нужно посчитать строки, обойти их несколько раз, найти строку, передать таблицу дальше |

Выборка экономна: строки читаются по мере движения курсора. Таблица значений из занятия 18 удобнее: у неё есть `Количество()`, `Найти()`, `Итог()`, её можно обойти циклом `Для Каждого` сколько угодно раз. Платить за удобство приходится памятью, поэтому выгружать в таблицу миллион строк, чтобы обойти их один раз, не стоит.

`ТаблицаЗначений`, как и сам запрос, существует только на сервере. Вернуть её в клиентскую процедуру формы нельзя — клиенту передают уже подготовленные простые значения или данные формы.

## Пустой результат

Метод `Пустой()` объекта `РезультатЗапроса` возвращает `Истина`, если в ответе нет ни одной строки:

```bsl
Результат = Запрос.Выполнить();
Если Результат.Пустой() Тогда
	Сообщить("Заявок по объекту нет");
	Возврат;
КонецЕсли;
Выборка = Результат.Выбрать();
```

Проверка пустого результата — не украшение. Код, который молча ничего не выводит, невозможно отличить от кода, который не выполнился. Пользователь должен узнать, что ответ получен и он пуст.

## Что важно запомнить

1. Без `УПОРЯДОЧИТЬ ПО` порядок строк результата не гарантирован; `ВОЗР` — по умолчанию, `УБЫВ` — в обратную сторону.
2. `ПЕРВЫЕ N` ограничивает количество строк и имеет смысл только вместе с упорядочиванием.
3. `РАЗЛИЧНЫЕ` убирает строки, совпадающие по всем полям результата; для сложения количеств нужна группировка.
4. `Выбрать()` даёт однопроходную выборку, `Выгрузить()` — таблицу значений в памяти сервера.
5. `Пустой()` проверяет, что в результате нет строк, и позволяет честно сообщить об этом пользователю.
