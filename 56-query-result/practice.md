# Практика. Ответ в нужной форме

## Перед началом

Запустите конфигуратор учебной конфигурации **«Управление строительной компанией с логистикой»** и откройте модуль формы обработки `УчебнаяКонсоль`. Понадобятся заявки из занятия 55: несколько заявок «ЖК Северный» и одна на другой объект, с цементом, кирпичом и песком в строках. Нужно, чтобы хотя бы один материал встречался в двух разных заявках.

После каждой правки кода: `Ctrl+S`, затем `F5`, раздел **Разработка → Учебная консоль**, кнопка **Выполнить**.

## Шаг 1. Получите повторы и уберите их

Вопрос: «Какие материалы хоть раз заказывались?»

1. Добавьте процедуру и вызовите её из `Выполнить` вместо прежних вызовов:

```bsl
&НаСервере
Процедура ВывестиЗаказанныеМатериалы()

	Запрос = Новый Запрос;
	Запрос.Текст =
		"ВЫБРАТЬ
		|	ЗаявкаМатериалы.Материал КАК Материал
		|ИЗ
		|	Документ.ЗаявкаНаМатериалы.Материалы КАК ЗаявкаМатериалы";

	Выборка = Запрос.Выполнить().Выбрать();

	Пока Выборка.Следующий() Цикл
		Сообщить(Строка(Выборка.Материал));
	КонецЦикла;

КонецПроцедуры
```

2. Запустите консоль. Материал, который встречается в нескольких строках, выведен несколько раз.
3. Замените `"ВЫБРАТЬ` на `"ВЫБРАТЬ РАЗЛИЧНЫЕ` и запустите снова. Каждый материал выведен один раз.
4. Добавьте в список полей `ЗаявкаМатериалы.Количество КАК Количество` и запустите ещё раз. Повторы вернулись: строки с разным количеством уже не совпадают полностью.
5. Уберите поле `Количество`.

Запишите в конспект, почему на шаге 4 `РАЗЛИЧНЫЕ` перестало убирать повторы.

**Проверка:** каждый заказанный материал выводится ровно один раз.

## Шаг 2. Упорядочите ответ

1. Допишите в конец текста запроса:

```bsl
		|УПОРЯДОЧИТЬ ПО
		|	Материал";
```

2. Запустите консоль. Материалы выводятся по алфавиту.

`Материал` — псевдоним поля результата, а само поле ссылочного типа. Упорядочивая по ссылке, платформа сортирует по её представлению, то есть для материалов — по наименованию. Поэтому и вышел алфавитный порядок, хотя наименование мы в запрос не добавляли.

**Проверка:** материалы выводятся по алфавиту, без повторов.

## Шаг 3. Найдите пять крупнейших строк

Вопрос: «Какие пять строк заявок самые крупные по количеству?»

1. Добавьте процедуру `ВывестиКрупнейшиеСтроки`:

```bsl
&НаСервере
Процедура ВывестиКрупнейшиеСтроки()

	Запрос = Новый Запрос;
	Запрос.Текст =
		"ВЫБРАТЬ ПЕРВЫЕ 5
		|	ЗаявкаМатериалы.Ссылка КАК Заявка,
		|	ЗаявкаМатериалы.Материал КАК Материал,
		|	ЗаявкаМатериалы.Количество КАК Количество
		|ИЗ
		|	Документ.ЗаявкаНаМатериалы.Материалы КАК ЗаявкаМатериалы
		|УПОРЯДОЧИТЬ ПО
		|	Количество УБЫВ";

	Таблица = Запрос.Выполнить().Выгрузить();

	Сообщить("Строк в ответе: " + Таблица.Количество());

	Для Каждого СтрокаОтвета Из Таблица Цикл
		Сообщить(Строка(СтрокаОтвета.Заявка) + ": " + Строка(СтрокаОтвета.Материал) + " — " + СтрокаОтвета.Количество);
	КонецЦикла;

КонецПроцедуры
```

2. Добавьте вызов в `Выполнить`, запустите.

Здесь результат не выбирается, а выгружается в `ТаблицаЗначений`. Это нужно, чтобы до обхода узнать количество строк методом `Количество()`: выборка своего размера заранее не знает. Обходим таблицу циклом `Для Каждого`, как на занятии 18.

3. Временно уберите из текста секцию `УПОРЯДОЧИТЬ ПО` вместе с полем и запустите. Пять строк по-прежнему выводятся, но это уже не крупнейшие, а какие попались. Верните упорядочивание.

**Проверка:** выведено не больше пяти строк, и количество в них убывает сверху вниз.

## Шаг 4. Сообщите о пустом ответе

Вопрос: «Есть ли заявки по выбранному объекту?» Ответ «нет» тоже должен быть виден.

1. Добавьте процедуру `ПроверитьЗаявкиОбъекта` с запросом к `Документ.ЗаявкаНаМатериалы` и условием `Заявки.ОбъектСтроительства = &ОбъектСтроительства`, как на занятии 55.
2. Перед выборкой вставьте проверку:

```bsl
	Результат = Запрос.Выполнить();

	Если Результат.Пустой() Тогда
		Сообщить("По объекту «" + Строка(ОбъектСтроительства) + "» заявок нет");
		Возврат;
	КонецЕсли;

	Выборка = Результат.Выбрать();
```

3. Запустите консоль для «ЖК Северный» — выводятся заявки.
4. Замените параметр на объект строительства, по которому заявок нет. Если такого объекта нет, создайте его в справочнике `ОбъектыСтроительства`. Запустите снова — выводится сообщение об отсутствии заявок.

**Проверка:** для объекта без заявок консоль явно сообщает, что заявок нет.

## Шаг 5. Выберите способ получения результата

Для каждой задачи запишите в конспект, что вы выберете — `Выбрать()` или `Выгрузить()` — и почему.

| Задача | Способ и причина |
| --- | --- |
| Вывести сообщением каждую строку один раз | |
| Сообщить, сколько строк в ответе, до их вывода | |
| Дважды пройти один и тот же ответ: сначала проверить, потом вывести | |
| Обработать сто тысяч строк движений по одной | |

Верные направления: однократный обход и большие объёмы — выборка; подсчёт, повторный обход и поиск — таблица значений.

**Проверка:** для каждой задачи выбран способ и записана причина.

## Проверка результата

Занятие пройдено, если выполняются пять условий:

1. Процедура `ВывестиЗаказанныеМатериалы` выводит заказанные материалы без повторов и по алфавиту.
2. Процедура `ВывестиКрупнейшиеСтроки` выводит не больше пяти строк в порядке убывания количества и сообщает их число.
3. Процедура `ПроверитьЗаявкиОбъекта` сообщает об отсутствии заявок, если результат пуст.
4. Вы можете объяснить, почему `ПЕРВЫЕ` без `УПОРЯДОЧИТЬ ПО` даёт случайный ответ.
5. Вы можете объяснить, когда выгружать результат в таблицу значений, а когда обходить выборкой.

## Контрольные вопросы

Не подглядывая в теорию, ответьте устно или в заметках:

1. Почему нельзя полагаться на порядок строк результата без `УПОРЯДОЧИТЬ ПО`?
2. Почему `РАЗЛИЧНЫЕ` перестаёт убирать повторы, когда в запрос добавляют поле `Количество`?
3. Чем выборка отличается от таблицы значений, полученной методом `Выгрузить()`?
4. Зачем проверять результат методом `Пустой()`, если цикл по пустой выборке просто ничего не сделает?
5. Форме заявки нужен список пяти крупнейших строк. Можно ли вернуть таблицу значений из серверной процедуры в клиентскую и где тогда выполнять запрос и обход результата?

Сверьте ответы с [теорией](theory.md). Если на каждый вопрос получается ответить одним-двумя предложениями, переходите к занятию 57.
