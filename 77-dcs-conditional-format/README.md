# Занятие 77. Условное оформление

## Цель

Научиться делать важное в отчёте заметным: выделять строки по условию на данные, заменять вводящий в заблуждение ноль понятным текстом и задавать формат чисел. Понять, из чего состоит правило условного оформления, на каком уровне структуры оно должно действовать и почему оформление — это настройка, а не код.

## Результат занятия

В отчёте `ОстаткиНаСкладах` отрицательный остаток будет выделяться красным шрифтом на всех уровнях — в строке материала, склада и в общем итоге. У материала без цены вместо цены и нулевой стоимости будет написано «нет цены», и только в строке материала. Стоимость будет выводиться с двумя знаками после запятой. Проверка — передача задним числом сверх остатка, которую разрешает контроль занятия 67.
