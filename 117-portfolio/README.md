# Занятие 117. Портфолио на учебном проекте

## Цель

Превратить репозиторий `construction-erp` в портфолио, которое работодатель поймёт за десять минут: что делает система, как она устроена, как её развернуть, как в ней работают процесс разработки и тесты. Научиться честно описывать учебный проект и проверять, что в публичный репозиторий не попадает лишнее.

## Результат занятия

В корне `construction-erp` появится `README.md` проекта: назначение, возможности, архитектура, развёртывание из файлов, тесты, процесс разработки и известные ограничения. В каталоге `docs` — архитектурные решения и списки изменений версий. Инструкция развёртывания проверена на пустой базе дословно, по одному только README. Изменение прошло ветку и коммит слияния. В конспекте — двухминутный рассказ о проекте для собеседования. Если вы публикуете репозиторий, он лежит на GitHub с тегами версий и без личных данных.

## Маршрут

1. Прочитайте [теорию](theory.md) — около 25 минут.
2. Выполните [практику](practice.md) — около 90 минут.
3. Ответьте на контрольные вопросы в конце практики, не подглядывая в теорию.

## Ключевые термины

Портфолио, README проекта, архитектурное решение, инструкция развёртывания, известные ограничения, технический долг, честное описание учебного проекта, публичный репозиторий, адрес почты в коммитах, личные данные, рассказ о проекте.
