# Занятие 94. Текущий пользователь и параметры сеанса

## Цель

Научить конфигурацию знать, какой сотрудник сейчас работает и на каком складе, чтобы подставлять это в документы и использовать в ограничениях доступа. Понять, как связать пользователя информационной базы со справочником сотрудников, что такое параметры сеанса, когда их заполняет модуль сеанса и почему вычислять «кто я» один раз за сеанс лучше, чем в каждом документе.

## Результат занятия

У справочника `Сотрудники` появятся реквизиты `ИмяПользователя` и `Склад`, у сотрудников Петрова, Сидоровой и Кузнецова — связь с их пользователями. В конфигурации появятся параметры сеанса `ТекущийСотрудник` и `ТекущийСклад`, которые модуль сеанса заполняет при входе. Новая передача у Петрова сразу получает ответственного «Петров Пётр» и склад «Центральный склад», новая заявка у Сидоровой — ответственного «Сидорова Анна».
