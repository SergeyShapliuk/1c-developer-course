## Шаг 1. Решите билет

**1.** Чем `Доступность = Ложь` отличается от `Видимость = Ложь` у кнопки формы?

- А) Ничем
- Б) Недоступная кнопка скрыта, невидимая видна серым
- В) Недоступная кнопка видна, но нажать её нельзя; невидимой кнопки на форме нет
- Г) Недоступность действует только в веб-клиенте

**2.** Параметр выбора `Отбор.ВидКлиента = Поставщик` задан у реквизита `Поставщик` документа. В каких формах он действует?

- А) Только в форме, где его задали
- Б) Во всех формах документа, где есть поле этого реквизита
- В) Только в автогенерируемой форме
- Г) Ни в одной: параметры выбора задают только у элемента формы

**3.** Документ с поставщиком-заказчиком записывают из кода, хотя у реквизита заданы параметры выбора. Что произойдёт?

- А) Запись пройдёт, если правило не проверяется в модуле объекта
- Б) Запись отклонена параметрами выбора
- В) Платформа заменит поставщика на первого подходящего
- Г) Возникнет ошибка компиляции

**4.** Где должно быть продолжение действия после ответа пользователя на `ПоказатьВопрос`?

- А) Следующей строкой после `ПоказатьВопрос`
- Б) В экспортной процедуре, имя которой указано в `ОписаниеОповещения`
- В) В обработчике `ПриЗакрытии` формы
- Г) В модуле приложения

**5.** Почему форма списка на динамическом списке быстро открывается при ста тысячах документов?

- А) Динамический список загружает все документы заранее, при запуске программы
- Б) Динамический список показывает только документы текущего месяца
- В) Динамический список хранит документы на клиенте
- Г) Динамический список читает из базы порциями только то, что видно на экране

**6.** Где обычно формируют табличный документ печатной формы?

- А) В клиентской процедуре формы
- Б) На сервере, в модуле менеджера документа
- В) В модуле приложения
- Г) В макете, без кода

**7.** Команда печати накладной запускается из журнала для нескольких выделенных документов. Режим параметра команды — «Множественный». Что получает обработчик в `ПараметрКоманды`?

- А) Массив ссылок на выделенные документы
- Б) Ссылку на первый выделенный документ
- В) Табличный документ
- Г) Динамический список журнала

**8.** Как добиться, чтобы каждая накладная пачки печаталась с новой страницы?

- А) Ничего не делать: платформа разбивает документы по страницам сама
- Б) Перед каждой накладной, кроме первой, выводить `ВывестиГоризонтальныйРазделительСтраниц`
- В) Формировать каждую накладную в отдельном окне
- Г) Задать в макете высоту страницы

**9.** У роли есть основное право **Изменение** документа, но нет интерактивного права **Редактирование**. Что верно?

- А) Документ нельзя изменить никак
- Б) Пользователь изменит документ в форме, но не из кода
- В) Пользователь не откроет документ для правки в форме, но код, выполняемый от его имени, изменить и записать его может
- Г) Права **Изменение** без **Редактирования** не бывает

**10.** Кнопка формы открывает отчёт. Она должна быть видна каждому, у кого есть право на этот отчёт, при любых ролях. Какой проверкой задать видимость?

- А) `РольДоступна("Снабженец")`
- Б) `ПравоДоступа("Просмотр", Метаданные.Отчеты.ОстаткиНаСкладах)`
- В) `ЗначениеЗаполнено(ПараметрыСеанса.ТекущийСотрудник)`
- Г) `УстановитьПривилегированныйРежим(Истина)`

**11.** Что делает `УстановитьПривилегированныйРежим(Истина)` в серверном коде?

- А) Даёт пользователю роль администратора до конца сеанса
- Б) Включает запись событий в журнал регистрации
- В) Ускоряет выполнение запросов
- Г) Отключает проверку прав для следующего за ним серверного кода, пока режим не выключат

**12.** Администратор сменил склад у сотрудника Петрова, пока Петров работает в программе. Когда Петров получит новый склад в параметре сеанса `ТекущийСклад`?

- А) Сразу
- Б) Со следующего входа: параметр сеанса вычисляется при начале сеанса
- В) После обновления конфигурации базы данных
- Г) Никогда: параметр сеанса задают один раз

**13.** У пользователя ограничено чтение передач условием по складу. Запрос в коде без `РАЗРЕШЕННЫЕ` выбирает все передачи. Что произойдёт?

- А) Запрос завершится ошибкой нехватки прав, встретив запрещённые записи
- Б) Запрос вернёт только разрешённые передачи
- В) Запрос вернёт все передачи, включая запрещённые
- Г) Запрос вернёт пустой результат

**14.** Каким методом записывают в журнал регистрации своё событие — например, отклонение заявки?

- А) `Сообщить`
- Б) `ЗаписьЖурналаРегистрации`
- В) `ВызватьИсключение`
- Г) `Движения.Записать`

**15.** В расширении нужно добавить проверку перед записью заявки, сохранив проверки основной конфигурации. Какую аннотацию выбрать?

- А) `&Вместо("ПередЗаписью")`
- Б) Аннотация не нужна: процедура расширения заменит основную автоматически
- В) `&Перед("ПередЗаписью")`
- Г) `&НаСервере`

**Проверка:** на все пятнадцать вопросов записаны ответы, время записано.

## Шаг 3. Проверьте спорное экспериментом

1. **Подсказка и гарантия.** Добавьте в модуль формы `УчебнаяКонсоль` серверную процедуру:

```bsl
&НаСервереБезКонтекста
Процедура ПроверитьПодсказкуИГарантию()

	НачатьТранзакцию();
	Попытка
		Передача = Документы.ПередачаМатериалов.СоздатьДокумент();
		Передача.Дата = ТекущаяДатаСеанса();
		Передача.Склад = Справочники.Склады.НайтиПоНаименованию("Центральный склад");
		Передача.ОбъектСтроительства = Справочники.ОбъектыСтроительства.НайтиПоНаименованию("ЖК Восточный");
		СтрокаМатериалов = Передача.Материалы.Добавить();
		СтрокаМатериалов.Материал = Справочники.Товары.НайтиПоНаименованию("Песок речной");
		СтрокаМатериалов.Количество = 1;

		Передача.Записать();
		Сообщить("Записана передача на завершённый объект: параметр выбора её не остановил");

		Передача.Записать(РежимЗаписиДокумента.Проведение, РежимПроведенияДокумента.Оперативный);
		Сообщить("Проведена — так быть не должно");
	Исключение
		Сообщить("Проведение отклонено модулем объекта");
	КонецПопытки;
	ОтменитьТранзакцию();

КонецПроцедуры
```

Вызовите её из команды консоли и выполните. Сообщения: передача записана, затем — сообщение о завершённом объекте из `ОбработкаПроведения` и «Проведение отклонено модулем объекта». Подсказка поля не участвовала вовсе, гарантию дал модуль объекта. Транзакция отменена, в журнале передач этой передачи нет.
