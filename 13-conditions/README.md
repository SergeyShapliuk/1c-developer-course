# Занятие 13. Условия

## Цель

Научиться ветвить выполнение кода: выбирать действие по значению, объединять несколько проверок логическими операторами и защищать расчёт от незаполненных данных.

## Результат занятия

Обработка `УчебнаяКонсоль` рассчитывает скидку по сумме заказа тремя ветками, проверяет количество на попадание в диапазон, подставляет единицу измерения по умолчанию, различает вид клиента по значению перечисления и отказывается считать, если цена не заполнена. Вы понимаете, зачем в логическом выражении нужны скобки.

## Маршрут

1. Прочитайте [теорию](theory.md) — около 25 минут.
2. Выполните [практику](practice.md) — около 50 минут.
3. Ответьте на контрольные вопросы в конце практики, не подглядывая в теорию.

## Ключевые термины

`Если`, `Тогда`, `ИначеЕсли`, `Иначе`, `КонецЕсли`, ветка, операторы сравнения, `И`, `ИЛИ`, `НЕ`, приоритет операторов, сокращённое условие `?()`, ранняя проверка, вложенность условий.
