# Занятие 8. Реквизиты, типы данных и ссылочные типы

## Цель

Научиться добавлять объектам собственные поля и осознанно выбирать для них тип данных. Понять, чем ссылка на элемент справочника принципиально лучше хранения его названия строкой.

## Результат занятия

Все пять справочников проекта получат реквизиты: контакты и вид клиента, артикул и цену товара, должность и дату приёма сотрудника, адрес и ответственного по складу, адрес, дату начала работ и заказчика по объекту строительства. Карточки элементов, введённых на занятии 6, будут заполнены — в том числе ссылочные поля, которые выбираются из списка, а не набираются текстом.

## Маршрут

1. Прочитайте [теорию](theory.md) — около 25 минут.
2. Выполните [практику](practice.md) — около 60 минут.
3. Ответьте на контрольные вопросы в конце практики, не подглядывая в теорию.

## Ключевые термины

Реквизит, тип данных, примитивный тип, Строка, Число, Дата, Булево, длина, точность, состав даты, ссылочный тип, СправочникСсылка, ПеречислениеСсылка, пустая ссылка, составной тип.
