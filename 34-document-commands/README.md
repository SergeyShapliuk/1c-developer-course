# Занятие 34. Команды документа

## Цель

Понять, чем команда формы отличается от команды объекта, и разобраться, какие команды у документа уже есть без нашего участия. Научиться добавлять документу собственную команду, которая выполняет серверную работу одним вызовом.

## Результат занятия

У формы документа `ЗаявкаНаМатериалы` появится кнопка **Пересчитать заявку**: она за один серверный вызов пересчитает суммы всех строк табличной части из занятия 31, обновит итог и выведет сводку по строкам. Долг занятия 32 — итог, который не обновлялся после удаления строки, — будет закрыт.

## Маршрут

1. Прочитайте [теорию](theory.md) — около 25 минут.
2. Выполните [практику](practice.md) — около 60 минут.
3. Ответьте на контрольные вопросы в конце практики, не подглядывая в теорию.

## Ключевые термины

Команда формы, команда объекта, общая команда, стандартные команды, **Записать**, **Записать и закрыть**, командный интерфейс формы, свойство **Действие**, `&НаСервере`, серверный вызов, `Новый Структура`.
