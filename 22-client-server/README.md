# Занятие 22. Клиент, сервер и серверные вызовы

## Цель

Понять, что такое клиент и сервер в 1С, что доступно на каждой стороне и почему число серверных вызовов напрямую определяет скорость работы формы.

## Результат занятия

Вы сделаете медленный вариант кода — двадцать серверных вызовов в цикле — и быстрый вариант с одним вызовом, замерите оба и увидите разницу в числах. Вы воспроизведёте две типовые ошибки: обращение к `Справочники` из клиентского кода и попытку показать предупреждение на сервере. Таблица значений из занятия 18 переедет на сервер правильно: считаться будет там, а клиенту вернётся массив структур.

## Маршрут

1. Прочитайте [теорию](theory.md) — около 25 минут.

## Ключевые термины

Клиент, сервер, серверный вызов, контекст формы, передача контекста, `ТекущаяУниверсальнаяДатаВМиллисекундах()`, массив структур, антипаттерн «вызов в цикле».
