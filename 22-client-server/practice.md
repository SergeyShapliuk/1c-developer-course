# Практика. Считаем серверные вызовы

## Перед началом

Запустите конфигуратор учебной конфигурации **«Управление строительной компанией с логистикой»**.

Откройте **Обработки → УчебнаяКонсоль**, раскройте её **Формы**, откройте форму и перейдите на вкладку **Модуль**. Весь клиентский код занятия пишем внутри обработчика команды `&НаКлиенте Процедура Выполнить(Команда)`.

Нам понадобятся результаты занятия 21: функция `ПолучитьЦенуТовара` в модуле формы и общий модуль `УчебныеФункцииКлиент`. Если их нет, вернитесь к занятию 21 и выполните шаги 5 и 6.

После каждой правки: `Ctrl+S`, затем `F5` — платформа предложит обновить конфигурацию базы данных, согласитесь. В запущенном приложении откройте раздел **Разработка**, выберите обработку **Учебная консоль** и нажмите **Выполнить**.

Для замеров нужна встроенная функция `ТекущаяУниверсальнаяДатаВМиллисекундах()`. Она возвращает число миллисекунд. Само значение смысла не имеет; смысл имеет разница двух таких значений, взятых до и после работы кода.

## Шаг 1. Плохой вариант: двадцать вызовов

```bsl
&НаКлиенте
Процедура Выполнить(Команда)
	НачалоЗамера = ТекущаяУниверсальнаяДатаВМиллисекундах();

	Для Счётчик = 1 По 20 Цикл
		Цена = ПолучитьЦенуТовара("Цемент М500");
	КонецЦикла;

	Длительность = ТекущаяУниверсальнаяДатаВМиллисекундах() - НачалоЗамера;
	Сообщить(УчебныеФункцииКлиент.ОформитьСообщение("Двадцать вызовов, мс", Длительность));
КонецПроцедуры
```

1. `Ctrl+S`, `F5`, нажмите **Выполнить** и запишите полученное число.
2. Нажмите **Выполнить** ещё два-три раза и запишите ещё числа: первый замер обычно больше остальных, потому что платформа только что подготовила соединение.

Код работает правильно. Проблема в другом: внутри цикла стоит серверный вызов, поэтому клиент двадцать раз сходил на сервер за одной и той же цифрой.

**Проверка:** выведена длительность в миллисекундах, и вы записали несколько её значений.

## Шаг 2. Хороший вариант: один вызов

Привезём все цены одним вызовом. Нужна серверная функция, которая вернёт массив структур — по одной структуре на товар, с полями `Наименование` и `Цена` (массивы и структуры разбирались на занятии 17, перебор справочника — на занятии 19).

1. Добавьте в модуль формы:

```bsl
&НаСервереБезКонтекста
Функция ПолучитьВсеТовары()
	Результат = Новый Массив;

	Выборка = Справочники.Товары.Выбрать();
	Пока Выборка.Следующий() Цикл
		Если Выборка.ПометкаУдаления Тогда
			Продолжить;
		КонецЕсли;
		Элемент = Новый Структура;
		Элемент.Вставить("Наименование", Выборка.Наименование);
		Элемент.Вставить("Цена", Выборка.Цена);
		Результат.Добавить(Элемент);
	КонецЦикла;

	Возврат Результат;
КонецФункции
```

2. Перепишите обработчик так, чтобы серверный вызов был ровно один, а перебор шёл на клиенте:

```bsl
&НаКлиенте
Процедура Выполнить(Команда)
	НачалоЗамера = ТекущаяУниверсальнаяДатаВМиллисекундах();

	Товары = ПолучитьВсеТовары();
	Для Каждого Товар Из Товары Цикл
		Цена = Товар.Цена;
	КонецЦикла;

	Длительность = ТекущаяУниверсальнаяДатаВМиллисекундах() - НачалоЗамера;
	Сообщить(УчебныеФункцииКлиент.ОформитьСообщение("Один вызов, мс", Длительность));
	Сообщить(УчебныеФункцииКлиент.ОформитьСообщение("Получено товаров", Товары.Количество()));
КонецПроцедуры
```

3. `Ctrl+S`, `F5`, нажмите **Выполнить** несколько раз и запишите числа.

**Проверка:** выведены длительность и количество полученных товаров.

## Шаг 3. Сравните замеры

| Вариант | Серверных вызовов | Замер 1, мс | Замер 2, мс | Замер 3, мс |
| --- | --- | --- | --- | --- |
| Двадцать вызовов в цикле | 20 | | | |
| Один вызов за массивом | 1 | | | |

Сервер в обоих вариантах делает примерно одинаковую работу — читает справочник. Но в первом к этой работе двадцать раз добавляются накладные расходы на переход клиент → сервер и обратно, а во втором — один раз.

Предупреждение: на файловой базе разница будет небольшой, иногда в единицы миллисекунд, потому что клиент и сервер живут в одном процессе. На клиент-серверной базе с сетью между ними та же разница измеряется секундами. Направление одно и то же, меняется только масштаб — поэтому привычку считать вызовы надо заводить сразу.

**Проверка:** таблица заполнена, и вариант с одним вызовом не медленнее варианта с двадцатью.

## Шаг 4. Проверьте границу клиента

1. Добавьте в начало `&НаКлиенте Процедура Выполнить` строку:

```bsl
	Товар = Справочники.Товары.НайтиПоНаименованию("Цемент М500");
```

2. Выполните **Конфигурация → Проверка → Синтаксический контроль**.
3. Прочитайте ошибку: переменная или метод не обнаружены. На клиенте имени `Справочники` просто не существует — менеджеров объектов для клиентского кода нет.
4. Удалите строку и повторите синтаксический контроль.

**Проверка:** ошибка воспроизведена и устранена.

## Шаг 5. Проверьте границу сервера

1. Добавьте в начало `&НаСервереБезКонтекста Функция ПолучитьВсеТовары` строку:

```bsl
	ПоказатьПредупреждение("Готово");
```

2. Выполните синтаксический контроль и прочитайте ошибку: метод недоступен в серверном контексте. Показывать окно некому — у сервера нет экрана.
3. Удалите строку.
4. Сделайте правильно: сервер только возвращает данные, а предупреждение показывает клиент после возврата.

```bsl
&НаКлиенте
Процедура Выполнить(Команда)
	Товары = ПолучитьВсеТовары();
	ПоказатьПредупреждение(, "Получено товаров: " + Строка(Товары.Количество()));
КонецПроцедуры
```

5. `Ctrl+S`, `F5`, **Выполнить** — появится модальное окно с текстом.

Первый параметр `ПоказатьПредупреждение` оставлен пустым: там указывают, что сделать после закрытия окна, а нам этого пока не нужно.

**Проверка:** серверная версия вызывала ошибку, клиентская показала окно с числом товаров.

## Шаг 6. Перепишите таблицу значений из занятия 18

На занятии 18 в модуле формы появилась процедура `&НаСервере Процедура ПостроитьТаблицуМатериалов()`. Она строила `ТаблицаЗначений` на сервере и там же её разбирала. Теперь мы знаем, как отдать результат клиенту.

1. Добавьте в модуль формы функцию:

```bsl
&НаСервереБезКонтекста
Функция ПолучитьМатериалыМассивом()
	Материалы = Новый ТаблицаЗначений;
	Материалы.Колонки.Добавить("Наименование");
	Материалы.Колонки.Добавить("Цена");

	Выборка = Справочники.Товары.Выбрать();
	Пока Выборка.Следующий() Цикл
		Если Выборка.ПометкаУдаления Тогда
			Продолжить;
		КонецЕсли;
		НоваяСтрока = Материалы.Добавить();
		НоваяСтрока.Наименование = Выборка.Наименование;
		НоваяСтрока.Цена = Выборка.Цена;
	КонецЦикла;

	Материалы.Сортировать("Цена Убыв");

	Результат = Новый Массив;
	Для Каждого СтрокаТаблицы Из Материалы Цикл
		Элемент = Новый Структура("Наименование, Цена", СтрокаТаблицы.Наименование, СтрокаТаблицы.Цена);
		Результат.Добавить(Элемент);
	КонецЦикла;

	Возврат Результат;
КонецФункции
```

2. Выведите результат на клиенте:

```bsl
&НаКлиенте
Процедура Выполнить(Команда)
	Материалы = ПолучитьМатериалыМассивом();
	Для Каждого Материал Из Материалы Цикл
		Сообщить(УчебныеФункцииКлиент.ОформитьСообщение(Материал.Наименование, Материал.Цена));
	КонецЦикла;
КонецПроцедуры
```

3. `Ctrl+S`, `F5`, **Выполнить** — материалы выведутся по убыванию цены.

Почему так правильно. Таблица значений даёт удобную сортировку и итоги, поэтому считать на сервере в ней уместно. Но вернуть её клиенту нельзя: типа `ТаблицаЗначений` на клиенте не существует. А `Массив` и `Структура` живут на обеих сторонах, поэтому перед возвратом таблицу перекладывают в массив структур. Серверный вызов при этом остаётся один.

**Проверка:** на клиенте выведен список материалов, отсортированный по убыванию цены.

## Шаг 7. Правило на будущее

Перед тем как написать очередную процедуру, задайте себе три вопроса в этом порядке.

1. **Нужны ли данные базы?** Если да — процедура серверная.
2. **Нужен ли диалог с пользователем?** Если да — эта часть обязана быть клиентской, и её выносят в отдельную процедуру.
3. **Нужен ли контекст формы?** Если нет — ставьте `&НаСервереБезКонтекста` и передавайте всё параметрами.

И проверка после написания: нет ли серверного вызова внутри цикла. Если есть — соберите данные одним вызовом.

## Проверка результата

Занятие пройдено, если выполняются пять условий:

1. Вы замерили плохой и хороший варианты и записали числа.
2. Вы можете объяснить, почему двадцать вызовов дороже одного.
3. Вы воспроизвели ошибку обращения к `Справочники` из клиентского кода.
4. Вы воспроизвели ошибку вызова `ПоказатьПредупреждение` в серверной процедуре и сделали правильный вариант.
5. `ПолучитьМатериалыМассивом` строит таблицу на сервере и возвращает клиенту массив структур.
