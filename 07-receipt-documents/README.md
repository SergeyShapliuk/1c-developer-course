# День 7. Документы: закупка и поступление материалов

## Цель

Познакомиться с документами 1С и создать основу для учёта поступления материалов на склад.

## Результат дня

В конфигурации появится документ «ПоступлениеМатериалов» с реквизитами поставщика и склада. Вы создадите тестовый документ в режиме «1С:Предприятие».

## Маршрут

1. Прочитайте [теорию](theory.md).
2. Выполните [практику](practice.md).
3. Ответьте на контрольные вопросы в конце практики.
