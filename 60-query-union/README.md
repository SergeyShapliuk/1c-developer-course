# Занятие 60. Объединение запросов

## Цель

Научиться собирать в один ответ строки из разных таблиц, которые не соединяются по парам, а ставятся друг под другом: приходы из поступлений и расходы из передач. Понять разницу между `ОБЪЕДИНИТЬ` и `ОБЪЕДИНИТЬ ВСЕ` и почему по умолчанию нужен второй вариант.

## Результат занятия

В обработке `УчебнаяКонсоль` появится «история материала»: все проведённые поступления и передачи «Цемента М500» по «Центральному складу» одним списком в порядке дат, с видом операции и количеством со знаком. Сумма изменений, посчитанная по этому списку, совпадёт с остатком, который вы считали по записям регистра на занятии 51.

## Маршрут

1. Прочитайте [теорию](theory.md) — около 25 минут.
2. Выполните [практику](practice.md) — около 50 минут.
3. Ответьте на контрольные вопросы в конце практики, не подглядывая в теорию.

## Ключевые термины

Объединение запросов, `ОБЪЕДИНИТЬ`, `ОБЪЕДИНИТЬ ВСЕ`, часть объединения, поле-константа, совместимость полей, псевдонимы первой части, упорядочивание объединения.
