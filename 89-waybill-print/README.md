# Занятие 89. Накладная: печать нескольких документов

## Цель

Научиться печатать одной командой сразу несколько документов: каждый на своей странице, с данными, полученными одним запросом. Понять, почему для пачки документов чтение через ссылку превращается в «запросы в цикле», как разложить результат пакетного запроса по документам и где проверять, какие документы вообще можно печатать.

## Результат занятия

У документа `ПередачаМатериалов` появятся макет `ПФ_Накладная` и команда объекта **Накладная** в режиме множественного параметра. Кладовщик выделяет в журнале передачи за день и получает накладные одним окном: каждая на отдельной странице, с отправителем-складом, получателем-объектом, материалами, единицами измерения, числом наименований и местами для подписей. Непроведённые передачи не печатаются, и пользователь узнаёт, сколько их пропущено. Все данные собирает один пакетный запрос в модуле менеджера.

## Маршрут

1. Прочитайте [теорию](theory.md) — около 25 минут.
2. Выполните [практику](practice.md) — около 70 минут.
3. Ответьте на контрольные вопросы в конце практики, не подглядывая в теорию.

## Ключевые термины

Накладная, множественный режим параметра, массив ссылок, пакетный запрос, `ВыполнитьПакет`, `НайтиСтроки`, `Параметры.Заполнить`, разделитель страниц, `ВывестиГоризонтальныйРазделительСтраниц`, `ВысотаТаблицы`, чтение через ссылку в цикле.
