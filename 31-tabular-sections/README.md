# Занятие 31. Табличная часть

## Цель

Понять, почему список материалов заявки нельзя уложить в реквизиты шапки, и освоить табличную часть как подчинённую таблицу документа. Научиться создавать табличную часть, подбирать типы её реквизитов и выводить её на форму.

## Результат занятия

У документа `ЗаявкаНаМатериалы` появится табличная часть `Материалы` с реквизитами `Материал`, `Количество`, `Цена` и `Сумма`, выведенная на форму документа из занятия 30. В приложении вы оформите заявку сразу на два материала и увидите, что строк в одном документе может быть сколько угодно. Расчёт суммы остаётся ручным — считать её кодом будем в занятии 32.
