# Занятие 57. Выражения, NULL и обращение через точку

## Цель

Научиться вычислять в запросе новые поля: сумму строки, признак крупной позиции, текстовое представление ссылки. Понять, что происходит, когда в запросе обращаются к реквизиту через точку, откуда в результате берётся `NULL` и как с ним работать.

## Результат занятия

В обработке `УчебнаяКонсоль` появится «расшифровка заявок» для снабженца: по каждой строке — номер заявки, объект строительства, материал, единица измерения, количество, расчётная сумма и признак крупной позиции. Вторая процедура найдёт строки, в которых сохранённая сумма не равна количеству, умноженному на цену.

## Ключевые термины

Выражение в запросе, вычисляемое поле, арифметические операции, `ВЫБОР КОГДА ТОГДА ИНАЧЕ КОНЕЦ`, `NULL`, `ЕСТЬ NULL`, `ЕСТЬNULL`, `ПРЕДСТАВЛЕНИЕ`, обращение через точку, неявное соединение.
