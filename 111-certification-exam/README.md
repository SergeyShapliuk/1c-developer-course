# Занятие 111. Экзамен 1С:Профессионал: формат и план подготовки

## Цель

Понять, что проверяет экзамен 1С:Профессионал по платформе, как устроены его вопросы и почему знающий человек на нём ошибается. Оценить свою готовность по темам курса и составить личный план подготовки на занятия 112–116.

## Результат занятия

В конспекте появятся таблица самооценки по шестнадцати темам экзамена, результат диагностического теста из десяти вопросов с разбором ошибок, файл карточек повторения `exam/cards.md` и план подготовки: какие темы и занятия курса повторить перед каждым тренировочным билетом.

## Маршрут

1. Прочитайте [теорию](theory.md) — около 25 минут.
2. Выполните [практику](practice.md) — около 50 минут.
3. Ответьте на контрольные вопросы в конце практики, не подглядывая в теорию.

## Ключевые термины

Сертификат 1С:Профессионал, тестирование, вопрос с вариантами ответа, правдоподобный неверный ответ, ловушка контекста, самооценка, диагностический тест, карточка повторения, интервальное повторение, 1С:Специалист.
