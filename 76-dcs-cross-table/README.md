# Занятие 76. Таблица и кросс-таблица

## Цель

Научиться выводить ответ в виде таблицы, у которой и строки, и колонки — значения данных: материалы по строкам, объекты строительства по колонкам. Понять, чем элемент структуры **Таблица** отличается от группировки, и почему данные о выдаче на объекты берутся из документов, а не из регистра остатков.

## Результат занятия

В разделе **Логистика** появится отчёт `ВыдачаПоОбъектам`. Он строится по строкам проведённых передач материалов и показывает таблицу «материал × объект строительства» с итогами по строкам и колонкам. Вторая раскладка — «объект × месяц» — показывает, как выдача распределялась во времени. Числа совпадут с графой «выдано на объект» справки снабженца занятия 68.

## Ключевые термины

Элемент структуры «Таблица», строки таблицы, колонки таблицы, кросс-таблица, итоги по строкам и колонкам, пересечение, `НАЧАЛОПЕРИОДА`, источник данных отчёта, условие `Проведен` в запросе.
