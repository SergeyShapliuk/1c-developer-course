# Занятие 32. Работа со строками табличной части

## Цель

Научиться обрабатывать строки табличной части кодом: обходить их циклом, добираться до текущей строки и считать сумму в момент ввода. Понять, почему этот расчёт принадлежит модулю формы.

## Результат занятия

В модуле формы документа `ЗаявкаНаМатериалы` появятся процедуры `ПересчитатьСуммуСтроки` и `ПересчитатьИтогПоЗаявке` и три обработчика изменения колонок табличной части `Материалы` из занятия 31. Сумма строки станет считаться сама, цена будет подставляться из справочника `Товары` при выборе материала, а под таблицей появится итог по заявке.

## Маршрут

1. Прочитайте [теорию](theory.md) — около 25 минут.
2. Выполните [практику](practice.md) — около 60 минут.
3. Ответьте на контрольные вопросы в конце практики, не подглядывая в теорию.

## Ключевые термины

Коллекция строк, `Объект.Материалы`, `Для Каждого`, `Элементы`, `ТекущиеДанные`, обработчик `ПриИзменении`, `МатериалыКоличествоПриИзменении`, разыменование `Материал.Цена`, `УчебныеФункции.РассчитатьСумму`, `&НаСервереБезКонтекста`, реквизит формы `ИтогоПоЗаявке`.
