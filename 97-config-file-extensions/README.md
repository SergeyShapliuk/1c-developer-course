# Занятие 97. Файл конфигурации и расширения

## Цель

Понять, как доработка попадает из базы разработчика в рабочую базу компании, и научиться двум способам: обновлению основной конфигурации из файла и расширению конфигурации. Разобраться, что хранит файл `.cf`, чем он отличается от `.dt`, что такое заимствование объекта и перехват процедуры в расширении и когда какой способ выбирать.

## Результат занятия

У вас будет файл `.cf` с конфигурацией до доработки. В базе появится расширение `ДоработкиСнабжения`: оно заимствует документ `ЗаявкаНаМатериалы` и перед его записью требует комментарий у срочной заявки. Сравнение основной конфигурации с файлом покажет, что она не изменилась ни на строку: правило живёт только в расширении. Отключив расширение, вы увидите, как правило исчезает, не трогая основную конфигурацию.
