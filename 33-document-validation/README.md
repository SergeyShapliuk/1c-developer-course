# Занятие 33. Проверка данных документа и модуль объекта

## Цель

Понять, почему проверку данных нельзя оставлять на форме, и освоить модуль объекта документа как место для правил самого документа. Научиться отменять запись через параметр `Отказ` и сообщать пользователю, в какой строке ошибка.

## Результат занятия

У реквизитов документа `ЗаявкаНаМатериалы` будет включена проверка заполнения, а в его модуле объекта появятся обработчики `ОбработкаПроверкиЗаполнения` и `ПередЗаписью`. Заявку с нулевым количеством или без материалов записать станет невозможно, а сообщение об ошибке будет указывать на конкретную строку табличной части из занятия 31.

1. Прочитайте [теорию](theory.md) — около 25 минут.

## Ключевые термины

Модуль объекта, `ЭтотОбъект`, свойство **Проверка заполнения**, `ОбработкаПроверкиЗаполнения`, `ПроверяемыеРеквизиты`, `ПередЗаписью`, параметр `Отказ`, `Новый СообщениеПользователю`, `УстановитьДанные`, `НомерСтроки`.
