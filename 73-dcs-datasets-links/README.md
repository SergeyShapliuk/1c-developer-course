# Занятие 73. Несколько наборов данных и связи наборов

## Цель

Научиться показывать в одном отчёте данные из двух разных источников — остатки из регистра накопления и цены из регистра сведений — не склеивая их в одном запросе. Понять, что связь наборов данных работает как левое соединение, почему её направление важно и почему приёмник связи не должен размножать строки источника.

## Результат занятия

В схеме отчёта `ОстаткиНаСкладах` станет два набора данных: `Остатки` и `Цены` — срез последних регистра `ЦеныМатериалов`, связанные по материалу. В отчёте рядом с остатком появится цена материала на ту же дату, что и остаток. Новый материал «Щебень гранитный» без цены останется в отчёте с пустой ценой, а не исчезнет.
