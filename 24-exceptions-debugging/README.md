# Занятие 24. Исключения, сообщения и основы отладки

## Цель

Научиться перехватывать ошибки времени выполнения, сообщать пользователю о проблеме понятным способом и останавливать программу в отладчике, чтобы увидеть значения переменных своими глазами.

## Результат занятия

Вы увидите, как выглядит падение кода, и обернёте его в `Попытка … Исключение … КонецПопытки`. Вы напишете собственное исключение через `ВызватьИсключение` и выведете сообщение, привязанное к полю формы. Вы поставите точку останова в процедуре `ПересчитатьСумму` с занятия 23, пройдёте код по шагам и прочитаете значения переменных в окне **Табло** и цепочку вызовов в окне **Стек вызовов**.

## Маршрут

1. Прочитайте [теорию](theory.md) — около 25 минут.
2. Выполните [практику](practice.md) — около 60 минут.
3. Ответьте на контрольные вопросы в конце практики, не подглядывая в теорию.

## Ключевые термины

Исключение, `Попытка … Исключение … КонецПопытки`, `ОписаниеОшибки()`, `ИнформацияОбОшибке()`, `ВызватьИсключение`, `СообщениеПользователю`, точка останова, отладчик, шаг с заходом, шаг без захода, **Табло**, **Стек вызовов**.
