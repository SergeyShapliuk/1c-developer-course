# День 6. Склады и объекты строительства

## Цель

Создать справочники, которые свяжут складскую логистику с работами строительной компании.

## Результат дня

В конфигурации появятся справочники «Склады» и «ОбъектыСтроительства», а также раздел «Логистика». Вы введёте по одному тестовому складу и объекту.

## Маршрут

1. Прочитайте [теорию](theory.md).
2. Выполните [практику](practice.md).
3. Ответьте на контрольные вопросы в конце практики.
