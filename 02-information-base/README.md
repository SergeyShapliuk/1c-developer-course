# Занятие 2. Информационная база и режимы запуска

## Цель

Создать собственную учебную информационную базу и научиться запускать её в двух режимах — Конфигуратор и «1С:Предприятие», понимая, зачем нужен каждый.

## Результат занятия

В окне запуска появится база `УправлениеСтроительнойКомпанией`. Вы откроете её в обоих режимах, увидите разницу между ними и сделаете первую резервную копию в файл `.dt`. Структуру конфигурации пока не меняем — этим займёмся на занятии 3.

## Маршрут

1. Прочитайте [теорию](theory.md) — около 25 минут.
2. Выполните [практику](practice.md) — около 45 минут.
3. Ответьте на контрольные вопросы в конце практики, не подглядывая в теорию.

## Ключевые термины

Информационная база, файловый вариант, клиент-серверный вариант, СУБД, Конфигуратор, режим «1С:Предприятие», тонкий клиент, толстый клиент, выгрузка информационной базы, файл `.dt`.
