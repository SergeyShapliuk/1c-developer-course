# Занятие 116. Пробный экзамен

## Цель

Пройти экзамен в условиях, близких к настоящим: четырнадцать новых вопросов по всем темам платформы за двадцать минут, без курса и без пауз. Разобрать ошибки не по темам, а по причинам — незнание, невнимательность, ловушка контекста — и по результату решить, пора ли записываться на настоящий экзамен.

## Результат занятия

В конспекте появятся результат пробного экзамена с временем, разбор каждой ошибки по причине, обновлённые карточки и решение о готовности: записаться на экзамен или повторить конкретные темы и пройти пробный экзамен снова по официальным материалам фирмы «1С».

## Маршрут

1. Прочитайте [теорию](theory.md) — около 15 минут. Курс после этого не открывайте до конца пробного экзамена.
2. Выполните [практику](practice.md) — около 50 минут.
3. Ответьте на контрольные вопросы в конце практики, не подглядывая в теорию.

## Ключевые термины

Пробный экзамен, условия экзамена, порог прохождения, запас, ошибка незнания, ошибка невнимательности, ошибка контекста, решение о готовности, официальные материалы для подготовки, день экзамена.
