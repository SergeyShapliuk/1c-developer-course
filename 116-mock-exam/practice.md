# Практика. Четырнадцать вопросов за двадцать минут

## Перед началом

Нужны только конспект с файлами `exam/cards.md` и `exam/plan.md`, таймер и двадцать минут тишины. Создайте в конспекте файл `exam/mock.md` и запишите в него дату и время начала. Закройте курс, конфигуратор и браузер.

Ответы записывайте в `exam/mock.md` строкой «номер — буква». Если вопрос вызывает сомнение, отметьте его звёздочкой и вернитесь к нему, когда пройдёте все.

## Шаг 1. Пройдите пробный экзамен

Засеките 20 минут.

**1.** Чем тонкий клиент отличается от толстого клиента управляемого приложения?

- А) Тонкий клиент работает только через интернет
- Б) Тонкий клиент не умеет показывать формы
- В) Тонкий клиент не работает с базой данных напрямую: код, обращающийся к данным, выполняется на сервере
- Г) Ничем, это два названия одного клиента

**2.** Элемент справочника «Склады» пометили на удаление. Что происходит с документами, которые на него ссылаются?

- А) Документы не меняются: элемент удалится только при удалении помеченных объектов, которое проверит, нет ли на него ссылок
- Б) Ссылки на склад в документах очищаются
- В) Документы тоже помечаются на удаление
- Г) Проведение документов отменяется

**3.** Что содержит переменная цикла в конструкции `Для Каждого СтрокаТаблицы Из ТаблицаМатериалов Цикл`, где `ТаблицаМатериалов` — таблица значений?

- А) Номер строки
- Б) Значение первой колонки строки
- В) Копию всей таблицы
- Г) Строку таблицы значений, к колонкам которой обращаются через точку

**4.** Снабженец вводит цены вручную в форме списка регистра сведений. Каким должен быть регистр по отношению к регистратору?

- А) Подчинённым регистратору
- Б) Независимым
- В) Любым: режим записи на ручной ввод не влияет
- Г) Регистр сведений вручную вводить нельзя

**5.** Какое выражение запроса вернёт «Срочно» для срочных заявок и «Обычно» для остальных?

- А) `ВЫБОР КОГДА Заявка.Приоритет = ЗНАЧЕНИЕ(Перечисление.ПриоритетыЗаявок.Срочный) ТОГДА "Срочно" ИНАЧЕ "Обычно" КОНЕЦ`
- Б) `ЕСЛИ Заявка.Приоритет = ЗНАЧЕНИЕ(Перечисление.ПриоритетыЗаявок.Срочный) ТОГДА "Срочно" ИНАЧЕ "Обычно" КОНЕЦЕСЛИ`
- В) `ЕСТЬNULL(Заявка.Приоритет, "Обычно")`
- Г) `?(Заявка.Приоритет = ЗНАЧЕНИЕ(Перечисление.ПриоритетыЗаявок.Срочный), "Срочно", "Обычно")`

**6.** Зачем вместо вложенного запроса часто используют временную таблицу?

- А) Временная таблица хранится в базе до конца дня
- Б) Вложенные запросы запрещено соединять с виртуальными таблицами
- В) Её результат можно использовать в нескольких запросах пакета, а текст читается по шагам
- Г) Временная таблица всегда быстрее любого вложенного запроса

**7.** Нужны обороты материалов по месяцам за год. Что указать в таблице оборотов регистра?

- А) Условие `ГДЕ Период = МЕСЯЦ`
- Б) `СГРУППИРОВАТЬ ПО Месяц` без параметров таблицы
- В) Ничего: таблица оборотов всегда помесячная
- Г) Начало и конец периода и периодичность «Месяц» в параметрах таблицы

**8.** В отчёте после связи двух наборов данных суммы ресурса удвоились. Какая причина наиболее вероятна?

- А) Ресурс объявлен с выражением `Сумма`
- Б) Для одной строки набора-источника в наборе-приёмнике нашлось несколько строк
- В) В структуре отчёта две группировки
- Г) Отчёт открыт из формы документа

**9.** Отрицательный остаток в отчёте нужно показывать красным. Где это задать?

- А) Условным оформлением отчёта
- Б) Вычисляемым полем схемы
- В) В тексте запроса набора данных
- Г) Ресурсом с выражением `Минимум`

**10.** Поле «Ответственный» в форме должно предлагать только сотрудников склада, выбранного в поле «Склад» этой же формы. Что для этого использовать?

- А) Параметр выбора с фиксированным значением склада
- Б) Условное оформление формы
- В) Проверку в `ПередЗаписью`
- Г) Связи параметров выбора

**11.** У роли пользователя нет права **Просмотр** на отчёт. Что он увидит?

- А) Отчёт в разделе, но пустой
- Б) Ошибку при входе в программу
- В) Отчёта нет в командном интерфейсе
- Г) Отчёт без возможности поменять настройки

**12.** Расширение с правилом о срочной заявке отключили. Что произойдёт?

- А) Правило останется: при активации оно было скопировано в основную конфигурацию
- Б) Правило перестанет действовать, основная конфигурация не изменится
- В) Основная конфигурация вернётся к версии до создания расширения
- Г) Пользователи не смогут записывать заявки

**13.** Зачем `ОбработкаПроведения` получает параметр `РежимПроведения`?

- А) Чтобы выбрать регистр для движений
- Б) Чтобы отменить проведение
- В) Чтобы запретить запись документа
- Г) Чтобы узнать, проводится документ оперативно или неоперативно, и, например, контролировать остатки только в оперативном режиме

**14.** Нужно хранить «Основной склад компании» — одно значение на всю базу, которое меняет администратор. Что подходит?

- А) Константа
- Б) Перечисление
- В) Справочник с одним элементом
- Г) Параметр сеанса

Остановите таймер и запишите время. Если остались вопросы без ответа, ответьте на них сейчас, но отметьте, что ответ дан после двадцати минут: на экзамене он бы не засчитался.

**Проверка:** на все четырнадцать вопросов есть ответ, время записано, ответы после двадцати минут отмечены.

## Шаг 3. Разберите ошибки по причинам

Для каждой ошибки и для каждого ответа со звёздочкой, даже правильного, заполните в `exam/mock.md` строку:

| Вопрос | Ваш ответ | Причина | Что сделать |
| --- | --- | --- | --- |
| | | незнание, невнимательность или ловушка контекста | занятие, эксперимент, привычка |

Чтобы отличить незнание от невнимательности, перечитайте вопрос сейчас, спокойно. Если правильный ответ очевиден — это невнимательность. Если нет — незнание. Если ваш ответ верен где-то ещё в платформе — ловушка контекста; назовите этот контекст.

Посчитайте, сколько ошибок каждой причины. Заведите карточки на ошибки незнания и ловушки контекста.

**Проверка:** у каждой ошибки и каждого ответа со звёздочкой названа причина; карточки заведены.

## Шаг 4. Примите решение о готовности

1. Найдите свой результат в таблице «Решение о готовности» теории и запишите решение в `exam/plan.md`.
2. Если ошибок невнимательности больше, чем ошибок незнания, запишите привычку, которую будете тренировать: например, «перед ответом перечитываю вопрос и ищу отрицание».
3. Найдите на сайте фирмы «1С» актуальные условия экзамена 1С:Профессионал по платформе и официальные материалы для подготовки. Запишите в план: формат, число вопросов, время, порог, место и стоимость — и сравните с тем, что сказано в курсе.
4. Запланируйте прохождение официальных материалов и, если решение позволяет, дату записи на экзамен.

Закоммитьте конспект.

**Проверка:** решение о готовности записано и опирается на таблицу теории; актуальные условия экзамена сверены с курсом; следующий шаг запланирован с датой.

## Проверка результата

Занятие пройдено, если выполняются пять условий:

1. Пробный экзамен пройден за одну попытку, в двадцать минут, без курса.
2. Результат посчитан отдельно для ответов в пределах времени.
3. Каждая ошибка разобрана по причине, карточки заведены.
4. Решение о готовности принято по таблице теории.
5. Актуальные условия экзамена найдены у фирмы «1С», официальные материалы для подготовки запланированы.
