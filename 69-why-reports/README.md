# Занятие 69. Зачем нужны отчёты

## Цель

Понять, почему ответ, который разработчик получает в учебной консоли, ещё не годится для пользователя, и какой объект метаданных отдаёт этот ответ кладовщику. Познакомиться с объектом **Отчёт** и его основной схемой компоновки данных и сформировать первый отчёт учебного проекта, не написав ни одной строки кода в модуле.

## Результат занятия

В конфигурации появится отчёт `ОстаткиНаСкладах` с основной схемой компоновки данных. Его набор данных — запрос к таблице остатков регистра `ОстаткиМатериалов` из занятия 65. Отчёт входит в подсистему **Логистика**, открывается из раздела, формируется кнопкой **Сформировать** и показывает те же остатки «Центрального склада», что процедура `ВывестиОстаткиСклада` в учебной консоли.

## Маршрут

1. Прочитайте [теорию](theory.md) — около 25 минут.
2. Выполните [практику](practice.md) — около 50 минут.
3. Ответьте на контрольные вопросы в конце практики, не подглядывая в теорию.
