# Практика. Находим и читаем элементы справочников

## Перед началом

Запустите конфигуратор учебной конфигурации **«Управление строительной компанией с логистикой»**.

В дереве конфигурации откройте обработку `УчебнаяКонсоль` (синоним «Учебная консоль»), затем её форму, а в редакторе формы — вкладку **Модуль**. Работаем в процедуре `Выполнить` и в серверных процедурах, которые добавим рядом.

После каждой правки кода:

1. Сохраните конфигурацию — `Ctrl+S`.
2. Запустите приложение — `F5`.
3. В разделе **Разработка** откройте «Учебную консоль».
4. Нажмите кнопку **Выполнить** и прочитайте сообщения.

Перед началом убедитесь, что в базе есть тестовые элементы, заведённые в занятиях 6 и 8: товар «Цемент М500», сотрудник «Иванов Иван», склад «Центральный склад» с ответственным «Иванов Иван». Если их нет, заведите в режиме «1С:Предприятие» вручную.

Весь код этого занятия — серверный. Менеджеры справочников в клиентском коде недоступны.

## Шаг 1. Найти товар по наименованию

```bsl
&НаКлиенте
Процедура Выполнить(Команда)
	
	НайтиЦемент();
	
КонецПроцедуры

&НаСервере
Процедура НайтиЦемент()
	
	// У менеджера справочника просим найти элемент.
	// Результат — ссылка типа СправочникСсылка.Товары.
	Товар = Справочники.Товары.НайтиПоНаименованию("Цемент М500");
	
	Если Товар.ПустаяСсылка() Тогда
		Сообщить("Товар «Цемент М500» в справочнике не найден");
		Возврат;
	КонецЕсли;
	
	// Реквизиты читаем по ссылке через точку
	Сообщить("Наименование: " + Товар.Наименование);
	Сообщить("Артикул: " + Товар.Артикул);
	Сообщить("Цена: " + Строка(Товар.Цена));
	Сообщить("Единица измерения: " + Товар.ЕдиницаИзмерения);
	
КонецПроцедуры
```

Обратите внимание на `Возврат;` без значения: в процедуре он просто досрочно выходит из неё. Так проверку делают до основной работы, и дальше можно не заботиться о пустой ссылке.

Сохраните, запустите, нажмите **Выполнить**.

**Проверка:** выведены наименование, артикул, цена и единица измерения цемента.

## Шаг 2. Что будет, если элемента нет

Теперь поищем то, чего в справочнике заведомо нет. Добавьте вторую серверную процедуру и вызовите её из `Выполнить`:

```bsl
&НаКлиенте
Процедура Выполнить(Команда)
	
	НайтиЦемент();
	ПроверитьНенайденный();
	
КонецПроцедуры

&НаСервере
Процедура ПроверитьНенайденный()
	
	Товар = Справочники.Товары.НайтиПоНаименованию("Гипсокартон");
	
	// Поиск не выдал ошибку и не вернул Неопределено.
	// Он вернул пустую ссылку — значение правильного типа.
	Сообщить("Тип результата: " + Строка(ТипЗнач(Товар)));
	
	Если НЕ ЗначениеЗаполнено(Товар) Тогда
		Сообщить("Гипсокартон в справочнике не заведён — это не ошибка");
	Иначе
		Сообщить("Нашли: " + Товар.Наименование);
	КонецЕсли;
	
КонецПроцедуры
```

Сохраните, запустите, нажмите **Выполнить**. Тип результата выведется как `СправочникСсылка.Товары` — такой же, как при успешном поиске. Разница только в том, что ссылка пустая.

**Проверка:** код не упал, выведен тип ссылки и понятное сообщение о ненайденном элементе.

## Шаг 3. Разыменование: ответственный по складу

Добавьте третью серверную процедуру и вызов из `Выполнить`.

```bsl
&НаСервере
Процедура ПрочитатьСклад()
	
	Склад = Справочники.Склады.НайтиПоНаименованию("Центральный склад");
	
	Если Склад.ПустаяСсылка() Тогда
		Сообщить("Склад не найден");
		Возврат;
	КонецЕсли;
	
	Сообщить("Склад: " + Склад.Наименование);
	Сообщить("Адрес: " + Склад.Адрес);
	
	// Две точки — два обращения к базе:
	// сначала читаем реквизит Ответственный (это ссылка),
	// затем по этой ссылке читаем наименование сотрудника.
	Сообщить("Ответственный: " + Склад.Ответственный.Наименование);
	Сообщить("Должность: " + Склад.Ответственный.Должность);
	
КонецПроцедуры
```

Сохраните, запустите, нажмите **Выполнить**. Выведется «Иванов Иван» и его должность, хотя в справочнике `Склады` ни имени, ни должности нет: там лежит только ссылка.

Разыменование очень удобно, и именно поэтому им легко злоупотребить. В последних двух строках к базе обратились четыре раза. В цикле по сотне складов это было бы четыреста обращений.

**Проверка:** выведены наименование склада, адрес, наименование и должность ответственного.

## Шаг 4. Перебрать все товары

Теперь пройдём по всему справочнику. Добавьте процедуру и вызов из `Выполнить`.

```bsl
&НаСервере
Процедура ВывестиВсеТовары()
	
	// Выбрать() даёт выборку — курсор по элементам справочника.
	Выборка = Справочники.Товары.Выбрать();
	
	Номер = 0;
	// Следующий() двигает курсор и возвращает Ложь,
	// когда элементы закончились. Сколько их — заранее неизвестно,
	// поэтому здесь нужен именно цикл Пока (занятие 14).
	Пока Выборка.Следующий() Цикл
		Номер = Номер + 1;
		Сообщить(Строка(Номер) + ". " + Выборка.Наименование
			+ " — " + Строка(Выборка.Цена));
	КонецЦикла;
	
	Сообщить("Всего товаров: " + Строка(Номер));
	
КонецПроцедуры
```

Сохраните, запустите, нажмите **Выполнить**. Выведутся все товары, которые есть в справочнике, с нумерацией.

**Проверка:** выведен нумерованный перечень всех товаров и их общее количество.

## Шаг 5. Ссылка против объекта

Сравним два типа напрямую.

```bsl
&НаСервере
Процедура СравнитьСсылкуИОбъект()
	
	Товар = Справочники.Товары.НайтиПоНаименованию("Цемент М500");
	
	Если Товар.ПустаяСсылка() Тогда
		Сообщить("Товар не найден");
		Возврат;
	КонецЕсли;
	
	// ПолучитьОбъект() загружает данные элемента в память
	Объект = Товар.ПолучитьОбъект();
	
	Сообщить("Тип ссылки: " + Строка(ТипЗнач(Товар)));
	Сообщить("Тип объекта: " + Строка(ТипЗнач(Объект)));
	
	// Читать реквизиты можно и там, и там
	Сообщить("Цена по ссылке: " + Строка(Товар.Цена));
	Сообщить("Цена по объекту: " + Строка(Объект.Цена));
	
КонецПроцедуры
```

Сохраните, запустите, нажмите **Выполнить**. Первый тип — `СправочникСсылка.Товары`, второй — `СправочникОбъект.Товары`. Это разные типы, хотя речь об одном и том же элементе.

Читать реквизиты можно и через ссылку, и через объект. Разница появится на занятии 20: изменять и записывать можно только объект.

**Проверка:** выведены два разных типа и одинаковая цена, прочитанная двумя способами.

## Шаг 6. Собрать массив структур и вернуть на клиент

Соберём на сервере данные в коллекции занятия 17 и выведем их в клиентском коде.

```bsl
&НаКлиенте
Процедура Выполнить(Команда)
	
	СписокТоваров = ПолучитьСписокТоваров();
	
	Для Каждого Позиция Из СписокТоваров Цикл
		Сообщить(Позиция.Наименование + ": " + Строка(Позиция.Цена));
	КонецЦикла;
	
	Сообщить("Получено позиций: " + Строка(СписокТоваров.Количество()));
	
КонецПроцедуры

&НаСервере
Функция ПолучитьСписокТоваров()
	
	Результат = Новый Массив;
	Выборка = Справочники.Товары.Выбрать();
	
	Пока Выборка.Следующий() Цикл
		Позиция = Новый Структура;
		Позиция.Вставить("Наименование", Выборка.Наименование);
		Позиция.Вставить("Цена", Выборка.Цена);
		Результат.Добавить(Позиция);
	КонецЦикла;
	
	Возврат Результат;
	
КонецФункции
```

Здесь сошлось всё, что мы разобрали. Сервер читает базу, складывает нужное в массив структур и возвращает его на клиент; клиент перебирает массив и выводит сообщения. Массив и структура для этого годятся, потому что доступны и на клиенте, и на сервере — в отличие от таблицы значений занятия 18.

**Проверка:** в клиентском коде выведены наименования и цены всех товаров и их количество.

## Проверка результата

Занятие пройдено, если выполняются пять условий:

1. «Цемент М500» найден по наименованию, его реквизиты выведены.
2. Поиск «Гипсокартона» не привёл к ошибке, вы увидели пустую ссылку и обработали её.
3. Наименование ответственного получено разыменованием, и вы можете сказать, сколько было обращений к базе.
4. Все товары выведены выборкой через `Пока Выборка.Следующий() Цикл`.
5. Серверная функция вернула массив структур, и клиентский код его перебрал.
