# Занятие 35. Состояния документа

## Цель

Понять, какие состояния заявки платформа отслеживает сама, а какие приходится хранить реквизитом, и научиться задавать состояние перечислением так, чтобы пользователь не мог поставить его в обход правил.

## Результат занятия

В конфигурации появится перечисление `СостоянияЗаявок` и реквизит `Состояние` документа `ЗаявкаНаМатериалы`. Новая заявка будет получать состояние «Новая» сама, поле состояния на форме станет недоступным для прямого ввода, а менять его будет команда `Согласовать`, которая проверяет условия перехода. Форму документа вы собирали в занятии 30, команду формы — в занятии 34.

## Маршрут

1. Прочитайте [теорию](theory.md) — около 25 минут.
2. Выполните [практику](practice.md) — около 60 минут.
3. Ответьте на контрольные вопросы в конце практики, не подглядывая в теорию.

## Ключевые термины

Состояние документа, жизненный цикл, перечисление, `СостоянияЗаявок`, `ПеречислениеСсылка`, `Перечисления.<Имя>.<Значение>`, `ЭтоНовый()`, `ПометкаУдаления`, выводимое состояние, `ПередЗаписью`, свойство **ТолькоПросмотр**.
