# Практика. Первый запуск учебной базы

## Перед началом

Нужны установленная платформа 1С:Предприятие 8.3 и учебная файловая информационная база. Если базы ещё нет, в окне запуска нажмите «Добавить», выберите создание новой ИБ, затем вариант «Создание информационной базы без конфигурации для разработки» и файловое расположение. Назовите её `УправлениеСтроительнойКомпанией`.

Не беспокойтесь, если названия кнопок или расположение панелей немного отличаются: они зависят от версии платформы. Ищите команды с теми же словами в главном меню или в контекстном меню, которое открывается правой кнопкой мыши.

## Шаг 1. Откройте информационную базу

1. Запустите ярлык **1С:Предприятие**.
2. В списке выберите созданную учебную базу.
3. Убедитесь, что в нижней части окна, в поле пути, указано расположение вашей ИБ. Информационная база — это папка с учебными данными, а не ярлык программы.
4. Пока не запускайте её: сначала откроем среду разработки.

**Проверка:** вы видите название учебной базы в списке информационных баз.

## Шаг 2. Откройте Конфигуратор

1. Выделите учебную базу в списке.
2. Нажмите кнопку **Конфигуратор**.
3. Дождитесь открытия окна разработки. Первый запуск может занять несколько минут. Если система запросит учётные данные, используйте данные, заданные при создании базы; если пароль не задавался, оставьте поля пустыми и нажмите **ОК**.
4. Найдите заголовок окна: в нём обычно отображаются название базы и слово «Конфигуратор».

**Проверка:** открыто отдельное окно Конфигуратора, а не пользовательский интерфейс приложения.

## Шаг 3. Найдите дерево конфигурации

1. В главном меню выберите **Конфигурация → Открыть конфигурацию**. В некоторых вариантах интерфейса дерево появляется сразу.
2. В левой части окна найдите панель с корневым узлом конфигурации. Корневой узел обычно имеет значок жёлтого кубика и название вашей конфигурации.
3. Раскройте корневой узел и посмотрите на группы «Справочники», «Документы», «Отчёты».
4. Ничего не создавайте и не изменяйте: сегодня знакомимся с навигацией.

**Проверка:** вы можете показать, где в дереве находятся справочники и документы.

## Шаг 4. Откройте режим «1С:Предприятие»

1. Не закрывая Конфигуратор, выберите **Отладка → Начать отладку** или нажмите `F5`. Клавиша `F5` запускает проверку приложения для разработчика.
2. Если появится вопрос об обновлении конфигурации базы данных, подтвердите обновление: для учебной базы это безопасный штатный шаг.
3. Альтернативный способ: закройте Конфигуратор, в стартовом окне выделите ИБ и нажмите **1С:Предприятие**.
4. Рассмотрите открывшееся пользовательское приложение. В новой пустой базе оно почти не содержит разделов — это нормально.

**Проверка:** вы видите пользовательский режим, в котором нет дерева метаданных и средств редактирования конфигурации.

## Шаг 5. Сравните два режима

Вернитесь в Конфигуратор и заполните таблицу своими словами.

| Вопрос | Ваш ответ |
| --- | --- |
| Где создают справочник «Контрагенты»? | |
| Где пользователь добавляет нового контрагента? | |
| Где редактируют модуль объекта? | |
| Где формируют отчёт по введённым данным? | |

Верные направления: создание объектов и код — Конфигуратор; ввод данных и использование отчётов — «1С:Предприятие».

## Контрольные вопросы

Не подглядывая в теорию, устно или в заметках ответьте:

1. Чем платформа отличается от конфигурации?
2. Что хранит информационная база?
3. Почему конкретный контрагент — не объект метаданных?
4. В каком режиме вы будете проверять форму, созданную разработчиком?

Сверьте ответы с [теорией](theory.md). Если на каждый вопрос можно ответить в одном-двух предложениях, день пройден.
