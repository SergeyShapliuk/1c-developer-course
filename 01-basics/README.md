# День 1. Знакомство с 1С:Предприятие 8.3

## Цель

Разобраться, из каких частей состоит система 1С, и научиться уверенно переключаться между режимами разработки и работы пользователя.

## Результат дня

Вы откроете учебную информационную базу в двух режимах, найдёте дерево конфигурации и сможете объяснить назначение платформы, конфигурации и базы данных.

## Маршрут

1. Прочитайте [теорию](theory.md) — около 25 минут.
2. Выполните [практику](practice.md) — около 45 минут.
3. Ответьте на вопросы контрольного задания без подсказок.

## Ключевые термины

Платформа, конфигурация, информационная база, Конфигуратор, режим «1С:Предприятие», дерево конфигурации, метаданные.
