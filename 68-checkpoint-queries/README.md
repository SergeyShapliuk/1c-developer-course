# Занятие 68. Контрольная точка: запросы и контроль остатков

## Цель

Это **контрольная точка** этапа 5 и четвёртая в курсе. Нового материала здесь нет: справку для снабженца, заполнение цен и контроль остатков нужно собрать самостоятельно из того, что изучено в занятиях 53–67, а затем принять свою работу по чек-листу, сверяя ответы запросов с ручным подсчётом.

## Результат занятия

Серверный общий модуль `СправкиСнабженцаСервер` с функцией, которая одним пакетным запросом возвращает по объекту строительства: заказано, поступило, осталось получить, выдано на объект и сколько материала есть на складах. Работающая команда **Заполнить цены** в форме заявки и контроль остатков в `ОбработкаПроведения` передачи. Плюс заполненный чек-лист с фактическими результатами, включая отказ проведения, две строки одного материала и проведение задним числом.

## Маршрут

1. Прочитайте [теорию](theory.md) — около 20 минут. Она не про новые конструкции, а про то, как проверяют запрос.
2. Выполните [практику](practice.md): сначала решите задачу сами, потом пройдите чек-лист.
3. **Раздел «Разбор и эталонный вариант» открывайте только после своей попытки.** Готовый пакет запросов, прочитанный заранее, не научит его составлять: контрольная точка проверяет умение, а не память.

## Ключевые термины

Контрольная точка, приёмка запроса, ручной подсчёт, сверка с регистром, пакетный запрос, временная таблица, предварительная группировка, левое соединение, `ЕСТЬNULL`, виртуальная таблица, срез последних, таблица остатков, контроль остатков, блокировка, оперативное проведение.
