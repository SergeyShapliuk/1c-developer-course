# Занятие 65. Таблица остатков

## Цель

Получить остаток материала на складе из кода — запросом к виртуальной таблице остатков регистра `ОстаткиМатериалов`. Научиться спрашивать текущий остаток и остаток на момент, понять, почему граница периода по умолчанию не включает сам момент, и вынести получение остатка в серверный общий модуль.

## Результат занятия

В обработке `УчебнаяКонсоль` появятся процедуры, которые выводят текущие остатки всех материалов «Центрального склада», остаток цемента на момент передачи — без неё и с ней — и список всех материалов с остатком, включая нулевой. В конфигурации появится общий модуль `ОстаткиМатериаловСервер` с функцией `ОстатокМатериала`. Числа совпадут с теми, что на занятиях 51 и 60 вы считали руками.

## Маршрут

1. Прочитайте [теорию](theory.md) — около 30 минут.
2. Выполните [практику](practice.md) — около 60 минут.
3. Ответьте на контрольные вопросы в конце практики, не подглядывая в теорию.

## Ключевые термины

Виртуальная таблица остатков, `Остатки`, поле `КоличествоОстаток`, текущий остаток, остаток на момент, граница периода, `Граница`, `ВидГраницы.Включая`, условие на измерения в параметрах, нулевой остаток, общий модуль `ОстаткиМатериаловСервер`.
