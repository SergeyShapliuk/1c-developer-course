# Занятие 67. Контроль остатков при проведении

## Цель

Закрыть главный долг этапа 4: документ `ПередачаМатериалов` не должен проводиться, если материала на складе не хватает. Понять, почему остаток проверяют **после** записи движений, зачем при этом нужна блокировка и почему проверка выполняется только при оперативном проведении.

## Результат занятия

В `ОбработкаПроведения` модуля объекта `ПередачаМатериалов` появится контроль остатков по современной методике: движения записываются заранее под блокировкой, затем один запрос к таблице остатков находит материалы, ушедшие в минус, и проведение отменяется с сообщением, сколько не хватает. Передача `500` мешков при остатке `80`, которая на занятии 52 проводилась, теперь отклоняется, и в регистре не остаётся ни одной её записи.
