# Практика. Первый код в учебной консоли

## Перед началом

Весь код занятия пишем в одном месте. В дереве конфигурации откройте **Обработки → УчебнаяКонсоль**, затем её форму и перейдите на вкладку **Модуль**. Там уже есть обработчик команды, созданный на занятии 9:

```bsl
&НаКлиенте
Процедура Выполнить(Команда)

КонецПроцедуры
```

Все шаги выполняются **внутри** этой процедуры — между строкой `Процедура Выполнить(Команда)` и строкой `КонецПроцедуры`.

Порядок запуска после каждой правки один и тот же:

1. `Ctrl+S` — сохранить конфигурацию.
2. `F5` — начать отладку; на предложение обновить конфигурацию базы данных ответьте согласием.
3. В открывшемся приложении перейдите в раздел **Разработка** и откройте **Учебную консоль**.
4. Нажмите кнопку **Выполнить**.

Сообщения появятся в нижней части окна приложения. Дальше этот порядок будем называть коротко: «сохраните, запустите и нажмите **Выполнить**».

## Шаг 1. Первое сообщение

Напишите внутри процедуры одну строку:

```bsl
&НаКлиенте
Процедура Выполнить(Команда)

	Сообщить("Привет, 1С!");

КонецПроцедуры
```

Сохраните, запустите и нажмите **Выполнить**.

**Проверка:** внизу окна приложения появилась надпись «Привет, 1С!».

Не закрывайте приложение после каждого шага: достаточно вернуться в конфигуратор, поправить код и нажать `F5` снова — платформа предложит перезапустить сеанс отладки.

## Шаг 2. Арифметика

Посчитаем стоимость партии цемента: 20 мешков по 12.50 за мешок. Замените текст процедуры на такой:

```bsl
Количество = 20;
Цена = 12.5;
Сумма = Количество * Цена;
Сообщить("Сумма: " + Строка(Сумма));
```

Обратите внимание на две вещи. Первая: в коде цена записана как `12.5`, с точкой, а не с запятой. Вторая: `Сумма` — число, поэтому напрямую в `Сообщить()` его отдать нельзя, и мы обернули его в `Строка()`.

**Проверка:** выведено «Сумма: 250».

## Шаг 3. Конкатенация

Соберём описание партии из отдельных частей. Добавьте в конец процедуры:

```bsl
Материал = "Цемент М500";
Текст = "Материал: " + Материал + ", количество: " + Строка(Количество);
Сообщить(Текст);
```

Здесь `+` работает уже не как сложение, а как склеивание строк. Заметьте пробел и запятую внутри кавычек: платформа не добавляет разделители сама, всё, что нужно увидеть, вы пишете сами.

**Проверка:** выведено «Материал: Цемент М500, количество: 20».

## Шаг 4. Даты

Добавьте в конец процедуры:

```bsl
ДатаПоставки = '20260101';
Сообщить("Дата поставки: " + Строка(ДатаПоставки));
Сообщить("Сейчас: " + Строка(ТекущаяДата()));
```

`'20260101'` — это 1 января 2026 года: литерал даты записывается в одинарных кавычках в порядке год, месяц, день, без разделителей. `ТекущаяДата()` — функция, которая возвращает дату и время компьютера в момент выполнения.

**Проверка:** первое сообщение показывает 1 января 2026 года, второе — сегодняшнюю дату и текущее время.

## Шаг 5. Комментарии

Объясните расчёт из шага 2. Над строкой с ценой добавьте комментарий:

```bsl
// Цена из прайса поставщика «СтройСнаб», действует до конца января
Цена = 12.5;
```

Сохраните, запустите и нажмите **Выполнить**. Результат не изменился: комментарий — текст для человека, платформа его пропускает.

**Проверка:** код работает как раньше, а из комментария понятно, откуда взялось число 12.5.

## Шаг 6. Сломайте и почините

Теперь ошибку нужно увидеть специально.

1. Уберите точку с запятой в конце строки `Цена = 12.5;` — должно остаться `Цена = 12.5`.
2. Не запуская приложение, выполните **Конфигурация → Проверка → Синтаксический контроль**.
3. Внизу конфигуратора появится сообщение об ошибке с именем модуля и номером строки. Прочитайте его целиком и щёлкните по нему дважды — курсор встанет в проблемное место.
4. Обратите внимание: платформа часто указывает на **следующую** строку, а не на ту, где забыта `;`. Поэтому при такой ошибке всегда смотрите и строку выше.
5. Верните точку с запятой и выполните синтаксический контроль снова.

**Проверка:** после возврата `;` контроль сообщает, что ошибок нет.

## Шаг 7. Синтакс-помощник

1. Поставьте курсор на слово `Сообщить` в вашем коде.
2. Нажмите `Ctrl+Alt+F`.
3. Откроется синтакс-помощник с описанием: какие у функции параметры, что она делает, пример использования.
4. Повторите то же для `Строка` и `ТекущаяДата`.

**Проверка:** вы открыли описание трёх функций и видите, какие параметры они принимают.

## Проверка результата

Занятие пройдено, если выполняются четыре условия:

1. Нажатие кнопки **Выполнить** выводит не меньше пяти сообщений: приветствие, сумму, описание партии и две даты.
2. Числа выводятся через `Строка()`, а не передаются в `Сообщить()` напрямую.
3. Вы вызвали ошибку из-за пропущенной `;`, нашли её по сообщению синтаксического контроля и исправили.
4. Вы умеете открыть описание конструкции по `Ctrl+Alt+F`.
