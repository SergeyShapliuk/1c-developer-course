# Занятие 11. BSL: синтаксис, выражения и сообщения

## Цель

Написать первые строки на встроенном языке 1С: научиться записывать операторы, литералы и выражения, выводить результат на экран и находить ошибки записи до запуска приложения.

## Результат занятия

Обработка `УчебнаяКонсоль` при нажатии кнопки **Выполнить** выводит несколько сообщений: текст, результат арифметического расчёта, собранную из частей строку и дату. Вы умеете читать сообщение об ошибке синтаксического контроля и открывать описание любой конструкции в синтакс-помощнике.

## Маршрут

1. Прочитайте [теорию](theory.md) — около 20 минут.
2. Выполните [практику](practice.md) — около 50 минут.
3. Ответьте на контрольные вопросы в конце практики, не подглядывая в теорию.

## Ключевые термины

Встроенный язык 1С, BSL, модуль, оператор, точка с запятой, комментарий, литерал, строка, число, дата, булево, конкатенация, `Сообщить()`, `Строка()`, синтакс-помощник, синтаксический контроль.
