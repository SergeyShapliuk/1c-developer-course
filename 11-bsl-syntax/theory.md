# Теория. Синтаксис встроенного языка

## Встроенный язык 1С

Код в 1С пишут на **встроенном языке 1С**; в сообществе его часто называют **BSL**. Язык существует в двух вариантах — русском и английском: `Сообщить` и `Message` — одно и то же слово. Мы пишем по-русски: на занятии 4 в свойствах конфигурации вариант встроенного языка задан как «Русский».

Код не живёт сам по себе, он лежит в **модуле**. Сегодня нам нужен только один модуль — модуль формы обработки `УчебнаяКонсоль`, созданной на занятии 9.

## Оператор и точка с запятой

**Оператор** — одна законченная команда. Каждый оператор заканчивается точкой с запятой:

```bsl
Сообщить("Первая строка");
Сообщить("Вторая строка");
```

Забытая `;` — самая частая ошибка новичка. Платформа перестаёт понимать, где кончилась одна команда и началась другая, и показывает ошибку в строке, которая на вид совершенно правильная.

## Регистр не важен

Для платформы `Сообщить`, `СООБЩИТЬ` и `сообщить` — одно и то же имя. Но принято писать так, как написано в синтакс-помощнике: КаждоеСловоСБольшойБуквы. Чужой код читается быстрее, когда все пишут одинаково.

## Комментарии

Две косые черты `//` превращают остаток строки в **комментарий** — текст для человека, который платформа пропускает.

```bsl
// Цена мешка по прайсу поставщика на январь
Цена = 12.5;
Сумма = 20 * Цена; // 20 мешков — стандартный поддон
```

Хороший комментарий объясняет **почему**, а не **что**. Запись «присваиваем цену» бесполезна, это и так видно. Полезно другое: откуда взялось число 12.5 и почему мешков именно 20.

## Литералы

**Литерал** — значение, записанное в коде прямо.

| Тип | Как записать | Пример |
| --- | --- | --- |
| Строка | двойные кавычки | `"Цемент М500"` |
| Число | точка как разделитель | `12.5` |
| Дата | одинарные кавычки, ГГГГММДД | `'20260101'` |
| Дата со временем | ГГГГММДДЧЧММСС | `'20260101120000'` |
| Булево | два ключевых слова | `Истина`, `Ложь` |

Кавычку внутри строки удваивают:

```bsl
Сообщить("Склад ""Центральный""");  // выведет: Склад "Центральный"
```

В коде десятичный разделитель — всегда **точка**, даже если на форме пользователь видит запятую. Запись `12,5` в коде — ошибка.

## Арифметика и конкатенация

Для чисел работают `+`, `-`, `*`, `/` и круглые скобки. Приоритет обычный: умножение и деление раньше сложения и вычитания.

Для строк `+` означает другое — **конкатенацию**, то есть склеивание:

```bsl
Материал = "Цемент" + " " + "М500";  // Цемент М500
```

## Сообщить()

`Сообщить()` выводит текст в окно сообщений в нижней части окна приложения. Это главный инструмент первых занятий языка: он показывает, что код отработал, и какое значение получилось.

`Сообщить()` принимает **строку**. Число передавать нельзя — его сначала преобразуют функцией `Строка()`:

```bsl
Сумма = 20 * 12.5;
Сообщить("Итого: " + Строка(Сумма) + " руб.");
```

Подробно о преобразованиях типов — занятие 12.

## Синтакс-помощник и синтаксический контроль

**Синтакс-помощник** — встроенный справочник языка. Поставьте курсор на имя конструкции и нажмите `Ctrl+Alt+F`: откроется описание с параметрами и примером.

**Синтаксический контроль** — команда **Конфигурация → Проверка → Синтаксический контроль**. Она проверяет весь код конфигурации, не запуская приложение, и находит ошибки записи: пропущенную `;`, незакрытую кавычку, неизвестное имя функции.

Чего контроль не умеет — проверять смысл. Если вы умножили количество на количество вместо цены, контроль промолчит: формула записана правильно, она просто неверная.

## Что важно запомнить

1. Код встроенного языка живёт в модулях; каждый оператор заканчивается точкой с запятой.
2. Регистр букв в именах не важен, но писать принято как в синтакс-помощнике.
3. Строка — в двойных кавычках, дата — в одинарных в формате ГГГГММДД, десятичный разделитель в коде — точка.
4. Для чисел `+` складывает, для строк — склеивает; `Сообщить()` принимает только строку, число нужно обернуть в `Строка()`.
5. Синтаксический контроль находит ошибки записи без запуска, но не проверяет правильность формул.
6. `Ctrl+Alt+F` открывает описание конструкции под курсором.
