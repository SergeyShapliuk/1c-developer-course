# Занятие 55. Условия и параметры запроса

## Цель

Научиться отбирать в запросе только нужные строки: заявки одного объекта строительства, документы за период, строки с определёнными материалами. Понять, почему значения для условий передают параметрами, а не вклеивают в текст запроса.

## Результат занятия

В обработке `УчебнаяКонсоль` появится процедура, которая выводит заявки только для «ЖК Северный», без помеченных на удаление и отклонённых, за текущий месяц. Вторая процедура находит строки заявок по списку материалов, третья — материалы по части наименования. Все значения условий передаются в запрос параметрами.

## Маршрут

1. Прочитайте [теорию](theory.md) — около 25 минут.
2. Выполните [практику](practice.md) — около 50 минут.

## Ключевые термины

Условие запроса, `ГДЕ`, параметр запроса, `&Параметр`, `УстановитьПараметр`, `И`, `ИЛИ`, `НЕ`, `В`, `МЕЖДУ`, `ПОДОБНО`, `ЗНАЧЕНИЕ()`, пометка удаления.
