# Теория. Повторение действий

## Зачем нужен цикл

Допустим, нужно вывести таблицу умножения на 7. Можно написать десять строк `Сообщить()`, отличающихся одной цифрой. Но если завтра понадобится не до десяти, а до двадцати, придётся дописывать ещё десять строк и ничего не перепутать.

**Цикл** решает эту задачу иначе: код пишется один раз, а платформа повторяет его столько раз, сколько нужно. Одно повторение называют **итерацией**.

## Для … По … Цикл

Если число повторений известно заранее, берут цикл со счётчиком:

```bsl
Для Счётчик = 1 По 10 Цикл
	Сообщить("7 x " + Строка(Счётчик) + " = " + Строка(7 * Счётчик));
КонецЦикла;
```

`Счётчик` — обычная переменная; её не нужно ни объявлять заранее, ни увеличивать вручную. Платформа сама присваивает ей 1, выполняет тело цикла, затем 2, снова выполняет, и так далее.

Границы включаются **обе**: при записи `1 По 10` тело выполнится ровно десять раз, последнее значение счётчика — 10. Закрывает конструкцию `КонецЦикла;`.

Границы можно задавать выражениями: `Для Счётчик = Начало По Конец Цикл`. Если нижняя граница окажется больше верхней, тело не выполнится ни разу — и это не ошибка.

## Пока … Цикл

Если заранее неизвестно, сколько повторений понадобится, используют цикл по условию:

```bsl
Значение = 1;
Пока Значение < 1000 Цикл
	Значение = Значение * 2;
КонецЦикла;
```

Условие проверяется **перед каждым** повторением. Истина — тело выполняется; ложь — цикл заканчивается. Если условие ложно с самого начала, тело не выполнится ни разу.

Главное отличие от `Для … По`: здесь никто не меняет условие за вас. Строка `Значение = Значение * 2;` внутри тела — это и есть то, что рано или поздно сделает условие ложным, и отвечает за неё разработчик.

## Когда какой

| Задача | Цикл |
| --- | --- |
| Повторить ровно 10 раз | `Для … По` |
| Пройти номера с 1 по N | `Для … По` |
| Удваивать, пока не превысим границу | `Пока` |
| Повторять, пока пользователь не остановит | `Пока` |

Коротко: число повторений известно — `Для … По`; повторяем до наступления события — `Пока`.

## Прервать и Продолжить

Внутри любого цикла работают два оператора.

`Прервать;` немедленно заканчивает цикл: оставшиеся повторения не выполняются, управление переходит на строку после `КонецЦикла`.

`Продолжить;` заканчивает только текущее повторение: остаток тела пропускается, и цикл переходит к следующей итерации.

```bsl
Для Счётчик = 1 По 20 Цикл
	Если Цел(Счётчик / 2) * 2 <> Счётчик Тогда
		Продолжить;  // нечётное — пропускаем
	КонецЕсли;
	Сообщить(Строка(Счётчик));
КонецЦикла;
```

В условии использован приём проверки на чётность. `Цел()` отбрасывает дробную часть: `Цел(7 / 2)` даёт 3, и `3 * 2 = 6`, что не равно 7 — значит, число нечётное. Для чётного числа деление на 2 и умножение обратно вернут его же.

## Бесконечный цикл

Если в цикле `Пока` условие никогда не станет ложным, цикл не закончится никогда:

```bsl
Пока Истина Цикл
	Сообщить("Этот цикл не закончится");
КонецЦикла;
```

Приложение перестанет отвечать: оно занято выполнением тела и не успевает ни перерисовать окно, ни отреагировать на мышь. Выход один — остановить сеанс отладки в конфигураторе клавишами `Shift+F5` или закрыть окно приложения принудительно.

Чаще бесконечный цикл получается не из `Пока Истина`, а по невнимательности: в теле забыли изменить то, что проверяется в условии. Отсюда правило: в цикле `Пока` должно быть видно, какая именно строка тела меняет условие. Не видно — цикл написан неправильно.

## Третий вид цикла

Есть третий вид цикла — `Для Каждого`, он перебирает коллекцию. Коллекции появятся на занятии 17, там же разберём и этот цикл.

## Что важно запомнить

1. Цикл повторяет один и тот же код, не заставляя копировать его; одно повторение — итерация.
2. `Для Счётчик = 1 По 10 Цикл … КонецЦикла;` выполняется ровно десять раз, обе границы включаются, счётчик меняется сам.
3. `Пока Условие Цикл … КонецЦикла;` проверяет условие перед каждым повторением; за изменение условия отвечает разработчик.
4. `Прервать;` выходит из цикла целиком, `Продолжить;` пропускает остаток текущего повторения.
5. Бесконечный цикл получается, когда условие никогда не становится ложным; останавливают его через `Shift+F5`.
6. Накопление результата делают в переменной, объявленной **до** цикла, — иначе на каждой итерации она начиналась бы заново.
