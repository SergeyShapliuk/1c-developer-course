# Занятие 14. Циклы

## Цель

Научиться повторять действия без копирования кода: освоить цикл со счётчиком, цикл по условию, досрочный выход и пропуск повторения, а также понять, как возникает бесконечный цикл и как его не допустить.

## Результат занятия

Обработка `УчебнаяКонсоль` выводит таблицу умножения, накапливает сумму и строку в переменной, удваивает число до нужной границы, прерывает перебор по достижении лимита и печатает только чётные значения. Вы умышленно создали бесконечный цикл, остановили приложение и добавили условие выхода.

## Маршрут

1. Прочитайте [теорию](theory.md) — около 20 минут.
2. Выполните [практику](practice.md) — около 55 минут.
3. Ответьте на контрольные вопросы в конце практики, не подглядывая в теорию.

## Ключевые термины

Цикл, итерация, счётчик, `Для … По … Цикл`, `Пока … Цикл`, `КонецЦикла`, `Прервать`, `Продолжить`, переменная-накопитель, бесконечный цикл, остановка отладки.
