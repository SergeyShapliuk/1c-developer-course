# Теория. Перечисления и константы

## Перечисление

**Перечисление** — объект метаданных с заранее определённым небольшим списком вариантов. В отличие от справочника, пользователь не добавляет в него новые элементы во время работы.

Например, вид клиента в ERP-системе может быть только «Заказчик», «Поставщик» или «Подрядчик». Эти варианты создаёт разработчик в Конфигураторе. Перечисление подходит, когда набор значений известен и редко меняется.

## Константа

**Константа** хранит одно общее значение для всей информационной базы. Например, наименование организации, рабочий телефон или дату начала учёта. В отличие от реквизита, константа не повторяется у каждого элемента справочника.

Разработчик создаёт константу и задаёт её тип в Конфигураторе. Пользователь вводит само значение в режиме «1С:Предприятие», обычно через команду «Константы».

## Как выбрать объект

Используйте справочник для растущего списка сущностей, перечисление — для фиксированного выбора, константу — для одного общего значения. Неправильный выбор усложняет работу: например, не стоит хранить название компании в каждом клиенте.
