# Практика. Создаём виды клиентов и настройку компании

## Перед началом

Откройте учебную базу в Конфигураторе. Сегодня создаются два новых типа объектов метаданных: перечисление и константа.

## Шаг 1. Создайте перечисление «ВидыКлиентов»

1. В дереве найдите группу **Перечисления**, щёлкните по ней правой кнопкой мыши и выберите **Добавить**.
2. В окне свойств введите имя `ВидыКлиентов` и синоним «Виды клиентов».
3. Откройте вкладку **Данные** или ветку значений перечисления. Нажмите **Добавить**.
4. Создайте значение с именем `Заказчик` и синонимом «Заказчик».
5. Таким же способом создайте `Поставщик` / «Поставщик» и `Подрядчик` / «Подрядчик».
6. Нажмите `Ctrl+S`.

**Проверка:** перечисление содержит ровно три предопределённых варианта. Пользователь не сможет создать четвёртый вариант через интерфейс приложения.

## Шаг 2. Создайте константу «НаименованиеКомпании»

1. В дереве найдите группу **Константы**, щёлкните правой кнопкой и выберите **Добавить**.
2. В поле **Имя** введите `НаименованиеКомпании`, в поле **Синоним** — «Наименование компании».
3. В свойстве **Тип** выберите `Строка`: название компании — текст.
4. Нажмите `Ctrl+S`.

## Шаг 3. Введите значение константы

1. Нажмите `F7` и подтвердите обновление конфигурации базы данных.
2. Нажмите `F5`, чтобы открыть «1С:Предприятие».
3. Откройте команду **Все функции** (если она доступна) и найдите группу **Константы**. Откройте «Наименование компании».
4. Введите «ООО Управление строительной компанией» и сохраните значение.

Если команды «Все функции» нет, включите её в Конфигураторе: **Сервис → Параметры**, затем на вкладке «Запуск 1С:Предприятия» установите флажок «Отображать команду “Все функции”». Перезапустите пользовательский режим.

## Контрольные вопросы

1. Почему «ВидыКлиентов» — перечисление, а не справочник?
2. Где разработчик создаёт варианты перечисления, а где пользователь вводит значение константы?
3. Что хранит константа «НаименованиеКомпании»: одно значение или отдельное значение для каждого клиента?
