# День 5. Перечисления и константы

## Цель

Научиться хранить фиксированный набор вариантов в перечислении и одно общее значение компании в константе.

## Результат дня

В конфигурации появится перечисление «ВидыКлиентов» и константа «НаименованиеКомпании». Вы введёте их значения в режиме «1С:Предприятие».

## Маршрут

1. Прочитайте [теорию](theory.md).
2. Выполните [практику](practice.md).
3. Ответьте на контрольные вопросы в конце практики.
