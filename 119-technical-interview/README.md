# Занятие 119. Техническое собеседование

## Цель

Подготовиться к техническому собеседованию на позицию junior 1С-разработчика: отвечать на теоретические вопросы по схеме «что это, зачем, пример из проекта», рассказывать о своих ошибках и решениях по схеме ситуация — задача — действия — результат, решать задачи на запрос и код без конфигуратора, рассуждая вслух, и задавать работодателю вопросы, по которым видно, что вы понимаете работу.

## Результат занятия

В конспекте появятся тезисы ответов на двадцать типичных вопросов, три истории из проекта, решения трёх задач собеседования, написанные без конфигуратора и проверенные потом в «Учебной консоли», список вопросов работодателю и запись пробного собеседования с разбором. Конфигурация после проверки задач вернётся к состоянию `main`.

## Маршрут

1. Прочитайте [теорию](theory.md) — около 30 минут.
2. Выполните [практику](practice.md) — около 120 минут; пробное собеседование можно провести отдельным днём.
3. Ответьте на контрольные вопросы в конце практики, не подглядывая в теорию.

## Ключевые термины

Этапы собеседования, теоретический вопрос, схема ответа, история по схеме «ситуация — задача — действия — результат», задача на запрос, задача на поиск ошибок, задача на код, рассуждение вслух, уточнение условий, «не знаю, но выясню так», вопросы работодателю, пробное собеседование.
