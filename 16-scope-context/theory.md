# Теория. Где живут переменные

## Область видимости

На занятии 12 всё происходило внутри одной процедуры, и вопрос «а где это имя вообще известно?» не возникал. Теперь процедур несколько, и вопрос становится главным.

**Область видимости** — это участок кода, внутри которого имя переменной известно. Снаружи такого имени для платформы не существует. Задаётся область видимости не вашим желанием, а местом объявления: где объявили — там и видно.

## Локальная переменная

**Локальная переменная** объявлена внутри процедуры или функции. Она видна только в этой процедуре, от строки объявления до `КонецПроцедуры`.

```bsl
&НаКлиенте
Процедура ПосчитатьМатериалы()
	
	Количество = 5; // локальная переменная: существует только здесь
	Сообщить("Позиций: " + Строка(Количество));
	
КонецПроцедуры
```

Важнее всего время жизни. Значение локальной переменной появляется при входе в процедуру и исчезает при выходе. Вызвали процедуру второй раз — переменная создалась заново и ничего не помнит о первом вызове.

Если из другой процедуры написать `Сообщить(Количество)`, модуль не скомпилируется. Это **ошибка компиляции**: платформа обнаружит её при проверке модуля, ещё до запуска приложения, а не в момент, когда пользователь нажал кнопку.

## Переменная модуля

Иногда значение должно сохраняться между вызовами. Для этого переменную объявляют **в самом начале модуля**, до первой процедуры:

```bsl
Перем ЧислоВызовов;

&НаКлиенте
Процедура Выполнить(Команда)
	
	ЧислоВызовов = ЧислоВызовов + 1;
	Сообщить("Вызов номер " + Строка(ЧислоВызовов));
	
КонецПроцедуры
```

**Переменная модуля** видна во всех процедурах и функциях этого модуля. Её значение живёт, пока открыта форма: первое нажатие кнопки даст `1`, второе `2`, третье `3`. Закрыли форму — значение потеряно, при новом открытии всё начинается с нуля.

Обратите внимание: такую переменную нельзя увидеть в приложении. Она существует только для кода.

## Контекст формы

**Контекст формы** — это набор данных и процедур формы, доступных её коду без всяких дополнительных действий. Реквизиты формы — часть контекста.

Реквизиты формы вы создавали на занятии 9, на вкладке **Реквизиты** редактора формы. Там же их перетаскивают на форму, чтобы пользователь увидел поле.

Поскольку реквизит принадлежит форме, а процедура тоже принадлежит форме, передавать реквизит параметром не нужно — он и так известен:

```bsl
&НаКлиенте
Процедура УвеличитьСчётчик()
	
	Счётчик = Счётчик + 1; // Счётчик — реквизит формы, параметр не нужен
	
КонецПроцедуры
```

## ЭтаФорма

`ЭтаФорма` — это явная ссылка на саму форму. Запись `ЭтаФорма.Счётчик` означает ровно то же, что и короткая `Счётчик`.

Короткая запись удобнее, но у неё есть слабое место: если у процедуры окажется параметр с таким же именем, имя внутри процедуры будет означать параметр, а не реквизит. Явная запись `ЭтаФорма.Счётчик` снимает двусмысленность и сразу говорит читателю: это данные формы, а не что-то местное.

## Реквизит формы или переменная модуля

Оба способа сохраняют значение между нажатиями кнопки. Разница в том, видит ли значение пользователь.

| Что нужно | Что выбрать |
| --- | --- |
| Значение надо показать на форме | Реквизит формы |
| Значение нужно только коду, его не показывают | Переменная модуля |
| Значение нужно в одной процедуре | Локальная переменная |

Правило простое: если значение выводится на форму или вводится пользователем — это реквизит.

## Почему избегают глобальных переменных

**Глобальной** называют переменную, доступную из очень большого числа мест. Чем шире область видимости, тем больше кода может изменить значение — и тем труднее понять, кто его изменил.

Беда не в самом факте доступа, а в диагностике: ошибка проявляется там, где значение прочитали, а причина — в совсем другой процедуре, которая записала его раньше. Искать такую причину долго и неприятно.

Поэтому действует правило: **выбирайте минимальную область видимости, которой достаточно для задачи**.

## Переменные, видимые из других модулей

Переменную модуля можно объявить особым ключевым словом, и тогда её разрешат читать из других модулей. На практике так почти не делают: это та самая широкая область видимости, от которой советуют держаться подальше. Способы правильно разделить код между модулями разберём на занятии 21.

## Что важно запомнить

1. Область видимости определяется местом объявления: где объявили — там и видно.
2. Локальная переменная живёт от входа в процедуру до выхода и ничего не помнит о предыдущем вызове.
3. Обращение к локальной переменной другой процедуры — ошибка компиляции, она обнаруживается при проверке модуля, а не во время работы.
4. Переменная модуля объявляется до первой процедуры, видна во всём модуле и живёт, пока открыта форма.
5. Реквизит формы — часть контекста формы, поэтому процедуры формы видят его без параметров и его можно показать пользователю.
6. `ЭтаФорма.Счётчик` и `Счётчик` — одно и то же; явная запись спасает, когда рядом есть параметр с тем же именем.
7. Выбирайте самую узкую область видимости, которой достаточно для задачи.
