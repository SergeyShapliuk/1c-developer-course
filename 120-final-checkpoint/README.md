# Занятие 120. Итоговая контрольная точка: тестовое задание

## Цель

Это **итоговая контрольная точка** курса — девятая и последняя. Нового материала здесь нет. Нужно выполнить задание, похожее на тестовое задание работодателя: самостоятельно добавить в конфигурацию новый документ со своим проведением, контролем, вводом на основании, правами и тестами и довести его через весь жизненный цикл доработки до версии в рабочей базе. Задание опирается на все этапы курса сразу.

## Результат занятия

В конфигурации появится документ `ВозвратМатериалов`: материал, не израсходованный на объекте, возвращается на склад и увеличивает его остаток. Вернуть больше, чем передано на объект за вычетом уже возвращённого, нельзя — даже кладовщику, который не видит передач чужих складов. Возврат вводится на основании передачи, кладовщик оформляет возвраты только на свой склад, тесты `ТестыСнабжения` проверяют правило за секунды. Изменение прошло ветку, pull request и самопроверку, вышла версия `1.3.0` с тегом, поставочным файлом и списком изменений, копия рабочей базы обновлена, README портфолио дополнен. Плюс заполненный чек-лист и фактическое время работы.

## Маршрут

1. Прочитайте [теорию](theory.md) — около 20 минут. Она не про новые возможности, а про то, как выполнять тестовое задание.
2. Выполните [практику](practice.md): сначала решите задачу сами, потом пройдите чек-лист. Ориентир — восемь часов чистого времени, как у тестового задания; их можно разделить на несколько дней.
3. **Раздел «Разбор и эталонный вариант» открывайте только после своей попытки.** Готовое решение, прочитанное заранее, не научит его находить: контрольная точка проверяет умение, а не память.

## Ключевые термины

Тестовое задание, итоговая контрольная точка, учёт времени, документ-регистратор, ввод на основании, контроль по данным документов, привилегированный режим, ограничение доступа на уровне записей, автоматический тест, регрессионный набор, pull request, версия, поставка, портфолио.
