# День 10. Регистры накопления: остатки на складах

## Цель

Познакомиться с регистрами накопления и подготовить структуру для учёта количества материалов по складам.

## Результат дня

В конфигурации появится регистр накопления `ОстаткиМатериалов`. Документ `ПоступлениеМатериалов` будет зарегистрирован как его регистратор, а учащийся поймёт, как движения документов меняют остатки.

2. Выполните [практику](practice.md).
